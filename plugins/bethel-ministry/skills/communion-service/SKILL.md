# 벧엘교회 성찬식 집례 스킬

## 기본 컨텍스트

| 항목 | 내용 |
|------|------|
| 교회 | 1사단 58포병대대 벧엘교회 |
| 집례자 | 군선교사 김병국 목사 |
| 시행 주기 | 매월 마지막 주일 (성례주일) |
| 대상 | 20대 초반 남성 군인, 초신자 중심 |
| 위치 | 설교 직후, 봉헌 이전 |

---

## 성찬식 5단계 구조 (고정)

```
도입 멘트
  ↓
① 성령임재의 기도
  ↓
② 성찬제정말씀 (고전 11:23-26) — 항상 동일
  ↓
③ 분병·분잔 — 항상 동일
  ↓
④ 성찬후기도
```

---

## 입력 → 출력 매핑

### 입력 (사용자 제공)
1. **설교 주제어** (필수): 당일 설교의 메인아이디어 또는 제목
2. **서브 키워드** (선택): 설교 무브 제목들, 핵심 이미지, 마지막 무브 언어
3. **절기 정보** (선택): 교회력 절기 (예: 성령강림절후 5주)

입력이 없으면 "오늘 설교 주제어가 무엇인지 알려주시면 그에 맞게 작성해 드리겠습니다"라고 묻는다.

### 출력
5단계 성찬식 전체 멘트. 마크다운 헤더 구분, 강단 낭독에 적합한 단문 구조.

---

## 단계별 작성 원칙

### 도입 멘트 (2~3문장)
- 설교의 메인아이디어를 한 줄로 회수
- "이제 성찬을 통해 그 [주제어]를 몸으로 기억하겠습니다"로 마무리
- 성찬 식탁으로의 초대로 마침

**구조 공식:**
```
오늘 우리는 [메인아이디어] — [부연 한 줄]을 배웠습니다.
이제 성찬을 통해 그 [주제어]를 몸으로 기억하겠습니다.
[선행적 은혜 한 줄: 주님이 먼저 ~ 기다리십니다 / 부르셨습니다 등]
```

### ① 성령임재의 기도 (4~6문장)
- 고정 틀 + 설교 키워드 1개 삽입
- "우리의 믿음이 [설교 이미지]처럼 작아도" 형식으로 삽입
- 아멘으로 마침

**고정 골격:**
```
하나님 아버지, 우리가 이 떡과 잔 앞에 나왔습니다.
[선행적 은혜 1문장 — 주님이 먼저 ~ 를 고백합니다]
성령님께서 임하셔서 예수님의 몸과 피를 기억하는 이 시간을 거룩하게 하여 주소서.
우리의 믿음이 [설교 이미지]처럼 작아도, 이 순간 주님을 만나게 하소서.
예수님의 이름으로 기도합니다. 아멘.
```

### ② 성찬제정말씀 — 항상 동일 (수정 금지)
아래 텍스트를 그대로 사용한다.

```
주 예수께서 잡히시던 밤에 떡을 가지사 축사하시고 떼어 이르시되,
"이것은 너희를 위하는 내 몸이니, 이것을 행하여 나를 기념하라" 하시고,
식후에 또한 잔을 가지시고 이르시되,
"이 잔은 내 피로 세운 새 언약이니, 이것을 행하여 마실 때마다 나를 기념하라" 하셨나니,
너희가 이 떡을 먹으며 이 잔을 마실 때마다 주의 죽으심을 그가 오실 때까지 전하는 것이니라.
```

### ③ 분병·분잔 — 항상 동일 (수정 금지)
```
[ 떡을 들고 ]
이것은 우리를 위하여 찢기신 그리스도의 몸입니다.
믿음으로 받으십시오.

[ 잔을 들고 ]
이것은 우리를 위하여 흘리신 그리스도의 피,
새 언약의 잔입니다. 믿음으로 받으십시오.

(세례받으신 분들은 앞으로 나오셔서 받으십시오. — 음악 재생)
```

### ④ 성찬후기도 (5~7문장)
- 설교 키워드 2~3개를 기도 언어로 회수
- 구조: 기억 → 감사 → 삶으로 내보냄 → 제목·핵심 고백을 기도로 수행
- 마지막 문장: 설교 제목 또는 핵심 선언을 1인칭 복수 서원으로 마침

**구조 공식:**
```
주님, 이 떡과 잔을 통해 우리를 위해 찢기시고 흘리신 그 사랑을 다시 기억합니다.
[설교 무브 키워드 회수 1~2문장]
이 기억이 우리 안에 살아서 [삶의 적용] 하게 하옵소서.
[제목/핵심 고백을 기도로 수행]
예수님의 이름으로 기도합니다. 아멘.
```

## 스타일 원칙

- **단문 구조**: 한 문장 = 한 생각. 구어 낭독에 적합하게.
- **만연체 금지**: 접속사 중복, 복문 중첩 피함.
- **초신자 언어**: 신학 전문 용어 최소화.
- **선행적 은혜**: 하나님이 먼저 행하신다는 주도성이 모든 단계에 최소 1회 명시.
- **설교 흐름 지속**: 성찬식 멘트는 설교의 연장선이지 별개 예식이 아님.

## 작업 절차

1. 입력에서 **설교 주제어·키워드** 추출
2. 도입 멘트 작성 (구조 공식 적용)
3. 성령임재기도 작성 (고정 골격 + 설교 이미지 삽입)
4. 제정말씀 그대로 삽입 (수정 금지)
5. 분병분잔 그대로 삽입 (수정 금지)
6. 성찬후기도 작성 (키워드 회수 + 제목 기도 수행)
7. 전체 5단계 최종 출력
