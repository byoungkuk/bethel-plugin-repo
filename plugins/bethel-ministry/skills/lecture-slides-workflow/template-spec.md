# 강의 슬라이드 템플릿 디자인 사양

이 문서는 강의 슬라이드 생성(Phase 4)에서 참조하는 디자인 사양이다.
`중소_건설사를_위한_AI_실무_혁신.pptx` 템플릿을 기준으로 추출했다.

## Quick Reference

Phase 4 시작 시 아래 값만 먼저 확인한다. 상세 좌표는 해당 유형 작업 시 참조.

```javascript
// 슬라이드 크기
pres.defineLayout({ name: "LECTURE", width: 26.67, height: 15 });

// 공통 제목 좌표 (타이틀 제외 모든 유형)
{ x: 1.0, y: 0.59, w: 24.67, h: 1.2, fontSize: 60, color: "000000", bold: true, align: "center" }

// 색상 팔레트
const COLORS = {
  black: "000000",      // 주 텍스트
  accent: "F27100",     // 악센트 (주제별 변경 가능 → 섹션 7 참조)
  section: "5E5E5E",    // 섹션 번호 원형 배경
  white: "FFFFFF",      // 섹션 번호 텍스트, 배경
  gray: "B8B8B8",       // 보조 텍스트
  cardBg: "F5F5F5",     // 카드 배경
  practiceBg: "FFF3E0", // 실습 슬라이드 배경
};

// 폰트 크기
// 타이틀: 180pt | 섹션번호: 90pt | 섹션제목: 95pt | 콘텐츠제목: 60pt | 강사명: 32pt
```

## 3. 타이포그래피

### 폰트 크기 (EMU 단위 → pt 환산)

| 용도 | EMU sz 값 | pt 환산 | 적용 위치 |
|------|----------|---------|----------|
| 타이틀 슬라이드 제목 | 18000 | 180pt | 슬라이드 1 메인 제목 |
| 섹션 구분 번호 | 9000 | 90pt | 원형 안 숫자 |
| 섹션 구분 제목 | 9500 | 95pt | 섹션 제목 텍스트 |
| 콘텐츠 슬라이드 제목 | 6000 | 60pt | 일반 슬라이드 제목 |
| 타임라인/보조 텍스트 | 5000 | 50pt | 비활성 시간 표시 등 |
| 강사 정보 | 3200 | 32pt | 강사명, 소속 |

> python-pptx에서 `Pt(180)` = `Emu(18000 * 12700)` = `228600000`. 
> `font.size = Pt(180)` 형태로 사용.

### 폰트 패밀리
- 시스템 기본 폰트 사용 (별도 지정 없음)
- 한글: 시스템 기본 한글 폰트
- 정렬: 타이틀·섹션 구분은 중앙 정렬, 콘텐츠 제목은 중앙 또는 좌측

## 4. 슬라이드 유형별 좌표 사양

### 4-0. 공통 제목 좌표

타이틀 슬라이드를 제외한 모든 슬라이드 유형은 아래 공통 제목 좌표를 사용한다.

| 요소 | x (in) | y (in) | w (in) | h (in) |
|------|--------|--------|--------|--------|
| 제목 텍스트 | 1.0 | 0.59 | 24.67 | 1.2 |

- 60pt, 검정(#000000), bold, 중앙 정렬
- 제목 폭 24.67"는 전체 슬라이드 폭(26.67")에서 좌우 1" 여백을 뺀 값
- 이 값은 테스트에서 60pt 한글 긴 제목(25자)이 1줄에 표시됨을 확인한 값

> `references/slide-types.md`의 각 유형에서 "공통 제목 좌표 적용"으로 표기된 경우 이 값을 사용한다.

### 4-1. 타이틀 슬라이드

```
┌─────────────────────────────────────┐
│                                     │
│     [강의 제목] — 180pt, 중앙정렬    │
│     악센트 색상으로 키워드 강조       │
│                                     │
│     [강사명] — 32pt, 중앙            │
│                                     │
│     ┌───────────────────────┐       │
│     │   일러스트 이미지       │       │
│     │   (좌우 대비 구도)      │       │
│     └───────────────────────┘       │
│                                     │
└─────────────────────────────────────┘
```

| 요소 | left (in) | top (in) | width (in) | height (in) |
|------|-----------|----------|------------|-------------|
| 제목 텍스트 | 2.62 | 1.46 | 21.43 | 5.81 |
| 강사명 | 9.5 | 7.6 | 7.67 | 0.94 |
| 일러스트 | 3.38 | 9.33 | 19.90 | 5.54 |

> **테스트 검증 결과**: 강사명은 제목 텍스트 아래, 일러스트 위에 배치해야 가려지지 않는다. 원본 템플릿의 EMU 좌표(top=6696148)는 180pt 제목과 겹침 발생.

**제목 텍스트 규칙:**
- 제목에서 핵심 키워드 1~2개를 악센트 색(#F27100)으로 표시
- 나머지 텍스트는 검정(#000000)
- 줄바꿈으로 2줄 구성 (예: "중소 건설사를 위한" + "AI 실무 혁신")

### 4-2. 섹션 구분 슬라이드

```
┌─────────────────────────────────────┐
│                                     │
│     (N)  섹션 제목                   │
│     원형   95pt                      │
│     90pt                            │
│                                     │
│     [일러스트 / 아이콘]              │
│                                     │
└─────────────────────────────────────┘
```

| 요소 | left (in) | top (in) | width (in) | height (in) |
|------|-----------|----------|------------|-------------|
| 원형 번호 그룹 | 6.87 | 2.51 | 2.56 | 2.56 |
| 섹션 제목 | 9.95 | 2.94 | 15.89 | 1.69 |

**원형 번호 그룹 구성:**
- 원형(circle) 도형: 배경 #5E5E5E, 텍스트 #FFFFFF, 폰트 90pt
- 숫자만 표시 (1, 2, 3...)

**섹션 제목 규칙:**
- 95pt, 색상 #5E5E5E
- 간결한 구문 (예: "AI 리터러시 & 인식 전환", "AI 필수 도구 소개: 우리 회사의 무기")
- 2줄까지 허용

### 4-3. 콘텐츠 슬라이드 (제목 + 일러스트)

```
┌─────────────────────────────────────┐
│  [①번호 + 제목] — 60pt, 중앙정렬    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │                             │    │
│  │     일러스트 이미지           │    │
│  │     (슬라이드 면적 60~70%)   │    │
│  │                             │    │
│  └─────────────────────────────┘    │
│                                     │
└─────────────────────────────────────┘
```

| 요소 | left (in) | top (in) | width (in) | height (in) |
|------|-----------|----------|------------|-------------|
| 제목 텍스트 | **공통 제목 좌표 적용 (4-0 참조)** | | | |
| 일러스트 | 1.66 | 3.04 | 23.34 | 11.10 |

**제목 규칙:**
- 공통 제목 좌표(4-0) + 60pt, 검정, bold
- 섹션 내 순서를 ①②③ 번호로 접두 (예: "①왜 지금 AI인가?")
- 판단·행동 중심 문장 (예: "사람을 대체하는 것이 아닌, '서류 지옥'에서 해방")

**일러스트 배치:**
- 제목 아래 전체 영역에 배치
- 가로·세로 비율 유지하며 최대 크기로 배치

### 4-4. 마무리/요약 슬라이드

콘텐츠 슬라이드와 동일한 레이아웃.
- 제목에 "④스마트한 현장 관리자로의 변화" 같은 요약 문구
- 하단에 한 줄 결론 텍스트 추가 가능

| 요소 | left (in) | top (in) | width (in) | height (in) |
|------|-----------|----------|------------|-------------|
| 결론 텍스트 | 9.43 | 11.49 | 12.22 | 0.85 |

## 5. pptxgenjs 구현 시 참고

> pptx 스킬(`/mnt/skills/public/pptx/pptxgenjs.md`)은 pptxgenjs를 사용한다.
> 모든 좌표는 **인치(inches)** 단위.

### 슬라이드 크기 설정
```javascript
const pptxgen = require("pptxgenjs");
let pres = new pptxgen();
pres.defineLayout({ name: "LECTURE", width: 26.67, height: 15 });
pres.layout = "LECTURE";
```

### 콘텐츠 슬라이드 제목
```javascript
slide.addText("①왜 지금 AI인가? 현실은 우리를 기다려주지 않습니다", {
  x: 1.0, y: 0.59, w: 24.67, h: 1.2,
  fontSize: 60, color: "000000", bold: true, align: "center", valign: "middle",
});
```

### 섹션 번호 원형
```javascript
// 원형 배경
slide.addShape(pres.shapes.OVAL, {
  x: 6.87, y: 2.51, w: 2.56, h: 2.56,
  fill: { color: "5E5E5E" },
});
// 원형 안 숫자
slide.addText("1", {
  x: 6.87, y: 2.51, w: 2.56, h: 2.56,
  fontSize: 90, color: "FFFFFF", bold: true, align: "center", valign: "middle",
});
// 섹션 제목
slide.addText("AI 리터러시 & 인식 전환", {
  x: 9.95, y: 2.94, w: 15.89, h: 1.69,
  fontSize: 95, color: "5E5E5E", bold: true, valign: "middle",
});
```

### 악센트 색상 적용 (타이틀 슬라이드)
```javascript
slide.addText([
  { text: "중소 ", options: { fontSize: 180, color: "000000", bold: true } },
  { text: "건설사", options: { fontSize: 180, color: "F27100", bold: true } },
  { text: "를 위한", options: { fontSize: 180, color: "000000", bold: true, breakLine: true } },
  { text: "AI ", options: { fontSize: 180, color: "F27100", bold: true } },
  { text: "실무 혁신", options: { fontSize: 180, color: "000000", bold: true } },
], {
  x: 2.62, y: 1.46, w: 21.43, h: 5.81,
  align: "center", valign: "middle",
});
```

### 이미지 배치
```javascript
slide.addImage({
  path: "illustration.png",
  x: 1.66, y: 3.04, w: 23.34, h: 11.10,
});
```

## 6. 슬라이드 순서 패턴

템플릿에서 관찰된 슬라이드 순서:

```
1. 타이틀 슬라이드
2. 섹션 구분 (모듈 1)
3~6. 콘텐츠 슬라이드 (①②③... 번호 접두)
7. 섹션 구분 (모듈 2)
8~9. 콘텐츠 슬라이드
...반복
```

- 각 섹션의 콘텐츠 슬라이드는 ①②③④ 번호로 순서 표시
- 섹션이 바뀌면 번호가 ①부터 다시 시작
- 마지막 콘텐츠 슬라이드에 한 줄 결론 텍스트 가능

## 7. 색상 커스터마이징

기본 팔레트(섹션 2)는 건설 분야용이다. 강의 주제에 따라 악센트 색을 변경한다.

### 주제별 추천 색상

| 강의 주제 | 악센트 색 | 섹션 번호 | 배경 유지 |
|----------|---------|----------|---------|
| 건설·안전 | `F27100` (주황) | `5E5E5E` | 흰색 |
| IT·개발 | `2563EB` (파랑) | `374151` | 흰색 |
| 마케팅·콘텐츠 | `7C3AED` (보라) | `4B5563` | 흰색 |
| 교육·학술 | `059669` (초록) | `4B5563` | 흰색 |
| 금융·경영 | `1E40AF` (네이비) | `374151` | 흰색 |
| 의료·헬스케어 | `0891B2` (틸) | `475569` | 흰색 |

### 색상 변경 규칙

1. **악센트 색 1가지만 변경** — 타이틀 키워드, 콘텐츠 번호, 실습 라벨, 체크포인트 제목에 적용
2. **섹션 번호 원형 색은 진회색 계열 유지** — 악센트와 동일 색으로 바꾸지 않음
3. **배경은 흰색 유지** — 실습 슬라이드의 연한 배경만 악센트의 10% 투명도 변형 사용
4. 사용자가 색상을 직접 지정하면 그 값을 우선 적용

### 실습 배경색 변환 규칙

악센트 색에서 실습 배경색을 도출:
- `F27100` → `FFF3E0` (연한 주황)
- `2563EB` → `EFF6FF` (연한 파랑)
- `7C3AED` → `F3E8FF` (연한 보라)
- `059669` → `ECFDF5` (연한 초록)

## 8. Speaker Notes (발표 노트) 삽입

pptxgenjs에서 슬라이드별 발표 노트를 삽입한다.

### 코드
```javascript
slide.addNotes("발표 노트 텍스트 내용");
```

### 발표 노트 작성 규칙

각 슬라이드의 노트에 다음 3가지를 포함:

1. **무엇을 말할지** — 이 슬라이드에서 전달할 핵심 메시지 (100~200자)
2. **전환 멘트** — 다음 슬라이드로 넘어갈 때 사용할 문장 ("[전환 멘트]" 접두)
3. **예상 질문** — 수강생이 할 수 있는 질문과 답변 ("[예상 질문]" 접두, 선택)

### 예시
```javascript
slide.addNotes(
  "프롬프트 엔지니어링의 핵심 공식 Role+Context+Format을 설명합니다.\n\n" +
  "[전환 멘트] \"이 세 가지만 기억하면 됩니다. 하나씩 살펴보겠습니다.\"\n\n" +
  "[예상 질문] \"영어로 써야 하나요?\" → 한국어로 써도 됩니다."
);
```

### 슬라이드 유형별 노트 분량

| 유형 | 노트 분량 | 포함 요소 |
|------|----------|----------|
| 타이틀 | 50~100자 | 인사, 강의 소개 |
| 섹션 구분 | 50~100자 | 이 모듈에서 다룰 내용 예고 |
| 콘텐츠 | 150~300자 | 핵심 설명 + 전환 멘트 |
| 실습 안내 | 200~400자 | 진행 안내 + 시간 관리 + 예상 질문 |
| 체크포인트 | 100~200자 | 정답 해설 + 전환 멘트 |
| 요약/정리 | 100~150자 | 핵심 정리 + 다음 섹션 예고 |
