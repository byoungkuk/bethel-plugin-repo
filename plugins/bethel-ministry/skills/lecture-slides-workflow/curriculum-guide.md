# 커리큘럼 설계 가이드

이 문서는 Phase 2(커리큘럼 설계)에서 참조한다.
시간별 구성 가이드, 모듈 설계 원칙, 실습 설계 기준을 정의한다.

---

## 1. 설계 원칙

### 전체 흐름
- **이해 → 설계 → 실행 → 확장**을 기본 골격으로
- 각 모듈은 **"왜 필요한가"로 시작 → 개념 → 실습/적용 → 정리** 구조
- 실습 비율: 전체의 30~50% 권장
- 모듈당 20~40분 단위로 구성 (집중력 한계 고려)
- 모듈 사이 휴식·전환 시간 포함

### 모듈 내부 구조

```
[왜 필요한가] (2~3분)
     ↓
[핵심 개념] (10~15분)
     ↓
[기준·판단] (5~10분)
     ↓
[실습/적용] (10~15분)
     ↓
[정리·전환] (2~3분)
```

---

## 2. 시간별 구성 가이드

### 60분 (1시간) 강의

```
모듈 1 (20분): 핵심 개념 — 왜 이것이 필요한가 + 기본 구조
모듈 2 (25분): 실습/적용 — 핵심 1가지를 직접 해보기
마무리 (15분): 정리 + Q&A
```

> 60분은 기업 특강, 세미나 발표에서 가장 많이 요청되는 포맷이다.
> 쉬는 시간 없이 진행하므로, 모듈 1→2 전환 시 "잠깐 스트레칭" 정도만 넣는다.
> 개념과 실습을 1:1 비율로 구성하되, 실습은 따라하기 유형 1개에 집중한다.

### 90분 강의

```
모듈 1 (25분): 개념 이해 — 왜 이것이 필요한가
모듈 2 (25분): 핵심 기준과 구조
  쉬는 시간 (10분)
모듈 3 (20분): 실습/적용
마무리 (10분): 정리 + Q&A
```

### 2시간 강의

```
모듈 1 (30분): 개념 이해 — 왜 이것이 필요한가
모듈 2 (35분): 핵심 기준과 구조
  쉬는 시간 (10분)
모듈 3 (30분): 실습/적용
마무리 (15분): 정리 + Q&A
```

### 3시간 강의

```
모듈 1 (35분): 개념과 사고 방식
모듈 2 (35분): 구조와 기준
  쉬는 시간 (10분)
모듈 3 (35분): 실습 1 — 기본 적용
  쉬는 시간 (10분)
모듈 4 (25분): 실습 2 — 심화 또는 변형
마무리 (10분): 정리 + Q&A
```

### 4시간 (반일) 강의

```
모듈 1 (40분): 개념과 사고 방식
모듈 2 (40분): 구조와 기준
  쉬는 시간 (15분)
모듈 3 (45분): 실습 1 — 기본 적용
모듈 4 (45분): 실습 2 — 심화 적용
  쉬는 시간 (15분)
모듈 5 (30분): 수정·변형·확장
마무리 (20분): 전체 정리 + Q&A
```

### 6시간 (1일) 강의

```
[오전]
모듈 1 (40분): 개념과 배경
모듈 2 (40분): 핵심 구조
  쉬는 시간 (15분)
모듈 3 (50분): 기초 실습
  점심 (60분)

[오후]
모듈 4 (45분): 심화 실습
  쉬는 시간 (15분)
모듈 5 (45분): 프로젝트/응용
모듈 6 (30분): 확장·연결
마무리 (20분): 전체 정리 + Q&A
```

## 3. 실습 설계 기준

### 실습 유형

| 유형 | 설명 | 소요 시간 | 적합 상황 |
|------|------|----------|----------|
| 따라하기 | 강사 시연을 그대로 재현 | 10~15분 | 입문자, 새 도구 |
| 조건부 과제 | 주어진 조건에 맞게 결과물 생성 | 15~25분 | 중급, 응용력 |
| 자유 과제 | 본인 업무에 적용 | 20~30분 | 실무자, 워크숍 |
| 모둠 과제 | 팀 단위 협업 결과물 | 30~45분 | 1일 과정, 프로젝트 |

### 실습 안내 포함 요소

1. **과제 명세**: 무엇을 만드는가 (산출물 명확히)
2. **제약 조건**: 사용 도구, 범위, 제한 사항
3. **시간**: 분 단위로 명시
4. **판단 기준**: "이것만 지키면 된다" 1~2개
5. **힌트** (선택): 막힐 때 참고할 방향

---

## 4. 모듈 간 연결 설계

### 전환 논리

각 모듈의 마지막 슬라이드에서 다음 모듈로의 연결을 설계한다.

- **질문으로 전환**: "이제 개념을 알았으니, 실제로 어떻게 쓸까요?"
- **문제 제기로 전환**: "그런데 이 방법에는 한 가지 문제가 있습니다."
- **확장으로 전환**: "기본을 익혔으니, 더 강력한 활용법을 봅시다."

### 반복 요소

- 아젠다 슬라이드: 각 모듈 시작 시 전체 흐름에서 현재 위치 표시
- 체크포인트: 개념 모듈 후 1~2개 이해도 확인 질문
- 요약: 각 모듈 종료 시 핵심 포인트 3~5개

## 5. 수강 대상별 조정

| 대상 | 개념 비율 | 실습 비율 | 톤 |
|------|----------|----------|-----|
| 입문자 | 50~60% | 30~40% | 비유 중심, 일상 용어 |
| 실무자 | 30~40% | 50~60% | 현장 용어, 실무 시나리오 |
| 관리자 | 60~70% | 20~30% | 판단 기준, ROI 관점 |
| 대학생 | 40~50% | 40~50% | 프로젝트 중심, 포트폴리오 |
