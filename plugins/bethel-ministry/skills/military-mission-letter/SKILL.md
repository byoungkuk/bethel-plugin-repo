# 벧엘교회 선교편지 작성 스킬

## 기본 컨텍스트

- **사역자**: 군선교사 김병국 목사, 정인숙 사모
- **사역지**: 제1보병사단 포병여단 58포병대대 벧엘교회
- **대상**: 초신자 중심의 20대 초반 남자 군인(용사)들
- **수신자**: 후원교회, 후원자, 동역자, 중보기도 파트너
- **발행 주기**: 월 1회 (매월 말일 발송)
- **표제 성구**: "하나님은 우리의 피난처시요, 힘이시니, 환난 중에 만날 큰 도움이시라" (시 46:1) — 고정 사용

5. **이번 달 전역자** (이름 목록, 있을 경우)
6. **특별 기도제목** (개인/부대/사역 관련)

## 선교편지 구조 및 형식

### 헤더 (고정)
```
제 1보병사단 포병여단 58포병대대          [발행연도 N호]

벧엘교회 선교편지 ([연도]. [월]월 선교보고/기도요청)

하나님은 우리의 피난처시요, 힘이시니, 환난 중에 만날 큰 도움이시라 (시 46:1)
```

### 본문 구성 (총 5~7개 단락)

#### 1. 인사말 + 계절/상황 묘사 (1~2문단)
- 짧고 감각적인 계절 묘사로 시작
- 사역지의 현재 분위기나 감사 포인트를 자연스럽게 연결
- "샬롬" 또는 "샬롬, 주님의 평강으로 인사드립니다"로 시작

#### 2. 이달의 주요 사역 (2~4개 소제목 단락)
- 각 단락은 **소제목** + 본문으로 구성
- 소제목은 사역의 본질을 시적으로 포착 (예: "여름나기, 함께하기" / "성례식, 그 소중함을 전하며")
- 구체적인 에피소드와 감동 포인트 포함
- 출석 인원은 인사말 또는 첫 번째 사역 단락에 괄호로 삽입 (예: 7월 예배인원: 53-52-49-74명)

#### 3. 후원에 대한 감사 (선택, 1문단)
- 특정 후원자나 후원교회의 섬김이 있을 경우 **굵은 글씨**로 이름 표기
- 과도한 나열보다 따뜻한 감사의 마음을 담아 간결하게 작성

#### 4. 마무리 인사 (1문단)
- 동역자들에 대한 감사
- 다음 달에 대한 소망이나 결단
- 수신자의 건강과 평안을 위한 기도 언급
- 날짜와 서명으로 마무리

```
[연도]년 [월]월 [일]일, 군선교사 김병국 목사, 정인숙 사모 올림
```

#### 5. 중보기도 요청 (고정 섹션)
```
[ 중보기도를 부탁드립니다 ]

1. [월]월 중 등록새신자 총 N명 : (이름1, 이름2, ...) - 전입신병들이 부대와 교회에 잘 적응할 수 있도록…
2. [세례자가 있을 경우] [월]월 세례자 총 N명 : 이름1, 이름2 - 하나님의 자녀로 꾸준히 신앙생활 이어갈 수 있도록…
3. [전역자가 있을 경우] [월]월 전역자 총 N명 : 이름1, 이름2 - 지역교회에 잘 연결되어 신앙생활 잘 이어갈 수 있도록…
4. 용사들이 근무하는 동안 안전사고 없이, 건강하게 군복무에 임할 수 있도록…
5. [이달 특별 사항에 맞는 기도제목]
6. 끝으로 군선교사명을 잘 감당할 수 있도록 저희 가정의 건강과 영성을 위해 기도 부탁드립니다 -끝-
```

## 문체 및 톤 가이드

### 핵심 문체 원칙
- **따뜻하고 진솔하게**: 어렵고 힘든 현실도 감사와 소망으로 승화시켜 표현
- **구체적이고 생생하게**: 추상적인 사역 보고가 아니라 실제 에피소드와 장면으로 전달
- **단문 중심**: 긴 복문보다 짧고 명료한 문장의 연속
- **군선교 특수성 반영**: 잦은 전역, 인원 교체, 근무로 인한 불참 등 군대의 특수한 상황을 자연스럽게 녹여냄
- **소망의 언어**: 현재의 어려움도 하나님의 섭리 안에서 의미있게 해석

### 자주 사용되는 표현 패턴
- "조금 친해지고 알만하면 전역합니다" → 군선교의 어려움을 표현하는 전형적 문장
- "복음의 씨앗이 이들의 마음속에 심겨진 채 전국 곳곳에 흩어질 수 있기를" → 군선교의 소망
- "이열치열의 원리" 식의 생활 속 철학적 표현 환영
- 이야기체 구어 표현 (예: "그래, 이 맛이야! 이 맛에 군선교를 하는 거지!")
- 독자에게 묻는 형식 (예: "빈 자리들이 말해주는 것은 무엇일까요?")

### 피해야 할 표현
- 과도한 신학 용어나 설교체 문장
- 수치 나열 중심의 딱딱한 보고서 문체
- 성과 중심의 자랑식 표현
- 지나치게 긴 복문

## 소제목 작성 원칙

소제목은 단순 사역 나열이 아니라 그 달의 핵심 경험을 **시적이고 인상적으로** 압축해야 한다.

| 사역 내용 | 좋은 소제목 예시 |
|-----------|-----------------|
| 여름 무더위 중 섬김 | 여름나기, 함께하기 |
| 세례식과 성찬식 | 성례식, 그 소중함을 전하며 |
| 해외 선교지 방문 | 선교현장을 품다, 태국 치앙마이 방문 |
| 새신자 등록 | 새신자들, 소중한 영혼들 |
| 가정의 달 이벤트 | 사랑을 전하다, 부모님께 드리는 편지 |

## 출석 통계 표기 형식

예배 출석 인원은 주별로 붙임표(-)로 연결하여 표기:
```
(예: 7월 예배인원: 53-52-49-74명)
(예: 8월 출석통계: 54-53-70-50-59)
```
월에 따라 주 수가 다를 수 있으므로 입력받은 숫자 그대로 적용.

## 품질 체크리스트

작성 완료 후 다음 항목을 점검하라:

- [ ] 헤더 형식 (호수, 표제 성구) 정확히 반영되었는가
- [ ] "샬롬"으로 시작하는 인사말인가
- [ ] 소제목이 2개 이상 포함되어 있는가
- [ ] 출석 인원이 본문에 삽입되었는가
- [ ] 구체적인 에피소드가 1개 이상 포함되어 있는가
- [ ] 후원에 대한 감사가 자연스럽게 녹아 있는가
- [ ] 날짜와 서명이 정확한가
- [ ] 중보기도 섹션이 정해진 형식으로 작성되었는가
- [ ] 새신자/전역자/세례자 명단이 기도제목에 포함되었는가
- [ ] 사역자 가정을 위한 기도제목이 마지막에 포함되었는가
- [ ] 전체 길이: A4 1페이지 내외 (너무 짧거나 길지 않은가)
