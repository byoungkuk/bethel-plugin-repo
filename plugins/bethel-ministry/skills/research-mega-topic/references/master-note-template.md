# 마스터 노트 템플릿

대주제 폴더 안에 1개 생성되는 인덱스 노트의 표준 구조.

## 파일 위치
`{베이스경로}/{대주제}/{대주제}.md`

## 전체 템플릿

```markdown
---
title: "{대주제}"
date: {YYYY-MM-DD}
tags: [research, MOC, {주제태그1}, {주제태그2}]
status: in-progress
folder: "02 AI 리서치 노트/{대주제}"
research_depth: basic
sub_topics: 10
---

# {대주제}

## 개요

{대주제에 대한 2~3문장 정의 + 조사 동기}

## 조사 범위

- {범위 항목 1}
- {범위 항목 2}
- {범위 항목 3}
- {범위 항목 4}

- [ ] 02. {주제 제목 2} → [[R_02 {짧은 주제명}]]

- [ ] 06. {주제 제목 6} → [[R_06 {짧은 주제명}]]
- [ ] 07. {주제 제목 7} → [[R_07 {짧은 주제명}]]

## 시사점 (리서치 완료 후 작성)

```

## Step 5에서 채워 넣는 종합 시사점 구조

10개 R_ 노트 완료 후 "시사점" 섹션을 다음 구조로 작성한다.

```markdown
## 종합 시사점

10개 하위 주제를 통해 확인된 {대주제}의 핵심 그림은 다음과 같다.

**시장 구조**: {1문단 — A축 노트 핵심 종합}

**카테고리 분화**: {1문단 — B축 노트 핵심 종합}

**정의·대상**: {1문단 — C축 노트 핵심 종합}

**활용 영역**: {1~2문단 — D축 노트 핵심 종합}

**사례·워크플로우**: {1문단 — E축 노트 핵심 종합}

**비용·ROI**: {1문단 — F축 노트 핵심 종합}

**한국 시장 특성**: {1문단 — 한국 관점 종합}

**활용 우선순위 권장**: {1문단 — 1인 지식 노동자/홍작가 관점 추천}

## 진행 메모

- 생성일: {YYYY-MM-DD}
- 완료일: {YYYY-MM-DD}
- 리서치 깊이: basic 또는 deep
- 총 노트: 마스터 1 + 하위 주제 10
- 후속 활용: write-content·write-blog·book-writing 등 참조 자료로 활용 가능
```

## 체크박스 업데이트 규칙

R_NN 노트 작성 직후, 마스터 노트의 해당 줄에서 `- [ ]`를 `- [x]`로 변경한다.

```diff
- - [ ] 01. {주제} → [[R_01 ...]]
+ - [x] 01. {주제} → [[R_01 ...]]
```

Edit 도구의 정확한 문자열 치환을 사용한다. replace_all은 사용하지 않는다.

## YAML 필드 의미

| 필드 | 값 | 설명 |
|------|-----|------|
| title | 대주제 | 큰따옴표로 감쌈 |
| date | YYYY-MM-DD | 생성일 |
| tags | [research, MOC, ...] | MOC 태그 필수 |
| status | in-progress / done | Step 5에서 done으로 변경 |
| folder | 저장 폴더 경로 | 옵시디언 검색용 |
| research_depth | basic / deep | Step 1 결정값 |
| sub_topics | 10 | 고정값 |
