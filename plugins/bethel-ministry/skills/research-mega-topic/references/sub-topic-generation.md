# 10개 하위 주제 생성 가이드 (6축 프레임)

대주제를 6축으로 분해해 정확히 10개 하위 주제를 만든다.

## 6축 정의

### A. 시장·규모·트렌드 (1~2개)
- 시장 규모(USD/원), CAGR, 주요 플레이어
- 점유율 변동, 매출, ARR
- 글로벌·한국 분리 가능

**예시 주제**
- "{대주제} 글로벌 시장 규모와 성장률, 주요 플레이어"
- "{대주제} 한국 시장 동향과 점유율"

### B. 카테고리·지형도 (1~2개)
- 분류 체계, 카테고리 지형도
- 도구·서비스·솔루션 랜드스케이프
- 영역별 대표 플레이어 매핑

**예시 주제**
- "{대주제} 카테고리 지형도와 대표 도구"
- "{대주제} 분류 체계와 영역별 솔루션"

### C. 정의·대상·범위 (1개)
- 핵심 개념 정의
- 타깃 대상 구분
- 인접 개념과의 차이

**예시 주제**
- "{대주제} 정의와 시장 대상 변화"
- "{대주제} 핵심 개념과 인접 영역 구분"

### D. 활용 영역·대표 도구 (3~4개)
- 영역별 사용 시나리오
- 영역별 대표 도구·기능 비교
- 가장 비중이 큰 축 — 보통 3~4개 주제로 분할

**예시 주제** (대주제가 "AI 도구 시장"인 경우)
- "AI 글쓰기·콘텐츠 제작 도구 활용 영역"
- "AI 리서치·정보 수집 도구 활용 영역"
- "AI 이미지·영상 생성 도구 활용 영역"
- "AI 코딩·자동화 도구 활용 영역"

### E. 사례·워크플로우·패턴 (1~2개)
- 실제 사용자/기업 사례
- 워크플로우 패턴
- 도구 조합 사례

**예시 주제**
- "{대주제} 사용자 워크플로우 패턴 사례"
- "{대주제} 기업·1인 활용 사례"

### F. 비용·ROI·미래 전망 (1~2개)
- 가격대, 구독·요금제
- ROI 데이터, 비용 절감
- 향후 전망, 규제·이슈

**예시 주제**
- "{대주제} 구독·요금제 시장 트렌드와 ROI"
- "{대주제} 향후 전망과 주요 이슈"

## 분배 원칙

- **총합은 정확히 10개**
- D축(활용 영역)이 가장 비중이 크다 — 최소 3개 권장
- 대주제 성격에 따라 비율 조정:
  - 시장·산업 단위 → A·B·F 비중 ↑
  - 도구·기술 단위 → D·E 비중 ↑
  - 직무·인구 단위 → C·E 비중 ↑

## 분배 패턴 예시

### 패턴 1: 시장 중심 (산업 분석형)
- A 시장 규모: 2개
- B 카테고리: 1개
- C 정의: 1개
- D 활용 영역: 3개
- E 사례: 1개
- F 비용·전망: 2개

### 패턴 2: 도구 중심 (제품 분석형)
- A 시장 규모: 1개
- B 카테고리: 2개
- C 정의: 1개
- D 활용 영역: 4개
- E 사례: 1개
- F 비용·전망: 1개

### 패턴 3: 직무 중심 (페르소나 분석형)
- A 시장 규모: 1개
- B 카테고리: 1개
- C 정의: 2개
- D 활용 영역: 3개
- E 사례: 2개
- F 비용·전망: 1개

## 주제 작성 규칙

1. **명사형 제목**: 동사 끝맺음 금지 ("~의 활용 영역", "~의 시장 규모")
2. **30자 이내**: 길면 축약
3. **중복 금지**: 10개가 서로 다른 영역을 다루도록
4. **구체성**: "AI 도구"보다 "AI 글쓰기 도구"가 좋음

## 자가 점검 체크리스트

10개 주제 생성 후 다음을 점검한다.

- [ ] 정확히 10개인가
- [ ] 6축 모두 최소 1개 이상 포함되었는가
- [ ] 주제 간 중복이 없는가
- [ ] 각 주제가 독립적으로 리서치 가능한가
- [ ] 대주제와 명확히 연결되는가
