# 폴더·파일명 규칙

자동 생성 시 적용되는 경로·파일명 규칙.

## 기본 베이스 경로

```
~/Documents/Obsidian Vault/02 AI 리서치 노트/
```

홍작가 옵시디언 볼트의 리서치 노트 허브.

## 폴더 생성 규칙

### 폴더명
- 대주제(megatopic) 그대로 사용
- 한글·공백 허용
- 30자 이내 권장 (긴 경우 사용자에게 짧은 폴더명 제안)

### 경로 예시
```
~/Documents/Obsidian Vault/02 AI 리서치 노트/2026년 AI 도구 시장과 개인 지식 노동자가 활용하는 영역/
```

### 중복 처리
- 동일 이름 폴더가 이미 존재하면 사용자에게 묻는다.
  1. 기존 폴더에 덮어쓸지 (위험 — 추천 안 함)
  2. 새 폴더명을 변경할지 (예: 끝에 "(2)" 추가)
  3. 작업 중단

## 파일명 규칙

### 마스터 노트
- 형식: `{대주제}.md`
- 폴더명과 동일한 이름 사용
- 옵시디언 위키링크 매칭에 유리

### 하위 노트 (R_NN)
- 형식: `R_{NN} {짧은 주제명}.md`
- NN: 두 자리 숫자 (01~10), zero-padded
- 짧은 주제명: 30자 이내
- 공백 허용
- 폴더 내 R_NN 중복 금지

### 짧은 주제명 생성 규칙

원래 하위 주제 제목에서 다음을 제거하거나 축약한다.

| 제거 대상 | 예 |
|-----------|-----|
| 연도 | "2026년" |
| 한정사 | "글로벌", "국내", "최신" |
| 부가어 | "에 대한", "관련된", "분석" |
| 조사 | "와", "과", "의" 일부 |

**변환 예시**

| 원본 | 짧은 주제명 |
|------|-------------|
| 2026년 글로벌 AI 도구 시장 규모와 주요 플레이어 | 2026년 글로벌 AI 도구 시장 규모와 주요 플레이어 |
| AI 도구 카테고리 지형도 (글쓰기·이미지·영상·코딩·에이전트·리서치) | AI 도구 카테고리 지형도 |
| 개인 지식 노동자(솔로프리너·1인 전문가) 정의와 시장 규모 변화 | 개인 지식 노동자 정의와 시장 규모 |

## 파일 생성 순서

1. 폴더 생성
2. 마스터 노트 생성 (status: in-progress)
3. R_01 ~ R_10 순차 생성 (각 생성 직후 마스터 체크박스 [x] 업데이트)
4. 마스터 노트 status를 done으로 변경 + 종합 시사점 작성

## 옵시디언 위키링크 호환성

- 위키링크는 `[[파일명 (확장자 제외)]]` 형식
- 파일명에 특수문자(`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`)가 들어가지 않도록 한다
- 한글·공백·괄호·하이픈은 허용

## 사용자 지정 경로

사용자가 다른 폴더를 지정하면 베이스 경로를 교체한다.

| 입력 예시 | 적용 경로 |
|-----------|-----------|
| "03 주제별 작업 노트/AI트렌드/" | ~/Documents/Obsidian Vault/03 주제별 작업 노트/AI트렌드/{대주제}/ |
| "외장 폴더 ~/Desktop/리서치/" | ~/Desktop/리서치/{대주제}/ |
| 미지정 | ~/Documents/Obsidian Vault/02 AI 리서치 노트/{대주제}/ |
