# R_ 하위 노트 템플릿

R_01~R_10 각 노트에 적용되는 표준 구조.

## 파일 위치·이름
`{베이스경로}/{대주제}/R_{NN} {짧은 주제명}.md`

- NN: 01~10 (두 자리 zero-padded)
- 짧은 주제명: 30자 이내, 동일 폴더 내 중복 금지

## 전체 템플릿

```markdown
---
title: "{전체 주제명}"
date: {YYYY-MM-DD}
tags: [research, {대주제태그}, {세부태그1}, {세부태그2}]
status: done
folder: "02 AI 리서치 노트/{대주제}"
research_depth: basic
sources_count: {N}
parent: "[[{대주제}]]"
---

# {전체 주제명}

## 개요

{2~3문장 — 주제 정의 + 조사 범위}

## 핵심 내용

### {소제목 1}

{본문}

### {소제목 2}

{본문}

### {소제목 3}

{본문}

## 주요 수치·데이터

| 항목 | 수치 | 출처 |
|------|------|------|
| {지표 1} | {값} | {출처명} |
| {지표 2} | {값} | {출처명} |
| ... | ... | ... |

## 시사점

{2~3문장 — 후속 활용 방향, 1인 지식 노동자/홍작가 관점 권장}

## 출처

- [{소스 제목 1}]({URL}) (접근일 {YYYY-MM-DD})
- [{소스 제목 2}]({URL}) (접근일 {YYYY-MM-DD})
- [{소스 제목 3}]({URL}) (접근일 {YYYY-MM-DD})
```

## YAML 필드 의미

| 필드 | 값 | 설명 |
|------|-----|------|
| title | 전체 주제명 | 큰따옴표로 감쌈 |
| date | YYYY-MM-DD | 작성일 |
| tags | research + 주제태그 | 검색용 |
| status | done | 작성 완료 시 done |
| folder | 저장 폴더 경로 | 옵시디언 검색용 |
| research_depth | basic / deep | 마스터와 동일 |
| sources_count | 정수 | 인용 소스 수 |
| parent | [[{대주제}]] | 마스터 노트 위키링크 |

## 분량 가드레일

| 깊이 | 본문 분량 | 소스 수 |
|------|-----------|---------|
| basic | 1,500~2,500자 | 3~5개 |
| deep | 3,000~5,000자 | 10개 이상 |

## 작성 원칙

1. **사실 중심**: 의견 아닌 사실·데이터
2. **출처 명시**: 모든 핵심 주장에 출처 병기
3. **수치 포함**: 표로 정리, 천단위 콤마, 단위 명시
4. **소제목 활용**: 핵심 내용을 3~5개 소제목으로 분할
5. **문장**: 설명 중심, 능동형, 간결

## 문장 품질 기준

| BAD | GOOD |
|-----|------|
| 매우 혁신적인 기능 | 1회 입력으로 텍스트·이미지·코드 3종 동시 생성 |
| 빠르게 성장 중 | 2024년 12억 달러 → 2025년 28억 달러로 증가 (출처, 2025) |
| 다양한 분야 활용 | 교육·마케팅·법률 3개 분야 도입 사례 보고됨 |

## 자가 평가 체크리스트

작성 완료 후 순서대로 점검한다. 미달 시 해당 섹션만 재작성(최대 2회).

**1. AI 흔적**
- [ ] "혁신적인", "획기적인", "완벽한" 등 과장형 형용사 0건
- [ ] "~할 수 있다" 추측 표현 0건
- [ ] "매우", "쉽게", "빠르게" 등 모호 부사 0건

**2. 사실·출처**
- [ ] 출처 없는 수치·통계 0건
- [ ] 1년 이상 지난 소스를 최신 정보로 기술 0건

**3. 구조**
- [ ] 슬롯 구조 (YAML·개요·핵심 내용·수치·시사점·출처) 준수
- [ ] YAML 프론트매터 필드 누락 0건
- [ ] 분량 가드레일 범위 내

## 검색 쿼리 작성 가이드

각 R_ 주제에 대해 web_search 쿼리 3개를 다음 패턴으로 생성한다.

- **쿼리 1 (영문, 시장·통계 중심)**: "{topic} market size 2026 statistics"
- **쿼리 2 (영문, 도구·사례 중심)**: "{topic} tools comparison 2026 use cases"
- **쿼리 3 (한글, 한국 관점)**: "{한국어 주제명} 2026 한국 사례"

쿼리는 병렬 호출하여 시간을 줄인다.
