# 메가 리서치 워크플로우 (Research Mega Topic)

대주제 1개를 입력받아 10개 하위 주제로 분해한 뒤, 마스터 노트 1개와 R_ 하위 노트 10개를 한 번에 생성하는 자동화 워크플로우.

## 다른 리서치 스킬과의 차이

| 스킬 | 입력 | 출력 |
|------|------|------|
| research-topic | 주제 1개 | 노트 1개 |
| **research-mega-topic (이 스킬)** | **대주제 1개** | **마스터 1 + R_01~R_10 (총 11개)** |
| lecture-research | 강의 기획안 | 강의 목차 꼭지별 RL_ 노트 |
| book-research | 책 챕터 | 챕터별 압축 참조 카드 |
| bizplan-research | 사업 아이템 | 5종 BR_ 카드 (P/R/S/C/U) |

대주제·시장·산업 단위로 묶어 한 번에 정리해야 하는 리서치에 사용한다. 단일 주제는 research-topic으로 충분하다.

## 5단계 워크플로우

```
Step 1: 대주제 확인
  ↓
Step 2: 10개 하위 주제 생성 → 사용자 확정 (유일한 확인 지점)
  ↓
Step 3: 폴더 + 마스터 노트 생성 (체크박스 10개)
  ↓
Step 4: R_01~R_10 순차 작성 (작성 직후 마스터 체크박스 [x] 업데이트)
  ↓
Step 5: 마스터 노트 종합 시사점 작성 + status: done 마감
```

---

## Step 1: 대주제 확인

사용자 입력에서 다음을 파악한다.

1. **대주제(megatopic)**: 한 줄 문장 또는 키워드 묶음 (필수)
2. **리서치 깊이**: basic(기본) 또는 deep(딥)
   - "딥 리서치", "깊이 있게", "상세하게" 언급 시 deep
   - 별도 언급 없으면 basic
3. **저장 폴더**: 별도 지정 없으면 `02 AI 리서치 노트/{대주제}/`

**필수 입력 강제**: 대주제가 명확하지 않으면 Step 2로 넘어가지 않는다. 추측으로 진행하지 않는다.

**중복 폴더 처리**: 동일 폴더가 이미 존재하면 사용자에게 덮어쓸지·이름을 변경할지 묻는다.

---

## Step 2: 10개 하위 주제 생성 (유일한 확인 지점)

대주제를 6축 프레임으로 분해해 10개 하위 주제를 생성한다.

### 6축 분해 프레임

| 축 | 주제 수 | 내용 |
|----|---------|------|
| A. 시장·규모·트렌드 | 1~2 | 시장 규모, 성장률, 주요 플레이어 |
| B. 카테고리·지형도 | 1~2 | 분류 체계, 도구·서비스 지형도 |
| C. 정의·대상·범위 | 1 | 핵심 개념, 타깃, 정의 구분 |
| D. 활용 영역·대표 도구 | 3~4 | 영역별 사용 시나리오, 대표 도구 |
| E. 사례·워크플로우·패턴 | 1~2 | 실제 사용 사례, 워크플로우 |
| F. 비용·ROI·미래 전망 | 1~2 | 가격, 구독, ROI, 향후 전망 |

총합이 정확히 10개가 되도록 조정한다. 대주제 성격에 따라 축별 비율을 유연하게 조정한다.

### 출력 형식 (사용자 확인용)

```
대주제: {입력 그대로}

10개 하위 주제 (리서치 단위)
1. {축A 1번}
2. {축A 2번 또는 축B 1번}
3. ...
10. ...

저장 구조 제안
02 AI 리서치 노트/
└── {대주제}/
    ├── {대주제}.md            ← 마스터 노트
    └── R_01 ... R_10 *.md     ← 하위 노트 10개
```

이어서 1가지 질문만 한다.

> 위 10개 주제 그대로 진행할까요? 조정이 필요한 항목이 있으면 알려주세요.

사용자가 수정 요청하면 반영 후 재확정한다. **확정 전에는 폴더·파일을 만들지 않는다.**

자세한 6축 활용 가이드는 `references/sub-topic-generation.md` 참조.

---

## Step 3: 폴더 + 마스터 노트 생성

### 경로 규칙

| 항목 | 규칙 |
|------|------|
| 기본 베이스 | `~/Documents/Obsidian Vault/02 AI 리서치 노트/` |
| 폴더명 | 대주제 그대로 (한글·공백 허용) |
| 마스터 노트 파일명 | `{대주제}.md` |
| 하위 노트 파일명 | `R_{NN} {짧은 주제명}.md` (NN: 01~10) |

### 마스터 노트 구조

`references/master-note-template.md`의 템플릿을 사용한다. 핵심 구성:

- YAML 프론트매터 (status: in-progress, sub_topics: 10)
- 개요 (대주제 정의, 조사 범위)
- 10개 하위 주제 진행 상태 (체크박스 + 위키링크)
- 종합 시사점 (Step 5에서 채움)
- 진행 메모

체크박스 줄 형식:

```markdown
- [ ] 01. {하위 주제 제목} → [[R_01 {짧은 주제명}]]
```

---

## Step 4: R_01~R_10 순차 작성

10개 하위 주제를 1번부터 10번까지 순차 처리한다.

### 각 하위 주제 처리 절차

1. **검색 쿼리 3개 생성**: 영문 2 + 한글 1 또는 영문 1 + 한글 2 혼합
2. **web_search 병렬 호출**: 3개 쿼리 동시 실행
3. **소스 수집·검증**:
   - basic: 소스 3~5개
   - deep: 소스 10개 이상 (필요 시 web_fetch로 본문 정독)
4. **R_NN 노트 작성**: `references/sub-research-template.md` 템플릿 사용
   - 분량: basic 1,500~2,500자 / deep 3,000~5,000자
5. **마스터 노트 체크박스 업데이트**: 해당 줄 `- [ ]` → `- [x]`
6. **다음 주제로 이동**

### 자가 평가 루프 (각 R_ 노트 완료 후)

다음 항목을 점검하고 미달 시 해당 섹션만 재작성(최대 2회).

- 금지어 위반 0건 (혁신적인, 획기적인, 완벽한, 매우, 쉽게, 빠르게)
- 추상 형용사·모호 부사 0건
- 출처 없는 수치 기술 0건
- 슬롯 구조 준수 (YAML·개요·핵심 내용·주요 수치·시사점·출처)
- 분량 가드레일 범위 내

### 사용자 진행 상황 안내

각 R_ 노트 완료 시 "R_NN 완료" 한 줄로 보고. 장황한 중간 보고 금지.

---

## Step 5: 마스터 노트 마감

10개 R_ 노트 완료 후:

1. 마스터 노트 YAML `status: in-progress` → `status: done` 변경
2. "종합 시사점" 섹션 작성: 10개 노트의 핵심 발견을 6~8문단으로 통합
3. "진행 메모" 섹션에 완료일·총 노트 수 기록

종합 시사점은 다음 구조로 작성한다.

- 시장 구조 (1문단)
- 카테고리·지형 (1문단)
- 정의·대상 (1문단)
- 활용 영역·도구 (1~2문단)
- 사례·워크플로우 (1문단)
- 비용·ROI (1문단)
- 한국 시장 특성 (1문단)
- 활용 우선순위 권장 (1문단)

자세한 종합 시사점 구조는 `references/master-note-template.md` 참조.

---

## 산출물 안내

완료 후 사용자에게 다음을 보고한다.

```
리서치 완료.

생성 결과
- 마스터 노트 1개 + 하위 주제 노트 10개 (총 11개)
- 저장 폴더: 02 AI 리서치 노트/{대주제}/
- 마스터 노트 체크박스 10개 모두 체크 완료

[마스터 노트 열기](computer://...)

종합 핵심 — {2~3문장 요약}
```

장황한 후속 설명 금지. 마스터 노트 링크 + 한 줄 요약으로 끝낸다.

## Harness 블록

| 항목 | 값 |
|------|-----|
| 원문 보존 레벨 | L2 (균형형) — 직접 인용 시 큰따옴표 + 출처 |
| 생성-평가 분리 | 각 R_ 노트 작성 후 자가 평가 루프 (최대 2회 재작성) |
| 분량 가드레일 | basic R_ 1,500~2,500자 / deep R_ 3,000~5,000자 / 마스터 시사점 1,500~2,500자 |
| 사용자 확인 지점 | Step 2 (10개 주제 확정) 1회만 |

## 사용 예시

**기본 호출**
> "2026년 AI 도구 시장과 개인 지식 노동자가 활용하는 영역, 메가 리서치로 진행해줘"

→ 대주제 인식 → 10개 주제 생성·확인 → 폴더 생성 → R_01~R_10 작성 → 마스터 마감

**딥 모드**
> "AI 콘텐츠 마케팅 산업 동향, 딥 메가리서치로"

→ 동일 흐름, 각 R_ 노트 3,000~5,000자 + 소스 10+

**경로 지정**
> "이 주제로 메가 리서치, 폴더는 03 주제별 작업 노트/AI트렌드/에 저장"

→ 사용자 지정 경로 사용
