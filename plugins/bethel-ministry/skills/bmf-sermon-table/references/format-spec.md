## 최근 동향 (2023판 → 2026판 변화)

| 항목 | 2023판 | 2026판 (현행) |
|---|---|---|
| 표제어 정의 | 하단 M.I. 해설란에 산문 | 상단 **사전적 의미 / 복음적 전환** 2행 신설 |
| 정과 4본문 | 하단 해설란에 요약 | 상단 **창/시/롬(서신)/마(복음서) 4행** 신설 — 직인용+해설 |
| 연역적 설교 | 대지 서술문 | **선포문 정형화**: "주님은 ~ 말씀하십니다" (3대지+주제문 모두) |
| 귀납적 설교 | A~E 서술 | A~E 5단계에 **개념명(색 강조)+설명문** 구조 정착 |
| 네장면 설교 | Coram Deo/T/G/D/N/I/M/P1~4 혼재 | **T/G → T(본문) → T(주제) → D → N → I → M → P1~P4** 순서 고정 (Wilson TDNIM) |
| 우측 열 | "현상학적 전개식 프레임 잡기" — M1~M6 요약 | **"개념적 설교 형태으로(본문 읽기)"** — 무브별 산문 문단(설교 초안의 씨앗), 키워드 볼드 |
| 무브 수 | 6 고정 | 5~6 (1차라인 그대로) |

핵심 방향: 도표가 "분석 기록"에서 "설교 초안 직전 단계"로 진화했다. 우측 열 산문이 사실상 무브 초안의 압축본이다.

## 표 해부 (읽기 순서)

### ① 헤더행
`본문 : {복음서 장절} [ {구약} / {시편} / {서신} ] 절기: {절기명} [ YYYY. M. D. ] 작성자: 김 병 국 / 설아클래스 ⒸYYYY`
날짜는 예배일(주일). 정과 순서는 구약/시편/서신 고정.

### ② 좌측 세로 셀
메인아이디어 (붉은 대형 글자, 세로쓰기). 2~7자.

### ③ 사전적 의미 / 복음적 전환 (2행)
- 사전적 의미: 표제어의 일반 정의. 번호 나열 가능("1) ... 2) ..."). 1문장.
- 복음적 전환: 복음 안에서의 재정의. 1~2문장. 괄호 보충 가능(예: "(Coram Deo)").

### ④ 정과 4행 (창/시/롬/마 등 해당 주 문패)
각 행: 핵심 구절 직인용(절번호 괄호) + " / " + 한 줄 해설. 복음서 행은 2~3구절 인용 가능. 행당 1줄 이내.

### ⑤ ABIT 열 (성서, 신학, 목회적 / 개인-공동체)
- **A 블록 2~3개**: 본문 관찰·원어·석의 노트. 각 블록이 3대지 하나와 세로로 호응. 블록당 200~350자. 질문-답 구조 활용("~인가? ~이다").
- **B 블록 1개**: 적용점·신학 확장·반론 처리. 200~350자. "*" 목록 허용.
- **I 행**: 이미지·삽화 소재. 한 줄 (예: "그루터기의 움", "수차, 얼어붙은 강 Vs. 봄날 녹아 흐르는 강").
- **T 블록**: 신학적 주의점·경계선. "*" 목록 3~4개.

### ⑥ 개념 열
3대지 개념을 세로쓰기(각 A블록 옆에 배치) + 맨 아래 "주제문" 라벨 셀.

### ⑦ 연역적 설교(3대지) 열
번호 1~3 + 선포문. 형식: "주님은(하나님은) / {내용} / 말씀하십니다." 짧은 행갈이 리듬. 마지막에 주제문 선포문.

### ⑧ 귀납적 설교 열 (A~E 5단계)
각 셀 = **개념명**(강조) + 설명 2~5문장(40~120자).
흐름: A 현상(청중의 삶에서 출발) → B 본문 진입 → C 은혜 발견 → D 전환·확장 → E 소망/새 현실.

### ⑨ 네장면 설교 열 (위→아래 고정 순서)
| 칸 | 내용 | 분량 |
|---|---|---|
| T / G | 트러블 개념 / 그레이스 개념 (개념망 내 단어) | 각 1단어 |
| T | 본문 장절 | 1줄 |
| T | 주제문 압축 | 1문장 |
| D | 독트린 | 1단어~1구 (예: 섭리론, 성령론, 은총론) |
| N | 니즈 (청중 상태) | 1문장 |
| I | 지배 이미지 | 1구 |
| M | 미션 (실천) | 1문장 |
| P1~P4 | 세상트러블→성경트러블→성경은혜→세상은혜 | 각 1문장 |

P3·P4는 주님/하나님 주어. P1·P2는 사람들/종들 주어.

### ⑩ 개념적 설교 형태으로(본문 읽기) 열 — 우측
1차라인 무브 순서대로 5~6문단. 각 문단 = **무브 키워드**(볼드) + 산문 150~250자.
문체: 스피치체 단문. 현재형. 본문 장면 묘사 + 청중 연결. 무브 간 자연 연결(앞 문단 끝과 뒤 문단 처음이 이어짐).
이 열이 설교 초안(무브)의 씨앗이므로 가장 공들여 작성한다.

## 분량 총규격
표 전체가 A4 가로 1쪽. 셀 초과분은 행 높이를 밀어 쪽수를 넘길 수 있으므로 규격 상한을 넘기지 않는다.

### 서식 규칙 (필수)
템플릿 빈 셀의 잔존 서식은 9.5pt 볼드 — 본문을 그대로 넣으면 셀이 넘쳐 글자가 겹친다.
- **content_cells(7.5pt 일반, charPr 60) 적용 대상**: 사전적 의미·복음적 전환 값(0,4 / 1,4), ABIT 전체(8,2 / 13,2 / 16,2 / 19,2 / 23,2 / 25,2), 귀납 A~E(…,9), 네장면 문장 셀(11,11 / 12,11 / 14,11 / 15,11 / 16,11 / 18,11 / 21,11 / 22,11 / 26,11), 본문읽기 무브(…,13), 주제문 선포문(19,7)
- **템플릿 서식 유지**: 라벨, 개념(…,5), 선포문 1~3(8,7 / 13,7 / 16,7), 정과 4행(고유 5pt), T/G값·D값
- 분량 상한(7.5pt 기준): ABIT 블록 ≤200자 / 귀납 설명 ≤60자 / 본문읽기 산문 ≤150자 / 네장면 문장 ≤25자 / 복음적 전환 ≤55자. 넘으면 넣기 전에 압축한다.
