# Patch: lecture-review 체크리스트에 블루프린트 반영률 추가

## 변경 지점 1 — 점검 축 0 타깃 적합성 섹션 바로 아래에 신규 섹션 추가

### 추가 위치

`### 점검 축 0: 타깃 적합성 (Target Fit)` 섹션 바로 다음, `### 점검 축 1: 구조 흐름` 앞에 아래를 **신규 추가**한다.

### 추가할 내용

```
### 점검 축 0.5: 블루프린트 반영률 (Blueprint Fidelity)

lecture-blueprint의 BP_*.md가 있으면 슬라이드가 BP를 얼마나 충실히 반영했는지 점검한다. 이 축은 BP 입력이 있을 때만 실행한다.

| 점검 항목 | 기준 |
|----------|------|
| 제목 반영 | BP의 슬라이드 제목이 실제 슬라이드 제목과 일치 (대소문자·어미 허용 범위 내) |
| 핵심 메시지 반영 | BP의 핵심 메시지가 슬라이드 본문에 포함 (유사도 0.7 이상) |
| T-유형 일치 | BP에 지정된 T-유형대로 실제 슬라이드가 조판되었는가 |
| 시각 힌트 반영 | BP의 `[DIAGRAM/CHART/IMG]` 태그가 실제 시각 자료로 구현되었는가 |
| 증거 반영 | BP의 증거·소재가 슬라이드에 실제로 등장하는가 |

**반영률 산출**: 위 5개 항목 × 슬라이드 수 기준. 각 슬라이드마다 5개 중 몇 개가 통과했는지 집계 후 전체 평균.

| 반영률 | 판정 |
|-------|------|
| 90% 이상 | 통과 — BP 충실 구현 |
| 70~89% | 경고 — 주요 슬라이드 일부 편차 |
| 70% 미만 | 실패 — BP 재실행 권장 |

BP가 없으면 이 축은 "해당 없음"으로 표기한다.
```
