# T-유형 매칭 규칙 (강의디자인템플릿 v0.3)

각 슬라이드 내용에 따라 T-유형(Template Type)을 선택하는 기준. 강의디자인템플릿 v0.3의 10종 블록형 슬라이드와 1:1 대응한다.

## T-유형 전체 목록 (v0.3, 10종)

| T-유형 | 이름 | 용도 |
|--------|------|------|
| T-0 | 표지 | 강의 시작, 제목 + 연사 + 일시 |
| T-S | 섹션 구분 | Ch 시작, CHAPTER N + 대제목 + 프리뷰 카드 |
| T-1 | 3카드 번호 | 01·02·03 3개 항목 병렬 (가운데 Amber 강조) |
| T-2 | 2열 비교 | Before/After, 회색 vs Navy 헤더 + 체크 불릿 + CTA 바 옵션 |
| T-3 | STEP 카드 | 3~4 STEP, Navy 헤더 + 흰 본문 + Amber 포인트 |
| T-4 | 세로 번호 리스트 | 1~5 큰 원번호 + 제목·설명 (수직 배치) |
| T-5 | 대비 2열 강조 | 흰+Navy 테두리 vs Navy 풀필, 2개 도구·개념 대비 |
| T-Sum | 챕터 요약 | CHAPTER N SUMMARY + 큰 핵심 문장 + Navy 박스 Next |
| T-Fin | 마무리 | TODAY'S SUMMARY + 4카드 + Amber NEXT + Q&A |

## 내용별 매칭 규칙

### 슬라이드 내용 → T-유형

| 슬라이드 내용 | T-유형 | 근거 |
|---------------|--------|------|
| 강의 시작 | T-0 | 표지 전용 |
| Ch 시작 (섹션 전환) | T-S | 섹션 구분 전용 |
| 3개 항목 병렬 소개 | T-1 | 01·02·03 번호 카드 |
| Before/After 비교 | T-2 | 2열 비교 전용 |
| 두 관점·두 방식 비교 | T-2 | 같은 구조 |
| 단계별 절차 (3~4 STEP) | T-3 | STEP 헤더 + 본문 |
| 프로세스 흐름 | T-3 | 순차성 표현 |
| 순차 리스트 (1~5) | T-4 | 세로 번호 리스트 |
| 체크리스트 (1~5) | T-4 | 같은 구조 |
| 두 도구 장단점 강조 | T-5 | 대비 2열 강조 |
| 개념 vs 반례 대비 | T-5 | 한쪽이 더 강조될 때 |
| Ch 마무리·핵심 정리 | T-Sum | 큰 한 문장 + Next |
| 강의 전체 요약 | T-Fin | 4카드 + Q&A |

### 애매한 경우 판단 기준

- 항목이 **3개** → T-1 권장
- 항목이 **4개** → T-3 권장 (STEP 또는 카드 느낌)
- 항목이 **5개** → T-4 권장 (세로 번호)
- 비교 요소가 **2개**고 우열 없음 → T-2
- 비교 요소가 **2개**고 우열·강조 있음 → T-5
- **프로세스·단계** 강조 → T-3
- **나열·병렬** 강조 → T-1 또는 T-4
- 요약이 **Ch 단위** → T-Sum
- 요약이 **강의 전체** → T-Fin

## 강의 전체 배치 원칙

### 기본 배치 순서

```
T-0 표지
  ↓
T-S Ch1 섹션
  → T-1 / T-2 / T-3 / T-4 / T-5 (본문 5~8장, 3종 이상 혼합)
  → T-Sum Ch1 요약 (선택)
  ↓
T-S Ch2 섹션
  → 본문
  → T-Sum Ch2 요약 (선택)
  ↓
...
  ↓
T-Fin 마무리
```

### 비율 기준 (반일 4시간 기준, 30~40장)

- T-0: 1장 (고정)
- T-S: Ch 수만큼 (3~4장)
- T-1~T-5 본문: 25~32장 (전체의 70~80%)
- T-Sum: 0~4장 (선택, Ch 단위로)
- T-Fin: 1장 (고정)

### 피해야 할 배치

- T-1만 연속 3장 이상 (단조로움 → T-3·T-4·T-5 섞기)
- T-S 없이 Ch 전환 (청중이 전환을 인지하지 못함)
- T-Sum + T-Fin을 붙여 배치 (중복 느낌 → 둘 중 하나만 선택)
- T-0 다음 바로 T-1 (T-S 한 장 끼워서 Ch1 시작을 알림)
- 본문 슬라이드 전부 T-1·T-4 나열형으로만 구성 (비교·프로세스 없이 단조로움)

## 팔레트별 T-유형 특이 사항

- **darknavy 팔레트** (SNS·크리에이터): Amber 대신 Coral 페어 사용. T-1·T-3 포인트색이 Coral로 자동 변경됨
- **navy 기본 + 나머지 7종**: Amber 고정. T-유형 구조 동일
- 팔레트는 T-유형 배치 로직에 영향을 주지 않는다. 시각 톤만 바뀐다.
