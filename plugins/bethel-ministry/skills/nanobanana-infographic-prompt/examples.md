# 스타일별 실전 예시

각 스타일의 원고→추출→프롬프트 변환 과정을 보여준다. 프롬프트 작성 시 해당 스타일의 예시를 패턴으로 참조한다.

---

## 예시1: 스타일A (다이어그램형) — 프로세스형

**입력 원고**:

> AI 글쓰기 워크플로우는 5단계로 구성됩니다. 첫째, 글의 목적을 명확히 정의합니다. 누구를 위한 글인지, 어떤 행동을 이끌어낼 것인지를 먼저 정합니다. 둘째, 글의 구조를 설계합니다. 서론-본론-결론의 뼈대를 잡고 각 섹션에 들어갈 핵심 메시지를 배치합니다. 셋째, AI를 활용해 빠르게 초안을 작성합니다. 완벽한 글이 아닌 재료를 확보하는 단계입니다. 넷째, 초안을 사람의 관점에서 리라이팅합니다. 톤, 흐름, 논리를 점검하고 다듬습니다. 다섯째, 최종 검수를 거쳐 발행합니다.

**추출 결과**:
```
- 제목: "AI 글쓰기 5단계"
- 유형: 프로세스형
- 스타일: 다이어그램형 (추상적 단계 설명)
- 핵심 포인트:
  1. 목적 정의 — "독자·행동 설정"
  2. 구조 설계 — "뼈대·메시지 배치"
  3. 초안 작성 — "AI로 재료 확보"
  4. 리라이팅 — "톤·흐름·논리 점검"
  5. 최종 검수 — "발행 준비"
```

**출력 프롬프트**:
```
프로세스형 다이어그램형 인포그래픽 이미지를 생성해줘.

전체 레이아웃:
- 상단: 진한 파랑(#1565C0) 배경 띠 위에 제목 "AI 글쓰기 5단계"를 흰색 큰 텍스트로 배치
- 중앙: 연한 회색(#F5F5F5) 배경 블록 안에 5단계 플로우 배치

좌에서 우로 흐르는 5단계:
1단계: "목적 정의" — 과녁 아이콘, 설명: "독자·행동 설정"
2단계: "구조 설계" — 블록 아이콘, 설명: "뼈대·메시지 배치"
3단계: "초안 작성" — 연필 아이콘, 설명: "AI로 재료 확보"
4단계: "리라이팅" — 순환 화살표 아이콘, 설명: "톤·흐름·논리 점검"
5단계: "최종 검수" — 체크 아이콘, 설명: "발행 준비"

각 단계는 원형 번호 뱃지 + 아이콘 + 단계명 + 짧은 설명으로 구성.
단계 사이는 굵은 화살표로 연결.
각 단계 블록은 연한 파랑(#E3F2FD) 배경의 둥근 모서리 카드.
요소가 화면을 충분히 채우도록 각 단계 블록을 크게.

시각 스타일:
- 배경: #FFFFFF (Solid pure white, flat color, no shadows)
- 폰트: Noto Sans KR
- 스타일: 플랫 디자인, 미니멀하되 정보 밀도 높게
- 색상: 진한 파랑(#1565C0) 제목 배경, 연한 파랑(#E3F2FD) 카드, 진한 회색(#333333) 텍스트
- 가로세로 비율: 16:9
```

## 예시2: 스타일B (장면형) — 요약형

**입력 원고**:

> 스킬 없이 글을 쓸 때 벌어지는 일: 매번 같은 조건을 처음부터 입력해야 합니다. 톤은 합니다체, 분량 2000자, 소제목 3개, CTA 포함... 새 대화마다 다시 입력하고, 빠뜨리면 다른 결과물이 나옵니다. 같은 요청에도 결과물 톤이 매번 상이합니다. Claude는 이전 설정을 기억하지 못해 어제는 정중, 오늘은 캐주얼하게 처리합니다. 채널을 변경하면 조건을 전체 재설정해야 합니다. 블로그에서 페이스북으로 전환하면 행간, 클릭 유도, 댓글 설계 조건을 새로 입력해야 합니다. 프롬프트 관리가 또 하나의 업무가 됩니다. 조건을 메모장에 따로 저장하고, 매번 복사-붙여넣기를 반복합니다.

**추출 결과**:
```
- 제목: "스킬 없이 글쓸 때 벌어지는 일"
- 유형: 요약형 (4가지 문제 상황 나열)
- 스타일: 장면형 (구체적 문제 상황 묘사)
- 핵심 포인트:
  1. 매번 조건 재입력
  2. 톤 매번 상이
  3. 채널 변경 시 재설정
  4. 프롬프트 관리 업무
```

**출력 프롬프트**:
```
요약형 장면형 인포그래픽 이미지를 생성해줘.

전체 레이아웃:
- 상단: 진한 빨강(#C62828) 배경 위에 제목 "스킬 없이 글쓸 때 벌어지는 일"을 흰색 큰 텍스트로 배치
- 중앙: 4개 카드를 가로로 균등 배치

카드1 (연한 주황 배경):
- 장면: 스틱맨이 컴퓨터 앞에 앉아 키보드를 치는 모습. 화면에 긴 텍스트 목록이 보임. 말풍선에 "톤은 합니다체, 분량 2000자..."
- 제목: "매번 조건 재입력"
- 불릿 설명:
  · 새 대화마다 다시 입력
  · 빠뜨리면 다른 결과물

카드2 (연한 보라 배경):
- 장면: 스틱맨이 머리 위에 물음표를 띄우고, 양손에 서로 다른 톤의 문서 두 장을 들고 비교하는 모습. 한 문서는 "정중", 다른 문서는 "캐주얼" 표시.
- 제목: "톤 매번 상이"
- 불릿 설명:
  · 이전 설정을 기억 못함
  · 불명시 조건은 제각각

카드3 (연한 파랑 배경):
- 장면: 스틱맨이 "블로그" 문서에서 "페이스북" 문서로 화살표를 그리며 수정하는 모습. 두 문서 사이에 빨간 느낌표.
- 제목: "채널 변경 시 재설정"
- 불릿 설명:
  · 페이스북 전용 조건 새로 입력
  · 행간, 클릭 유도, 댓글 설계

카드4 (연한 녹색 배경):
- 장면: 스틱맨 주변에 종이 더미가 쌓여 있고, 스틱맨이 지친 표정으로 메모장에서 복사-붙여넣기를 하는 모습. 종이에 "PROMPT" 글자.
- 제목: "프롬프트 관리 업무"
- 불릿 설명:
  · 조건을 메모장에 따로 저장
  · 매번 복사-붙여넣기 반복

각 카드 상단에 번호 뱃지(1, 2, 3, 4).
카드마다 스틱맨의 동작과 소품이 모두 다르게.
요소가 화면을 충분히 채우도록 카드 크기를 크게.

시각 스타일:
- 배경: #FFFFFF (Solid pure white, flat color, no shadows)
- 폰트: Noto Sans KR
- 스타일: 플랫 디자인, 스틱맨 일러스트 중심, 정보 밀도 높게
- 색상: 진한 빨강(#C62828) 제목 배경, 연한 주황(#FFF3E0)/연한 보라(#EDE7F6)/연한 파랑(#E3F2FD)/연한 녹색(#E8F5E9) 카드 배경, 진한 회색(#333333) 텍스트
- 캐릭터: 스틱맨(stickman)
- 가로세로 비율: 16:9
```

## 예시3: 스타일C (비교형) — 구조형

**입력 원고**:

> 프롬프트를 매번 직접 입력하는 방식과 커스텀 스킬을 사용하는 방식의 차이가 큽니다. 직접 입력하면 매번 조건을 처음부터 작성해야 하고, 빠뜨리는 조건이 생기며, 결과물의 톤과 품질이 일정하지 않습니다. 작성 시간도 매번 30분 이상 소요됩니다. 반면 커스텀 스킬을 사용하면 조건이 자동 적용되고, 누락 없이 모든 규칙이 반영되며, 일관된 품질의 결과물이 나옵니다. 작성 시간은 5분 이내로 줄어듭니다.

**추출 결과**:
```
- 제목: "직접 입력 vs 커스텀 스킬"
- 유형: 구조형 (두 방식 비교)
- 스타일: 비교형 (대비 구조 명확)
- 핵심 포인트:
  좌측(직접 입력): 매번 조건 작성, 누락 발생, 품질 불일정, 30분 이상
  우측(커스텀 스킬): 조건 자동 적용, 누락 없음, 일관된 품질, 5분 이내
```

**출력 프롬프트**:
```
구조형 비교형 인포그래픽 이미지를 생성해줘.

전체 레이아웃:
- 상단: 진한 파랑(#1565C0) 배경 위에 제목 "직접 입력 vs 커스텀 스킬"을 흰색 큰 텍스트로 배치
- 중앙: 화면을 좌/우로 분할

좌측 영역 (연한 빨강(#FFEBEE) 배경) — "직접 입력":
- 제목: "직접 입력"
- 스틱맨이 지친 표정으로 긴 텍스트를 타이핑하는 모습
- 특징 4개 불릿:
  · 매번 조건 처음부터 작성
  · 빠뜨리는 조건 발생
  · 품질 들쭉날쭉
  · 소요 시간: 30분 이상

중앙: 큰 VS 표시

우측 영역 (연한 파랑(#E3F2FD) 배경) — "커스텀 스킬":
- 제목: "커스텀 스킬"
- 스틱맨이 환하게 웃으며 엄지를 치켜세우는 모습. 옆에 체크 리스트 아이콘
- 특징 4개 불릿:
  · 조건 자동 적용
  · 누락 없이 규칙 반영
  · 일관된 품질 유지
  · 소요 시간: 5분 이내

좌측은 빨강/회색 계열, 우측은 파랑/녹색 계열로 대비.
비교 항목 수를 좌우 동일하게 4개씩.
요소가 화면을 충분히 채우도록 각 영역을 크게.

시각 스타일:
- 배경: #FFFFFF (Solid pure white, flat color, no shadows)
- 폰트: Noto Sans KR
- 스타일: 플랫 디자인, 좌우 대비 구조, 정보 밀도 높게
- 색상: 진한 파랑(#1565C0) 제목 배경, 연한 빨강(#FFEBEE) 좌측, 연한 파랑(#E3F2FD) 우측, 진한 회색(#333333) 텍스트
- 캐릭터: 스틱맨(stickman)
- 가로세로 비율: 16:9
```

## 예시4: 스타일D (타임라인형) — 프로세스형

**입력 원고**:

> AI 글쓰기 도구의 발전 과정을 살펴봅시다. 2020년 GPT-3가 등장하면서 처음으로 사용 가능한 수준의 AI 글쓰기가 시작되었습니다. 2022년 ChatGPT가 출시되어 대중화의 문을 열었고, 2023년에는 Claude, Gemini 등 경쟁 모델이 등장하면서 선택지가 다양해졌습니다. 2024년에는 커스텀 GPT와 프로젝트 기능이 도입되어 개인화 시대가 열렸고, 2025년에는 Claude 커스텀 스킬처럼 워크플로우 자동화가 본격화되고 있습니다.

**추출 결과**:
```
- 제목: "AI 글쓰기 도구 발전사"
- 유형: 프로세스형 (시간 순서)
- 스타일: 타임라인형 (연도별 발전 과정)
- 핵심 포인트:
  1. 2020 — GPT-3 등장, AI 글쓰기 시작
  2. 2022 — ChatGPT 출시, 대중화
  3. 2023 — Claude·Gemini 등장, 경쟁 다양화
  4. 2024 — 커스텀 GPT, 개인화 시대
  5. 2025 — 커스텀 스킬, 워크플로우 자동화
```

**출력 프롬프트**:
```
프로세스형 타임라인형 인포그래픽 이미지를 생성해줘.

전체 레이아웃:
- 상단: 진한 보라(#6A1B9A) 배경 위에 제목 "AI 글쓰기 도구 발전사"를 흰색 큰 텍스트로 배치
- 중앙: 가로 시간축 배치

가로 시간축(직선) 위에 5개 마일스톤:
마일스톤1 (시간축 위, 연한 보라(#F3E5F5) 블록): "2020" + "GPT-3 등장" + 로봇 아이콘, 설명: "AI 글쓰기 시작"
마일스톤2 (시간축 아래, 연한 파랑(#E3F2FD) 블록): "2022" + "ChatGPT 출시" + 말풍선 아이콘, 설명: "대중화의 문"
마일스톤3 (시간축 위, 연한 녹색(#E8F5E9) 블록): "2023" + "경쟁 모델 등장" + 분기 화살표 아이콘, 설명: "선택지 다양화"
마일스톤4 (시간축 아래, 연한 주황(#FFF3E0) 블록): "2024" + "개인화 시대" + 사람 아이콘, 설명: "커스텀 GPT 도입"
마일스톤5 (시간축 위, 연한 핑크(#FCE4EC) 블록): "2025" + "워크플로우 자동화" + 톱니바퀴 아이콘, 설명: "커스텀 스킬 본격화"

마일스톤을 시간축 위/아래에 교차 배치하여 밀도 확보.
시간축 좌측에 "2020", 우측에 "2025" 시간 범위 표시.
각 마일스톤에 서로 다른 색상 배경.
요소가 화면을 충분히 채우도록 마일스톤 블록을 크게.

시각 스타일:
- 배경: #FFFFFF (Solid pure white, flat color, no shadows)

- 가로세로 비율: 16:9

## 예시5: 스타일E (데이터형) — 요약형

**입력 원고**:

> 커스텀 스킬 도입 전후의 성과를 비교하면, 글 작성 시간이 평균 30분에서 5분으로 83% 단축되었습니다. 결과물 재작성 비율은 60%에서 10%로 줄었고, 하루 생산 콘텐츠 수는 2개에서 8개로 4배 증가했습니다. 톤 일관성 평가 점수는 100점 만점에 45점에서 92점으로 올랐습니다.

**추출 결과**:
```
- 제목: "커스텀 스킬 도입 효과"
