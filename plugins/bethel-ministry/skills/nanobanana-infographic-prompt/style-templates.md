# 스타일별 상세 템플릿

각 스타일의 콘텐츠 영역 작성법을 유형(요약형/구조형/프로세스형)별로 제공한다. 프롬프트 작성 시 해당 스타일×유형 조합의 템플릿을 참조한다.

---

## 스타일A: 다이어그램형

아이콘 + 키워드 + 카드/화살표로 구성하는 도식 중심 스타일. 깔끔하고 정돈된 느낌. 스틱맨은 장식 역할(옆에 서 있거나 가리키는 정도).

### A-요약형

```
전체 레이아웃:
- 상단: 진한 색상 배경 띠 위에 제목을 흰색 텍스트로 배치
- 중앙: 연한 회색 배경 블록 안에 카드 배치

핵심 포인트 N개를 가로로 균등 배치:
1. "키워드" — 아이콘, 설명: "부가 설명", 하위 태그: "OOO", "OOO"
2. "키워드" — 아이콘, 설명: "부가 설명", 하위 태그: "OOO", "OOO"
...
각 카드는 서로 다른 연한 색상 배경, 좌상단에 번호 뱃지.
요소가 화면을 충분히 채우도록 카드 크기를 크게.
```

### A-구조형

```
전체 레이아웃:
- 상단: 진한 색상 배경 띠 위에 제목을 흰색 텍스트로 배치
- 중앙: 연한 회색 배경 블록 안에 구조 배치

[비교/분류/관계] 레이아웃:
- "요소A" — 아이콘, 설명: "부가 설명", 하위 태그: "OOO", "OOO", "OOO"
- "요소B" — 아이콘, 설명: "부가 설명", 하위 태그: "OOO", "OOO", "OOO"
...
각 카드마다 다른 연한 색상 배경, 좌상단에 번호 뱃지.
[배치 방향과 연결 방식 설명]
요소가 화면을 충분히 채우도록 카드 크기를 크게.
```

### A-프로세스형

```
전체 레이아웃:
- 상단: 진한 색상 배경 띠 위에 제목을 흰색 텍스트로 배치
- 중앙: 연한 회색 배경 블록 안에 플로우 배치

좌에서 우로 흐르는 N단계:
1단계: "키워드" — 아이콘, 설명: "부가 설명"
2단계: "키워드" — 아이콘, 설명: "부가 설명"
...
각 단계는 원형 번호 뱃지 + 아이콘 + 단계명 + 설명으로 구성.
단계 사이는 굵은 화살표로 연결.
요소가 화면을 충분히 채우도록 각 단계 블록을 크게.
```

## 스타일B: 장면형

스틱맨이 각 카드 안에서 **해당 상황을 행동으로 연기**하는 일러스트 중심 스타일. 생동감 있고 스토리텔링 느낌.

### 장면 설계 원칙

1. 각 카드에 스틱맨이 **서로 다른 동작·포즈·표정**으로 등장
2. 해당 내용을 상징하는 **소품**(컴퓨터, 문서, 화살표, 물음표 등) 배치
3. 카드 상단에 장면 일러스트, 하단에 **제목 + 불릿 포인트 설명**
4. 카드마다 시각적으로 다른 장면이 되도록 동작·소품·구도를 변화시킴

### 장면 묘사 작성 가이드

스틱맨의 동작은 구체적이고 시각적으로 구분되게 묘사한다.

| 피해야 할 묘사 | 좋은 묘사 |
|--------------|----------|
| "스틱맨이 작업하는 모습" | "스틱맨이 컴퓨터 앞에 앉아 키보드를 치는 모습. 화면에 긴 텍스트가 보임" |
| "스틱맨이 고민하는 모습" | "스틱맨이 머리 위에 물음표를 띄우고 두 장의 서로 다른 문서를 양손에 들고 비교하는 모습" |
| "스틱맨이 정리하는 모습" | "스틱맨이 여러 장의 종이를 허공에 흩날리며 정리하지 못하는 모습. 주변에 문서 더미" |
| "스틱맨이 성공하는 모습" | "스틱맨이 양팔을 들어 올리며 환호. 옆에 체크마크가 그려진 큰 화면" |
| "스틱맨이 발표하는 모습" | "스틱맨이 포인터를 들고 큰 화이트보드 앞에 서서 차트를 가리키는 모습. 아래에 청중 스틱맨 3명" |

### 불릿 설명 작성 규칙

- 1개 불릿당 한글 25자 이내
- 3개 이내로 제한
- 원고에서 해당 항목의 세부 내용을 압축

### B-요약형 / B-프로세스형

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: N개 카드를 가로로 균등 배치

카드1 (연한 OO색 배경):
- 장면: 스틱맨이 [구체적 동작 묘사]. [소품] 배치.
- 제목: "OOO"
- 불릿 설명:
  · OOO
  · OOO
  · OOO

카드2 (연한 OO색 배경):
- 장면: 스틱맨이 [다른 동작 묘사]. [다른 소품] 배치.
- 제목: "OOO"
- 불릿 설명:
  · OOO
  · OOO
  · OOO
...

각 카드 상단에 번호 뱃지(1, 2, 3...).
카드마다 스틱맨의 동작과 소품이 모두 다르게.
요소가 화면을 충분히 채우도록 카드 크기를 크게.
```

> 프로세스형은 카드 사이에 굵은 화살표를 추가하여 순서를 표현한다.

### B-구조형

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: N개 카드를 가로로 균등 배치

[각 카드에 비교 대상별 장면 배치 — 위 요약형 장면 패턴과 동일]
카드 간 vs 표시 또는 화살표로 비교·관계 표현.
```

## 스타일C: 비교형

**좌우 대비 또는 상하 대비**로 두 가지 이상을 비교하는 스타일. 차이점이 시각적으로 즉시 드러남.

### 비교형 작성 포인트

- 좌측은 부정적·기존·문제, 우측은 긍정적·새로운·해결로 배치
- 색상도 대비: 좌측 차가운 톤(회색·연한 빨강), 우측 따뜻한 톤(파랑·녹색)
- 비교 항목 수는 좌우 동일하게 맞춤
- 스틱맨 활용 시: 좌측 스틱맨은 부정적 동작(고개 숙임, 물음표), 우측은 긍정적 동작(엄지척, 환호)

### C-구조형 (대표)

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 화면을 좌/우로 분할

좌측 영역 (연한 OO색 배경) — "Before / A / 기존":
- 제목: "OOO"
- 아이콘 또는 장면
- 특징 3~4개 불릿:
  · OOO
  · OOO
  · OOO

중앙: 큰 VS 표시 또는 화살표(→)

우측 영역 (연한 OO색 배경) — "After / B / 새로운":
- 제목: "OOO"
- 아이콘 또는 장면
- 특징 3~4개 불릿:
  · OOO
  · OOO
  · OOO

좌측과 우측은 대비되는 색상.
요소가 화면을 충분히 채우도록 각 영역을 크게.
```

### C-요약형

좌우 분할 대신, **상단에 2~3개 비교 카드를 가로 배치**하고 각 카드 안에 장단점을 나열한다.

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: N개 비교 카드를 가로로 균등 배치

카드1 (OO색 배경):
- 제목: "옵션A"
- 장점 아이콘(✓): "OOO", "OOO"
- 단점 아이콘(✗): "OOO"

카드2 (OO색 배경):
- 제목: "옵션B"
- 장점 아이콘(✓): "OOO", "OOO"
- 단점 아이콘(✗): "OOO"
...

각 카드에 서로 다른 색상. 장점은 녹색, 단점은 빨간색으로 통일.
요소가 화면을 충분히 채우도록 카드 크기를 크게.
```

### C-프로세스형

좌측에 Before(기존 프로세스), 우측에 After(개선 프로세스)를 배치하고, 각 영역 안에 단계를 세로로 나열한다.

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 화면을 좌/우로 분할

좌측 (연한 회색 배경) — "기존 방식":
- 1단계: "OOO" — 아이콘
- 2단계: "OOO" — 아이콘
- 3단계: "OOO" — 아이콘
  단계 사이 아래로 향하는 화살표

중앙: 큰 화살표(→) 또는 "개선" 표시

우측 (연한 녹색 배경) — "새로운 방식":
- 1단계: "OOO" — 아이콘
- 2단계: "OOO" — 아이콘
- 3단계: "OOO" — 아이콘
  단계 사이 아래로 향하는 화살표

좌측은 회색/빨간 계열, 우측은 녹색/파랑 계열.
요소가 화면을 충분히 채우도록 각 영역을 크게.
```

## 스타일D: 타임라인형

**시간축** 위에 이벤트·단계를 배치하는 스타일. 과거→현재→미래 방향성이 명확.

### 타임라인형 작성 포인트

- 위/아래 교차 배치가 핵심 — 한쪽으로만 배치하면 절반이 비어 보임
- 마일스톤 수는 4~6개 적정
- 시점 표기: 연도, 단계명, "1주차/2주차" 등 원고에 맞게
- 각 마일스톤에 아이콘과 연한 색상 배경 블록 필수

### D-프로세스형 (대표)

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 가로 시간축 배치

가로 시간축(직선) 위에 N개 마일스톤:
마일스톤1 (시간축 위, 연한 OO색 블록): "시점" + "이벤트명" + 아이콘, 설명: "부가 설명"
마일스톤2 (시간축 아래, 연한 OO색 블록): "시점" + "이벤트명" + 아이콘, 설명: "부가 설명"
마일스톤3 (시간축 위, 연한 OO색 블록): "시점" + "이벤트명" + 아이콘, 설명: "부가 설명"
마일스톤4 (시간축 아래, 연한 OO색 블록): "시점" + "이벤트명" + 아이콘, 설명: "부가 설명"
...

마일스톤을 시간축 위/아래에 교차 배치하여 밀도 확보.
시간축 좌측 시작점과 우측 끝점에 시간 범위 표시.
각 마일스톤에 서로 다른 색상 배경.
요소가 화면을 충분히 채우도록 마일스톤 블록을 크게.
```

### D-요약형

시간축 없이, **가로 배열된 카드에 시점 뱃지**를 붙여 시간 흐름을 암시한다.

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: N개 카드를 가로로 균등 배치, 카드 사이에 점선 화살표

카드1 (연한 OO색 배경):
- 시점 뱃지: "1단계" 또는 "2020"
- 아이콘
- 제목: "OOO"
- 설명: "부가 설명"
...

카드 사이에 점선 화살표로 시간 흐름 표현.
각 카드에 서로 다른 색상, 좌상단에 시점 뱃지.
```

### D-구조형

시간축 위에 **카테고리별 레인(lane)**을 나눠 병렬 진행을 표현한다.

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 가로 시간축 + 상/하 레인

시간축 위에 가로 기간 표시:
상단 레인 (OO색) — "카테고리A":
  구간1: "이벤트명" + 설명
  구간2: "이벤트명" + 설명

하단 레인 (OO색) — "카테고리B":
  구간1: "이벤트명" + 설명
  구간2: "이벤트명" + 설명

레인별 다른 색상. 같은 시점의 이벤트는 수직으로 정렬.
```

## 스타일E: 데이터형

**숫자·비율·그래프**를 전면에 내세우는 스타일. 임팩트 있는 통계 전달에 최적.

### 데이터형 작성 포인트

- 숫자가 주인공 — 가장 크고 눈에 띄게
- 단위를 명확히: %, 배, 만, 건, 시간 등
- 보조 시각 요소(미니 차트, 화살표)로 데이터 방향성 표현
- 숫자가 없는 원고에서는 사용하지 않는다

### E-요약형 (대표)

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 핵심 데이터 카드를 가로로 균등 배치

데이터 카드 N개를 가로로 균등 배치:
카드1 (연한 OO색 배경):
- 큰 숫자: "OO%" (강조색, 매우 큰 폰트)
- 설명: "OOO"
- 보조 시각 요소: 파이차트 또는 상승 화살표 아이콘

카드2 (연한 OO색 배경):
- 큰 숫자: "OO배" (강조색, 매우 큰 폰트)
- 설명: "OOO"
- 보조 시각 요소: 막대그래프 아이콘

카드3 (연한 OO색 배경):
- 큰 숫자: "OO만" (강조색, 매우 큰 폰트)
- 설명: "OOO"
- 보조 시각 요소: 사람 아이콘 그룹
...

각 카드에 서로 다른 강조색. 숫자를 가장 크게 배치.
요소가 화면을 충분히 채우도록 카드 크기를 크게.
```

### E-구조형

좌우 또는 상하로 나눠 **두 데이터 세트를 비교**한다.

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 화면을 좌/우로 분할

좌측 (연한 OO색 배경) — "데이터셋A":
- 큰 숫자: "OO%" + 설명
- 큰 숫자: "OO건" + 설명
- 보조: 미니 막대그래프

중앙: VS 또는 비교 화살표

우측 (연한 OO색 배경) — "데이터셋B":
- 큰 숫자: "OO%" + 설명
- 큰 숫자: "OO건" + 설명
- 보조: 미니 막대그래프

대비되는 색상으로 차이를 강조.
```

### E-프로세스형

시간축 위에 **각 단계의 핵심 수치**를 큰 숫자로 배치한다.

```
전체 레이아웃:
- 상단: 진한 색상 배경 위에 제목을 흰색 큰 텍스트로 배치
- 중앙: 좌→우 흐름에 데이터 카드 배치

좌에서 우로 흐르는 N단계:
1단계: 큰 숫자 "OO%" + "단계명" + 설명 + 보조 아이콘
→ 화살표
2단계: 큰 숫자 "OO배" + "단계명" + 설명 + 보조 아이콘
→ 화살표
3단계: 큰 숫자 "OO만" + "단계명" + 설명 + 보조 아이콘

각 단계에 번호 뱃지. 숫자를 가장 크게.
단계 사이 굵은 화살표로 연결.
```

## 스타일F: 마인드맵형

**중심 개념에서 방사형으로 확산**되는 스타일. 하나의 개념에서 파생되는 요소들을 시각화.

### 마인드맵형 작성 포인트

- 가지 수는 3~6개 적정
- 각 가지에 하위 항목 2~3개
- 가지 색상을 모두 다르게 하면 구분이 명확
- 1depth·2depth로 계층 표현

### F-요약형 (대표)

```
전체 레이아웃:
- 상단: 제목을 화면 상단 중앙에 배치
- 중앙: 마인드맵 구조

화면 중앙에 큰 원형 블록:
- "핵심 개념" (큰 텍스트, 강조색 배경)

중심에서 N개 가지(branch)가 방사형으로 뻗음:
가지1 (OO색): "키워드" — 하위: "OOO", "OOO"
가지2 (OO색): "키워드" — 하위: "OOO", "OOO"
가지3 (OO색): "키워드" — 하위: "OOO", "OOO"
...

각 가지마다 다른 색상. 중심 원에서 가지로 굵은 연결선.
하위 항목은 가지 끝에 작은 원 또는 태그로 배치.
요소가 화면을 충분히 채우도록 가지를 넓게 펼침.
```

### F-구조형

중심에서 가지가 뻗되, **각 가지 안에 하위 분류 계층**을 2depth로 표현한다.

```
전체 레이아웃:
- 상단: 제목을 화면 상단 중앙에 배치
- 중앙: 계층형 마인드맵

화면 중앙에 큰 원형 블록:
- "핵심 개념" (큰 텍스트, 강조색 배경)

1depth 가지 N개:
가지1 (OO색): "카테고리A"
  2depth: "하위1" — 설명: "부가 설명"
  2depth: "하위2" — 설명: "부가 설명"
가지2 (OO색): "카테고리B"
  2depth: "하위1" — 설명: "부가 설명"
  2depth: "하위2" — 설명: "부가 설명"
...

1depth는 큰 원, 2depth는 작은 원. 연결선 굵기로 계층 구분.
```

### F-프로세스형

중심에서 가지가 뻗되, **가지 간에 시계 방향 순서**가 있음을 화살표로 표현한다.

```
전체 레이아웃:
- 상단: 제목을 화면 상단 중앙에 배치
- 중앙: 순환형 마인드맵

화면 중앙에 큰 원형 블록:
- "핵심 개념" (큰 텍스트, 강조색 배경)

시계 방향으로 N개 가지:
가지1 (12시 방향, OO색): "1단계 키워드" — 하위: "OOO", "OOO"
→ 시계 방향 곡선 화살표
가지2 (2시 방향, OO색): "2단계 키워드" — 하위: "OOO", "OOO"
→ 시계 방향 곡선 화살표
가지3 (5시 방향, OO색): "3단계 키워드" — 하위: "OOO", "OOO"
→ 시계 방향 곡선 화살표
가지4 (8시 방향, OO색): "4단계 키워드" — 하위: "OOO", "OOO"
→ 가지1로 돌아오는 곡선 화살표

가지 사이에 시계 방향 곡선 화살표로 순서 표현.
순환 구조가 명확하게 보이도록.
```
