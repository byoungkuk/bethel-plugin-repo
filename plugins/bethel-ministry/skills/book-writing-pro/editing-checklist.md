# 퇴고 체크리스트 (Editing Checklist)

이 파일은 `book-writing-pro` 스킬의 Phase 6(퇴고)에서 참조하는 3회 패스 편집 체크리스트다.

---

## Pass 1: 구조 편집 (Structural Edit)

| # | 점검 항목 | 상태 |
|---|----------|------|
| 1 | 전체 논지/스토리 아크가 처음부터 끝까지 논리적으로 흐르는가 | ☐ |
| 2 | 각 챕터가 명확한 목적을 가지고 전체 흐름을 전진시키는가 | ☐ |
| 3 | 페이싱이 균형 잡혀 있는가 (늘어지거나 급한 챕터 없는가) | ☐ |
| 4 | 도입부 훅(hook)이 설득력 있는가 | ☐ |
| 5 | 결말이 전제와 일관되고 만족스러운가 | ☐ |
| 6 | 각 장의 첫 문장이 "왜 필요한가"를 설명하는가 | ☐ |
| 7 | 설명 순서가 개념 → 판단 기준 → 적용 방식을 따르는가 | ☐ |
| 8 | 소제목이 행동·판단 중심 문장인가 (기능명 나열 아닌가) | ☐ |
| 9 | 각 챕터 말미에 실무 정리 블록이 있는가 | ☐ |
| 10 | 중복되거나 모순되는 챕터가 없는가 | ☐ |
| 11 | **이탈 징후 재점검**: 방법이 기준보다 앞서는 장은 없는가 | ☐ |
| 12 | **이탈 징후 재점검**: 감정적 동기부여가 논리를 앞서는 장은 없는가 | ☐ |
| 13 | **이탈 징후 재점검**: 읽고 나서 기준 변화 없이 "뭘 하면 되지?"만 남는 장은 없는가 | ☐ |
| 14 | **경험·사례가 논증 도구로 작동하는가**: 사례가 판단 기준과 무관하게 나열만 된 곳은 없는가 | ☐ |

---

## Pass 2: 문장 편집 (Line Edit)

| # | 점검 항목 | 상태 |
|---|----------|------|
| 1 | 문장이 명확하고 간결한가 (40~70자 기준) | ☐ |
| 2 | 문체와 톤이 전체적으로 일관되는가 | ☐ |
| 3 | Phase 1에서 결정된 종결어미(~다체 또는 ~합니다체)가 전 챕터에 통일되어 있는가 (혼용 없는가) | ☐ |
| 4 | 문단 간 전환이 자연스러운가 | ☐ |
| 5 | 단정적 서술을 사용하는가 ("가능하다" 대신 "이렇게 판단한다") | ☐ |
| 6 | 전문 용어가 독자 수준에 맞게 설명되어 있는가 (한글 → 영문 병기) | ☐ |
| 7 | 감정적/감탄형/과장 표현이 없는가 | ☐ |
| 8 | 문장 길이와 리듬에 변화가 있는가 | ☐ |
| 9 | 줄바꿈이 문단 단위로만 적용되는가 | ☐ |
| 10 | 핵심 기준·판단 포인트가 볼드 강조되어 있는가 | ☐ |
| 11 | **경험 문단의 서술 톤이 유형(직접경험/관찰/실패담 등)에 맞는가** | ☐ |

**금지어 점검** (`writing-principles.md` 참조, Pass 2에서 함께 실행):
1. "~할 수 있습니다"가 있는가
2. "매우, 쉽게, 빠르게"가 있는가
3. 형용사가 근거 없이 쓰였는가
4. 추상 명사가 문장 중심에 있는가
5. 판단이 드러나는가
6. 실행 기준이 있는가

---

## Pass 3: 교정 (Proofreading)

| # | 점검 항목 | 상태 |
|---|----------|------|
| 1 | 맞춤법·띄어쓰기 오류 수정 | ☐ |
| 2 | 문법·구두점 검증 | ☐ |
| 3 | 서식 일관성 (제목, 폰트, 간격) | ☐ |
| 4 | 이름, 날짜, 사실관계 일관성 | ☐ |
| 5 | 페이지 번호와 목차 일치 | ☐ |
| 6 | 모든 `[TODO]` 마커 해결 또는 제거 (유형별 확인) | ☐ |
| 7 | 인용·참조 서식 통일 (논픽션) | ☐ |
| 8 | 금지 표현 최종 점검 (기능 나열, 감상형, AI 대체 표현 등) | ☐ |
| 9 | 최종 글자 수 기록 | ☐ |
