# 경험·사례 뱅크 템플릿 (Experience Bank Template)

이 파일은 `book-writing-pro` 스킬의 Phase 2~4에서 참조하는 경험·사례 수집 가이드다.
새 책 프로젝트를 시작할 때, 이 템플릿을 복사하여 `experience-bank-{프로젝트명}.md`로 저장한다.

> **핵심 원칙:** 경험은 결론을 증명하기 위한 도구다. "좋은 이야기"가 아니라 "판단 기준을 뒷받침하는 증거"를 모은다.

---

## 경험 유형 정의

| 유형 | 설명 | 서술 톤 | 적합한 위치 |
|------|------|---------|------------|
| **직접경험** | 내가 했던 일, 겪은 상황 | 1인칭, 구체적 시간·장소·행위 묘사 | 판단 기준 제시 직전/직후 |
| **관찰사례** | 수강생, 클라이언트, 동료에게서 본 것 | 3인칭 관찰, 간접 인용 화법 | 문제 상황 제시, 독자 공감 |
| **실패담** | 시도했으나 안 된 것, 왜 안 됐는지 | 1인칭, 과정 서술 → 원인 진단 | 기준 재정의 전, "왜 흔들리는가" |
| **비교사례** | A 방식 vs B 방식을 해본 결과 | 대조 구조, 조건·결과 병렬 | 방법론 비교, 선택 기준 제시 |
| **전환점** | 생각이 바뀐 계기 | 1인칭, 이전 관점 → 계기 → 이후 관점 | 장 도입부, 관점 전환 |

## 작성 형식

챕터별로 아래 형식으로 기록한다. 모든 항목을 채울 필요 없다. 떠오르는 것만 기록하고, Phase 4에서 추가한다.

```
## Ch[번호]: [챕터 제목]

### 사례 1
- 유형: [직접경험 / 관찰사례 / 실패담 / 비교사례 / 전환점]
- 메모: [자유 형식 3~5줄. 핵심 상황만 적는다]
- 판단 기준: [이 사례가 증명하는 판단 기준 한 문장]
- 삽입 위치 제안: [소제목명 / 미정]
- 상태: [미삽입 / Phase 3 반영 / Phase 4 반영]

### 사례 2
- 유형:
- 메모:
- 판단 기준:
- 삽입 위치 제안:
- 상태:
```

## 작성 예시

```
## Ch3: 프롬프트는 명령이 아니라 설계다

### 사례 1
- 유형: 관찰사례
- 메모: 2024년 기업 강의에서 수강생 80%가 프롬프트를 "명령문"으로만 
  이해하고 있었다. "~해줘"만 반복. 구조(역할-맥락-조건-출력)를 
  보여주자 같은 도구에서 결과 품질이 달라졌다.
- 판단 기준: 프롬프트의 품질은 지시의 정확성이 아니라 맥락의 설계에 달려 있다.
- 삽입 위치 제안: "왜 같은 도구에서 결과가 다른가" 소제목
- 상태: 미삽입

### 사례 2
- 유형: 실패담
- 메모: 처음 프롬프트 강의를 만들 때, "좋은 프롬프트 예시 50개"를 
  나열하는 방식으로 설계했다. 수강생들이 예시를 따라 쓰기만 하고 
  응용하지 못했다. 기준 없이 예시만 주면 복사만 된다는 것을 확인.
- 판단 기준: 예시는 기준 이해 후에 제공해야 학습 전이가 일어난다.
- 삽입 위치 제안: "사례는 기준 뒤에 온다" 소제목
- 상태: 미삽입

## Ch7: 워크플로우 자동화의 단위

### 사례 1
- 유형: 비교사례
- 메모: 전체 자동화(입력→최종본 한번에) vs 단계별 자동화(입력→구조→초안→편집)를 
  모두 시도. 전체 자동화는 빠르지만 오류 발생 시 전체 재작업. 
  단계별은 느리지만 중간 점검이 가능해 최종 품질이 높았다.
- 판단 기준: 자동화의 단위는 "검증 가능한 크기"여야 한다.
- 삽입 위치 제안: 미정
- 상태: 미삽입
```

## 수집 타이밍

| 시점 | 작업 | 비고 |
|------|------|------|
| Phase 2 (목차설계) | 챕터별 떠오르는 사례 초벌 수집 | 강제하지 않음, 있는 것만 |
| Phase 3 (집필) | 초안 작성 중 떠오르는 사례 추가 | `[TODO-EXP]` 마커로 위치 표시 |
| Phase 4 (경험주입) | 초안을 읽고 추가로 떠오르는 사례 후삽입 | 경험 주입 입력 템플릿 사용 |

## 품질 체크

경험 뱅크 전체를 점검할 때 확인할 항목:

1. **유형 편중**: 한 가지 유형(예: 직접경험)에만 치우쳐 있지 않은가
2. **판단 기준 누락**: 메모만 있고 판단 기준이 비어 있는 사례는 없는가
3. **챕터 공백**: 사례가 하나도 없는 챕터가 있는가 → Phase 4에서 보완
4. **중복**: 동일 사례가 복수 챕터에 배정되어 있지 않은가
5. **비율**: 장르별 경험 비율 가이드(SKILL.md 참조)에 맞는가
