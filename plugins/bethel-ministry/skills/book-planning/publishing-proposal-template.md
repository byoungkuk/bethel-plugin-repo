# 출판 기획서 템플릿 (Publishing Proposal Template)

Phase 5에서 기획서를 작성할 때 이 템플릿 구조를 따른다. 용도(출판사 제안용/자가출판 계획용/내부 검토용)에 따라 섹션을 조정한다.

---

## 문서 구조

### 1. 제목·부제

가제 2~3안을 제시한다. 각 안의 방향성을 한 줄로 설명한다.

**제목 설계 기준:**
- 독자의 문제 또는 욕구를 반영한다
- 8~15자 내외. 길면 부제로 보완한다
- 부제는 구체적 대상·방법·범위를 명시한다

**예시:**
```
[안 1] 제목: AI로 책 쓰기 / 부제: 기획부터 출판까지, 1인 저자의 워크플로우
→ 방향: 실용 가이드, 전 과정 포괄

[안 2] 제목: 혼자 쓰는 시대 / 부제: AI 시대, 1인 저자가 알아야 할 집필 설계법
→ 방향: 트렌드 + 방법론

[안 3] 제목: 쓰기 전에 설계하라 / 부제: AI 활용 책쓰기의 기획 원칙
→ 방향: 관점 제시형, 기획 특화
```

---

### 2. 저자 소개

약력 나열이 아닌, "왜 이 사람이 이 책을 쓰는가"에 답하는 구조로 작성한다.

**구성 요소:**
- 이 주제에 대한 실무 경험 (연차·프로젝트·실적)
- 관련 저서·강의·콘텐츠 활동
- 이 책을 쓰게 된 직접적 계기 (1~2문장)

**분량:** 200~400자

---

### 3. 기획 의도

Phase 1 콘셉트를 확장한다. "왜 지금 이 책이 필요한가"를 설득력 있게 서술한다.

**구조:**
```
[현재 상황/문제] — 독자가 처한 상태, 시장의 공백
[이 책의 접근] — 기존과 다른 관점·기준
[기대 효과] — 이 책이 채우는 빈자리
```

**분량:** 300~500자
**톤:** 출판사 제안용은 시장성 강조, 자가출판용은 저자 관점 중심

---

### 4. 독자 대상

Phase 2 독자 프로필을 요약한다.

**필수 항목:**
- 핵심 독자 (1줄 정의)
- 확장 독자 (1줄 정의)
- 독자의 현재 상태와 이 책을 통한 변화 (2~3문장)

---

### 5. 시장 분석

Phase 2 시장 분석을 요약한다.

**필수 항목:**
- 카테고리 분류
- 유사서 3~5권 비교표 (제목 / 저자 / 핵심 내용 / 이 책과의 차이)
- 차별화 포인트 (1~2문장)
- 시장 타이밍 (1~2문장)

**유사서 비교표 양식:**

| 유사서 | 저자 | 핵심 내용 | 이 책과의 차이 |
|--------|------|-----------|---------------|
| 제목 1 | 저자 | 요약 | 차이점 |

---

### 6. 목차

Phase 3 목차를 전문 수록한다. 전체 흐름(도입→전개→심화→마무리)을 표기하고, 챕터 제목과 핵심 메시지를 함께 표시한다.

**양식:**

```
[도입부]
Ch 1. 챕터 제목 — 핵심 메시지
Ch 2. 챕터 제목 — 핵심 메시지

[전개부]
Ch 3. 챕터 제목 — 핵심 메시지
...

[심화부]
...

[마무리]
...
```

---

### 7. 챕터별 개요 요약

Phase 4의 전체 개요에서 핵심 논점과 소제목만 추출한 압축본.

**양식:**

```
Ch [번호]: [챕터 제목]
핵심 논점: (1문장)
소제목: 1. ... / 2. ... / 3. ...
```

각 챕터를 3~4줄로 압축한다. 기획서 전체 분량을 고려해 상세도를 조정한다.

---

### 9. 마케팅 포인트 (출판사 제안용)

자가출판 계획용·내부 검토용에서는 이 섹션을 생략하거나 간소화한다.

**구성:**
- 타깃 홍보 채널 (서점 카테고리, 온라인 커뮤니티, SNS 등)
- 저자의 기존 플랫폼과 독자층 (블로그 방문자, SNS 팔로워, 강의 수강생 등)
- 홍보 가능 자산 (기존 강좌, 커뮤니티, 미디어 접점)
- 연계 가능한 이벤트·시즈널 포인트
