# 참조 자료 팩 출력 템플릿

챕터별 참조 자료 팩의 표준 출력 포맷. Step 3에서 이 구조를 적용한다.

## 모드 선택 기준

| 모드 | 사용 시점 | 분량 | 슬롯 |
|------|----------|------|------|
| **A 모드** (기본형) | 집필 전 — 아직 원고가 없는 챕터 | 500~800자 | ①~⑤ |
| **B 모드** (확장형) | 집필 후 — 초안이 완성된 챕터 | 1,200~2,000자 | ①~⑥ |

사용자가 모드를 지정하지 않으면, 해당 챕터 원고 파일 존재 여부로 자동 판단한다.
- 원고 파일 있음 → B 모드
- 원고 파일 없음 → A 모드
- 사용자가 명시적으로 모드를 지정하면 그것을 따른다

## A 모드 템플릿 (기본형, 500~800자)

```markdown

- **챕터 제목:** [목차에서 가져옴]
- **리서치 방향:** [Step 1에서 정리한 조사 방향 1~2문장]
- **작가 관점 연결:** [book-perspective에서 이 챕터에 해당하는 관점. 없으면 생략]

## ① 핵심 팩트
1. [팩트 — 출처 또는 근거]
2. [팩트 — 출처 또는 근거]
3. [팩트 — 출처 또는 근거]

## ② 인용 가능 수치
- [수치] — [기관명, 발행년도, URL]
- [수치] — [기관명, 발행년도, URL]

## ③ 사례·레퍼런스

### [사례 1 제목]
- **요약:** [2~3문장, 사실 중심]
- **출처:** [URL 또는 서지 정보]
- **집필 활용:** [이 사례를 챕터 어떤 맥락에서 쓸 수 있는지 1문장]

### [사례 2 제목]
- **요약:** [2~3문장]
- **출처:** [URL 또는 서지 정보]
- **집필 활용:** [1문장]

## ④ 반론·주의점
- [오해/반론 내용] → [왜 오해인지, 또는 한계의 범위]

## ⑤ 관련 키워드
[키워드1], [키워드2], [키워드3], [키워드4]
```

## 템플릿 사용 규칙

### 공통 규칙 (A·B 모드 모두 적용)

1. **챕터 정보** — 작가 관점 선언 파일이 없으면 "작가 관점 연결" 행을 생략한다
2. **핵심 팩트** — 출처를 확인할 수 없으면 `[미확인]` 표시
3. **인용 가능 수치** — 출처 없는 수치는 포함하지 않는다
4. **사례** — "집필 활용" 또는 "원고 인용 위치" 메모를 반드시 포함한다. 이것이 없으면 집필·퇴고 시 사례를 어디에 쓸지 판단할 수 없다
5. **반론** — 1개 이상 반드시 포함한다. 반론이 없는 리서치는 불완전하다
6. **키워드** — 작가 관점 선언 glossary와 표기를 통일한다
7. **슬롯 순서** — ①→②→③→④→⑤(→⑥) 순서를 바꾸지 않는다

### A 모드 전용 규칙

1. **핵심 팩트** — 3개 최소, 5개 최대
2. **인용 가능 수치** — 2~3개
3. **사례** — 1~2개, 각 사례에 "집필 활용" 메모 포함
4. **전체 분량** — 500~800자. 초과 시 우선순위 낮은 항목 제거

### B 모드 전용 규칙

1. **핵심 팩트** — 4개 이상
2. **인용 가능 수치** — 3개 이상
3. **사례** — 2~3개, 각 사례에 "원고 인용 위치" + "검증 결과" 포함
4. **검증 결과** — 원고 서술과 출처 데이터를 대조한다. 불일치가 있으면 구체적 차이를 명시하고 퇴고 시 수정 방향을 제안한다
5. **⑥ 교차 인용** — 다른 챕터와 겹치는 개념·수치·사례를 1문장으로 정리한다. 중복 서술 방지와 챕터 간 연결 강화에 활용
6. **전체 분량** — 1,200~2,000자. 초과 시 우선순위 낮은 항목 제거
