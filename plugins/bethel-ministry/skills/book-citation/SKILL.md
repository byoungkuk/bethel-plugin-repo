# 원고 출처 표기 워크플로우 (Book Citation Workflow)

4단계 구조적 출처 표기 프로세스. 완성된 책 원고(챕터 또는 전체)를 입력받아 인용·참조 부분을 탐지하고, 선택한 표기 방식에 맞춰 출처를 삽입한다.

### 책쓰기 스킬(퇴고)과의 역할 구분

book-writing의 퇴고(Phase 4 Pass 3)는 "기존 출처 표기의 형식 통일 여부"를 점검한다. 이 스킬은 **출처가 필요한데 빠진 부분을 새로 찾아내고, 출처 정보를 수집·매칭하여 삽입하는** 작업을 담당한다. 퇴고 스킬은 "있는 출처의 형식 점검", 이 스킬은 "없는 출처의 발견·삽입"이다.

## 전체 흐름

```
Step 1: 표기 방식 선택 → Step 2: 인용·참조 탐지 → Step 3: 출처 정보 매칭·보완 → Step 4: 출처 삽입·참고문헌 생성
```

사용자의 현재 상태를 파악해 적절한 단계부터 시작한다.
- 원고만 있고 표기 방식 미정 → Step 1부터
- 표기 방식 지정 + 원고 제공 → Step 2부터
- 인용 목록이 이미 정리되어 있음 → Step 3부터
- 출처 정보가 모두 준비됨 → Step 4부터

## Step 1: 표기 방식 선택

사용자에게 다음 정보를 수집한다.

### 필수 수집 항목

1. **원고 파일**: 텍스트, .docx, 또는 대화창 붙여넣기
2. **작업 범위**: 챕터 단위 vs 전체 원고
3. **표기 방식**: 아래 5가지 중 선택

### 작업 범위별 처리 방식

| 범위 | 탐지 대상 | 참고문헌 위치 | 중복 처리 |
|------|----------|-------------|----------|
| 챕터 단위 | 해당 챕터 내 | 챕터 말미 또는 별도 저장 | 챕터 내 중복만 처리 |
| 전체 원고 | 전 챕터 스캔 | 책 말미 통합 (또는 장 말미 분리) | 전체 중복 통합·제거 |

- 사용자가 범위를 지정하지 않으면 입력된 원고 분량으로 판단한다

### 표기 방식 옵션

| # | 방식 | 본문 표기 | 목록 위치 | 적합 장르 |
|---|------|----------|----------|----------|
| 1 | 국내 실용서 | 괄호 표기 (저자, 연도) | 책 말미 참고문헌 | 실용서, 가이드북 |
| 2 | 국내 학술 (KCI) | 각주 (페이지 하단) | 책 말미 참고문헌 | 학술서, 교재 |
| 3 | APA 7th | 괄호 표기 (Author, Year) | References | 사회과학, 교육 |
| 4 | Chicago | 각주/미주 | Bibliography | 인문학, 역사 |
| 5 | 간략형 | 없음 | 장 말미 "참고 자료" 목록 | 에세이, 경험서 |

- 사용자가 방식을 지정하지 않으면 **"국내 실용서"를 기본값으로 제안**하되, 장르를 확인한 후 추천한다
- 각 방식의 상세 포맷은 `references/citation-styles.md`를 참조한다

### 추가 확인 사항

- **출처 목록 위치**: 책 말미 통합 vs 장(Chapter) 말미 분리
- **번호 체계**: 등장순 vs 가나다순/알파벳순
- **URL 표기**: 포함 vs 제외 (접속일 표기 여부)

### 산출물

표기 방식 확정 메모 (대화창 텍스트)

---

## Step 2: 인용·참조 탐지

원고를 스캔하여 출처 표기가 필요한 부분을 자동 탐지한다.

### 분할 스캔 규칙

- 원고가 **2챕터 이상**이면 챕터 단위로 순차 스캔한다
- 각 챕터 스캔 완료 시 해당 챕터의 탐지 결과를 즉시 보고한다
- 모든 챕터 스캔 완료 후 **통합 탐지 목록**을 제시한다
- 단일 챕터 원고는 한 번에 스캔한다

### 탐지 기준

> **상세 탐지 규칙과 경계 사례는 `references/detection-rules.md`를 참조한다.**

| # | 유형 | 탐지 신호 | 예시 |
|---|------|----------|------|
| 1 | 직접 인용 | 따옴표, 인용문 블록, "~라고 했다" | "AI는 도구가 아니라 파트너다"(홍길동, 2024) |
| 2 | 간접 인용 | 통계 수치, "~에 따르면", 연구 결과 언급 | 2024년 기준 국내 1인 출판 시장은 약 3,200억 원이다 |
| 3 | 도표·그림 참조 | "출처:", 표·그림 캡션 | [표 2-1] 연도별 AI 도구 사용률 (출처: KPIPA, 2024) |
| 4 | 법령·정책 참조 | 법률명, 시행령, 정책 문서명 | 저작권법 제28조에 따라... |
| 5 | 도구·서비스 참조 | 도구명 + 버전/URL 필요 여부 | Claude 3.5 Sonnet(Anthropic, 2024) |
| 6 | 타인 저작물 참조 | 책 제목, 논문 제목, 기사 제목 | 『AI 시대의 글쓰기』에서 제시한 기준에 따르면... |

### 탐지 프로세스

1. 원고 전체를 순차 스캔한다 (분할 스캔 규칙 적용)
2. 위 6가지 유형에 해당하는 부분을 표시한다
3. 각 항목에 **위치(챕터/페이지/문단), 원문 발췌, 유형 분류**를 기록한다
4. 이미 출처가 표기된 부분은 "기존 표기"로 분류하고, 형식 통일 대상에 포함한다

### 산출물

인용·참조 탐지 목록 (대화창 텍스트 — 표 형식)

```
| # | 위치 | 유형 | 원문 발췌 | 출처 상태 |
|---|------|------|----------|----------|
| 1 | Ch2 3문단 | 간접 인용 | "국내 1인 출판 시장은..." | 미표기 |
| 2 | Ch3 1문단 | 직접 인용 | "AI는 도구가 아니라..." | 미표기 |
| 3 | Ch5 표2-1 | 도표 참조 | "연도별 AI 도구 사용률" | 기존 표기 (형식 불일치) |
```

### 사용자 검수·수정

탐지 결과를 사용자에게 보여주고 확인을 받는다. 사용자가 항목을 **삭제·추가·유형 변경**하면 목록을 갱신한 뒤 Step 3으로 진행한다. 수정이 없으면 그대로 Step 3으로 진행한다.

## Step 3: 출처 정보 매칭·보완

탐지된 각 항목에 대해 출처 정보를 정리하고, 누락된 정보를 사용자에게 요청한다.

### 출처 정보 필수 항목

| 자료 유형 | 필수 항목 |
|----------|----------|
| 도서 | 저자, 제목, 출판사, 출판연도 |
| 논문 | 저자, 논문 제목, 학술지명, 권(호), 페이지, 연도 |
| 웹 자료 | 저자/기관, 제목, URL, 접속일 |
| 보고서 | 기관명, 보고서 제목, 발행연도, (URL) |
| 법령 | 법률명, 조항, (시행일) |
| 도구/서비스 | 도구명, 개발사, 버전(해당 시), (URL) |
| 뉴스/기사 | 기자명, 기사 제목, 매체명, 발행일, (URL) |

### 매칭 프로세스

1. **본문 추출**: 원고 텍스트 안에 이미 적혀 있는 출처 정보(저자명, 연도, 기관명, 제목 등)를 추출하여 정리한다. 외부 DB·ISBN 조회는 불가하다.
2. **웹 검색 보완**: 본문 추출만으로 불완전한 항목에 한해 웹 검색을 시도한다.
   - **검색 대상 조건**: 저자명+제목이 추출되었으나 출판사·연도 등 필수 항목이 누락된 경우, 또는 수치·통계의 원출처 확인이 필요한 경우
   - **사전 승인**: 검색 전 사용자에게 검색 대상 목록을 보여주고 승인을 받는다
   - **결과 처리**: 검색 결과는 "⚠️ 확인 필요" 상태로 분류하고, 사용자가 최종 확인한다
3. **사용자 확인 요청**: 다음 세 가지를 구분하여 사용자에게 보여준다.

```
✅ 확인 완료 (본문에서 추출 성공)
  - Ch2: KPIPA(2024), 『2024 출판산업 실태조사』, 한국출판문화산업진흥원

⚠️ 확인 필요 (웹 검색 후보 있음, 사용자 검증 필요)
  - Ch3: "AI는 도구가 아니라 파트너다" → 홍길동(2024)『AI 글쓰기의 기술』로 추정. 맞습니까?

❌ 출처 누락 (사용자 제공 필요)
  - Ch5: "국내 1인 출판 비율 23%" → 출처를 알려주세요
```

4. 사용자가 출처를 제공할 수 없는 항목은 다음 중 택1:
   - 해당 문장을 일반 서술로 변경 (출처 불필요하게)
   - `[출처 확인 필요]` 마커 삽입 후 유지
   - 해당 문장 삭제

### Step 4 진행 조건

**❌ 출처 누락 항목이 남아 있으면**, 모든 항목에 대해 처리 방침(일반 서술 변경 / 마커 삽입 / 삭제)이 확정된 후에만 Step 4로 진행한다. 처리 방침이 확정되지 않은 항목이 있으면 사용자에게 결정을 요청한다.

### 산출물

출처 정보 매칭 표 (대화창 텍스트)

## Step 4: 출처 삽입·참고문헌 생성

Step 1에서 확정한 표기 방식에 따라 원고에 출처를 삽입하고, 참고문헌 목록을 생성한다.

### 삽입 프로세스

1. **본문 내 표기 삽입**
   - 국내 실용서: 괄호 표기 삽입 → (저자, 연도)
   - KCI: 미주 형태로 삽입 (아래 "각주 방식 처리 규칙" 참조)
   - APA: 괄호 표기 삽입 → (Author, Year)
   - Chicago: 미주 형태로 삽입 (아래 "각주 방식 처리 규칙" 참조)
   - 간략형: 본문 변경 없음. 각 챕터 끝에 "참고 자료" 섹션을 추가하고, `references/citation-styles.md`의 간략형 포맷에 따라 목록을 삽입한다

2. **참고문헌 목록 생성**
   - 위치: Step 1에서 확정한 위치 (책 말미/장 말미)
   - 정렬: Step 1에서 확정한 순서 (가나다순/알파벳순/등장순)
   - 형식: `references/citation-styles.md`의 해당 방식 포맷 적용

3. **최종 점검**
   - 본문 표기와 참고문헌 목록의 1:1 대응 확인 (누락/불일치 검출)
   - 번호 체계 연속성 확인
   - 동일 출처 반복 참조 시 형식 통일 확인 (ibid., 같은 책, 앞의 책 등)

### 각주 방식 처리 규칙

KCI·Chicago 등 각주(footnote) 방식을 선택한 경우:
- .docx 생성 시 **미주(endnote) 형태**로 구현한다 (python-docx/docx-js의 각주 지원 제약)
- 원고 본문에는 위첨자 번호를 삽입하고, 챕터 말미 또는 책 말미에 번호별 출처를 나열한다
- 사용자에게 다음을 안내한다: "기술적 제약으로 미주 형태로 생성했습니다. Word에서 미주→각주 변환이 필요하면 [참조 탭 → 각주/미주 변환]을 사용하세요."
- 사용자가 대화창 텍스트 출력만 요청한 경우, 각주 형식 그대로 표기한다 (이 제약은 .docx 파일 생성에만 해당)

### 산출물

| 산출물 | 형식 | 파일명 |
|--------|------|--------|
| 출처 삽입 원고 | .docx | `citation-manuscript.docx` |
| 참고문헌 목록 | 원고 말미 섹션으로 포함 | (원고 파일에 통합) |
| 출처 표기 리포트 | 대화창 텍스트 | — |

출처 표기 리포트에는 삽입 건수, 유형별 분포, 미해결 항목 요약을 포함한다.
.docx 생성 전 반드시 `/mnt/skills/public/docx/SKILL.md`를 읽고 따른다.

### 수정 요청 대응

Step 4 완료 후 사용자가 개별 항목의 수정을 요청하면:
- 해당 항목만 본문 표기와 참고문헌 목록을 수정한다
- 번호 체계가 변경되면 후속 번호를 자동 재정렬한다
- 수정 완료 후 변경된 부분만 요약 보고한다

## 표기 방식 간 변환 규칙

기존 원고의 표기 방식을 다른 방식으로 전환할 때 적용한다.

1. **각주 → 괄호**: 각주에서 (저자, 연도) 추출 → 본문 괄호 삽입 → 각주 삭제
2. **괄호 → 각주**: 괄호 내용을 각주 전체 형식으로 확장 → 미주 형태로 이동
3. **장 말미 → 책 말미**: 각 장 목록 통합 → 중복 제거 → 재정렬
4. **책 말미 → 장 말미**: 본문 참조 기준으로 장별 분리 → 각 장 말미 배치
5. **방식 전체 전환** (예: KCI → 국내 실용서): Step 1에서 새 방식 확정 → 기존 출처 정보 유지한 채 Step 4를 재실행하여 포맷만 변환

## 주의사항

- 출처가 불확실한 정보를 임의로 채우지 않는다. 반드시 사용자에게 확인한다
- 웹 URL은 접속 가능 여부를 보장하지 않으므로, 접속일 표기를 권장한다
- 저작권법상 인용 요건(출처 명시, 정당한 범위, 공표된 저작물)을 안내하되, 법적 판단은 하지 않는다
- 동일 출처가 여러 챕터에 걸쳐 반복 참조될 경우, 약식 표기 규칙을 적용한다
