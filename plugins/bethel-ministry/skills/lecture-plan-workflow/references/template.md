# 강의안 템플릿 (Lecture Plan Template)

강의안 7개 섹션의 구조, 작성 규칙, 분량 기준을 정의한다.

---

## 용도별 섹션 매트릭스

용도에 따라 각 섹션의 포함 수준을 결정한다.

| 섹션 | 기업·기관 제안용 | 내부 기획용 | 플랫폼 등록용 | 특강·단발 제안용 |
|------|:---:|:---:|:---:|:---:|
| 1. 강의 제목 | 포함 | 포함 | 포함 | 포함 |
| 2. 강의 소개 | 포함 | 간략(1~2문장) | 포함 | 포함 |
| 3. 학습 목표 | 포함 | 생략 | 포함 | 간략(2~3개) |
| 4. 강의 대상 | 포함 | 포함 | 포함 | 포함 |
| 5. 강의 목차 | 포함 | 포함 | 포함 | 포함 |
| 6. 운영 방식 | 포함 | 간략(형태+도구만) | 간략(형태+도구만) | 간략(형태+도구만) |
| 7. 기대 효과 | 포함 | 생략 | 간략(1~2개) | 간략(1~2개) |

- **포함**: 해당 섹션의 작성 규칙을 모두 적용하여 전체 분량으로 작성
- **간략**: 괄호 안의 분량/항목 수로 축소하여 작성
- **생략**: 해당 섹션을 작성하지 않음

## 1. 강의 제목

### 구조

```
[강의 제목]
```

### 작성 규칙

- **주제 + 핵심 가치**를 한 문장에 담는다
- 길이: 15~30자 (너무 짧으면 모호, 너무 길면 산만)
- 제목만 보고 "무엇을 배우는가"를 판단할 수 있어야 한다
- 부제가 필요하면 콜론(:) 또는 줄바꿈으로 분리

### 제목 패턴

| 패턴 | 예시 | 적합한 경우 |
|------|------|-------------|
| **도구+행동형** | Claude로 채널별 글쓰기 자동화하기 | 도구 중심 실습 강의 |
| **대상+결과형** | 마케터를 위한 AI 콘텐츠 전략 설계 | 직군 특화 강의 |
| **문제+해결형** | 반복 업무를 줄이는 AI 워크플로우 설계 | 실무 효율화 강의 |
| **수준+주제형** | AI 이미지 생성 입문: 나노바나나 프로 활용 | 입문/초급 과정 |
| **핵심 키워드형** | AI 글쓰기 스킬 만들기(초급+) | 시리즈·레벨 표기 |

### 금지 패턴

- 과장형: "완벽 마스터", "한 방에 끝내는", "혁신적인"
- 모호형: "AI의 모든 것", "디지털 시대의 변화"
- 나열형: "ChatGPT, Claude, Gemini 활용법" (도구를 3개 이상 나열)

## 2. 강의 소개

### 구조

```
[강의 소개]
(3~5문장, 단락형)
```

### 작성 규칙

- **첫 문장**: 이 강의가 다루는 핵심 주제를 명시한다
- **중간 문장**: 왜 지금 이 주제가 필요한지 맥락을 설명한다 (시장 상황, 업무 변화, 수요 등)
- **마지막 문장**: 이 강의에서 구체적으로 무엇을 하는지 요약한다
- 분량: 3~5문장 (150~300자)
- "이 강의에서는~"으로 시작하지 않는다. 주제의 필요성부터 시작한다

### 작성 공식

```
[주제가 필요한 맥락 1~2문장]
+ [이 강의가 다루는 범위 1~2문장]
+ [수강 후 할 수 있는 것 1문장]
```

## 3. 학습 목표

### 구조

```
[학습 목표]
1. (행동 동사) + (대상) + (기준/수준)
2. ...
3. ...
```

### 작성 규칙

- 3~5개 항목 (시간에 비례: 2시간=3개, 4시간+=4~5개)
- 각 항목은 **행동 동사**로 시작한다
- 측정 가능한 결과를 기술한다

### 행동 동사 가이드

| 수준 | 동사 예시 | 사용 맥락 |
|------|-----------|-----------|
| **이해** | 구분한다, 설명한다, 비교한다 | 개념 학습 |
| **적용** | 작성한다, 설계한다, 구성한다 | 실습·제작 |
| **분석** | 판단한다, 평가한다, 선택한다 | 기준 수립 |
| **생성** | 만든다, 완성한다, 배포한다 | 산출물 제작 |

### 금지 패턴

- "~을 이해한다" 단독 사용 (기준 없는 이해는 측정 불가)
  - ❌ "AI 글쓰기를 이해한다"
  - ✅ "AI 글쓰기 도구 3종의 차이점을 구분한다"
- "~할 수 있다" (추측형)
  - ❌ "프롬프트를 작성할 수 있다"
  - ✅ "목적별 프롬프트를 3가지 이상 작성한다"

## 4. 강의 대상

### 구조

```
[강의 대상]
- 대상 직군/역할: ___
- 추천 수강자: (구체적 상황 2~3개)
- 사전 지식: ___
```

### 작성 규칙

- **대상 직군/역할**: 포괄적 범주 (마케터, 기획자, 교육 담당자 등)
- **추천 수강자**: 구체적 상황으로 서술 ("AI 도구를 처음 도입하려는 팀", "콘텐츠 제작 시간을 줄이고 싶은 1인 사업자")
- **사전 지식**: 필요 수준을 명확히 명시 ("없음", "기본 PC 활용 가능", "ChatGPT 사용 경험 있음" 등)
- "누구나 들을 수 있습니다"는 금지. 구체적으로 기술한다

## 5. 강의 목차

### 구조

```
[강의 목차]

Ch1. (챕터 제목) — (소요 시간)
  · (세부 항목 1)
  · (세부 항목 2)
  · (세부 항목 3)

Ch2. ...
```

### Ch 수 기준 (단회 강의)

| 총 강의 시간 | 권장 Ch 수 | Ch당 시간 |
|-------------|-----------|----------|
| 1~2시간 | 2~3개 | 30~50분 |
| 3~4시간 | 3~4개 | 45~60분 |
| 6시간+ | 4~6개 | 50~90분 |

### 다회차 강의 목차 규칙

다회차(예: 2시간 × 4회) 강의는 회차(Session) 단위로 묶고, 각 회차 안에 Ch를 배치한다.

**구조**

```
[1회차] (회차 주제) — (소요 시간)

Ch1. (챕터 제목) — (소요 시간)
  · (세부 항목 1)
  · (세부 항목 2)
  · (세부 항목 3)

Ch2. ...

[2회차] (회차 주제) — (소요 시간)
...
```

**배분 규칙**

- 회차당 Ch 수: 2~3개
- 각 회차의 시작 10분: 전회 복습 + 이번 회차 목표 안내 (2회차부터 적용)
- 각 회차의 마지막 5분: 정리 + 다음 회차 예고

**회차 간 흐름 설계**

| 회차 | 역할 | 키워드 |
|------|------|--------|
| 1회차 | 도입·기초 | 왜, 개념, 현황 |
| 2회차 | 핵심·적용 | 무엇을, 기준, 원리 |
| 3회차 | 심화·실습 | 어떻게, 설계, 제작 |
| 4회차+ | 종합·확장 | 직접 해보기, 피드백, 응용 |

회차 수가 3 이하이면 위 표에서 인접한 역할을 병합한다.
예: 3회차 과정 → 1회차(도입+기초), 2회차(핵심+적용), 3회차(종합+확장)

### 챕터 제목 규칙

- 행동·판단 중심 문장으로 작성
- ❌ "프롬프트 기초" → ✅ "좋은 프롬프트의 조건을 구분한다"
- ❌ "실습" → ✅ "나만의 글쓰기 스킬을 설계하고 테스트한다"

### 세부 항목 규칙

- 각 Ch에 3개 (필요 시 4개까지 허용)
- 구체적 행동·내용을 기술한다
- 기능명 단독 사용 금지 ("레이어 기능" → "레이어로 요소를 분리하는 기준")
- [실습] 태그: 실습 항목에는 앞에 [실습]을 표기한다

### 흐름 설계 원칙 (단회 강의)

```
Ch1: 왜 (필요성·맥락·현황)
Ch2: 무엇을 (핵심 개념·기준·원리)
Ch3: 어떻게 (적용 방법·실습)
Ch4: 직접 해보기 (종합 실습·피드백) ← 시간이 충분할 때
```

### 시간 배분 규칙

- 이론:실습 비율을 반영하여 시간 배분
- 실습 Ch에 전체 시간의 40~60% 배정 (도구 강의 기준)
- 도입(Ch1)에 전체의 15~20% 배정
- 각 Ch 시간을 분 단위로 명시 (예: 50분, 40분)

## 6. 강의 운영 방식

### 구조

```
[강의 운영 방식]
- 강의 형태: ___
- 이론:실습 비율: ___
- 사용 도구: ___
- 수강 환경: ___
- 교재/자료: ___
```

### 작성 규칙

- **강의 형태**: 오프라인/온라인(Zoom)/혼합/녹화 중 택
- **이론:실습 비율**: 수치로 표기 (예: 이론 40% : 실습 60%)
- **사용 도구**: 강의에서 쓰는 도구를 구체적으로 나열 (예: Claude, 나노바나나 프로, Google Docs)
- **수강 환경**: 필요 장비·조건 (예: 노트북 지참 필수, Wi-Fi 환경)
- **교재/자료**: 제공 여부와 형태 (예: PDF 핸드아웃 제공, 실습 템플릿 배포)

## 7. 기대 효과

### 구조

```
[기대 효과]
- (수강 후 변화 1)
- (수강 후 변화 2)
- (업무 적용 시나리오)
```

### 작성 규칙

- 2~4개 항목
- **변화 중심**: "~을 알게 된다"가 아니라 "~을 할 수 있게 된다" → "~을 한다"
- **업무 적용 시나리오**: 최소 1개는 구체적 업무 상황을 기술
  - ❌ "업무 효율이 높아진다"
  - ✅ "주 3회 블로그 글을 1시간 내에 초안까지 완성한다"
- 과장 금지: 수치를 쓸 때는 근거가 있어야 한다
