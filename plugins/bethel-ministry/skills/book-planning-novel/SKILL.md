# 소설 기획 워크플로우 (초보자 단계별)

50~60페이지 분량 소설(단편 1~2편 또는 중편 1편)의 사전 설계 워크숍. 본문 작성 전에 5가지 핵심 요소를 단계별로 결정한다. 1단계에서 무엇을 쓸지 소재부터 끌어내므로, 쓸거리가 없는 초보자도 백지에서 시작할 수 있다.

## 핵심 원칙

**1. 본문 작성으로 직진 금지**

사용자가 "소설 써줘", "이런 이야기 만들어줘", "글 작성해줘" 등 어떤 형태로 요청해도 즉시 본문을 만들지 않는다. 항상 사전 설계 5단계로 진입한다.

**2. 한 번에 한 단계씩**

5단계를 한 번에 던지지 않는다. 1단계 완료 → 사용자 확인 → 2단계 진입 순서.

**3. 보기 제시**

각 단계 첫 질문에 보기 3~6개를 제공한다. 초보자가 "백지에서 답해야" 하는 부담을 줄인다. 보기에 없으면 본인 표현으로 답할 수 있다고 명시.

**4. 답변 정리·확인**

사용자 답변을 받으면 정리해서 다시 보여준다. 사용자가 "맞다" 또는 수정 신호 주면 다음 단계.

**5. 1쪽 분량 산출물**

마지막에 기획안 1쪽 + 챕터·씬 골격을 한 번에 출력한다. 본문은 만들지 않는다.

---

## 시작 응답 템플릿

사용자의 첫 입력이 들어오면 다음과 같이 시작한다.

```
소설 기획을 시작합니다.

좋은 소설은 글을 쓰기 전에 5가지를 먼저 정해야 합니다.
바로 쓰기 시작하면 글이 산발적이거나 일관성을 잃기 쉽습니다.

쓸거리가 아직 없어도 됩니다. 1단계에서 소재부터 함께 찾습니다.

함께 단계별로 정해보겠습니다. (총 30~35분)

  1단계 — 소재 발굴 (무엇을 쓸지)
  2단계 — 장르·톤
  3단계 — 주인공 1~2명
  4단계 — 플롯 골격 (3막)
  5단계 — 작업 단위 (분량·챕터·씬)

준비되셨으면 1단계로 시작합니다.
```

사용자가 "응", "네", "ㅇㅋ" 등 동의 표시 시 1단계로. 다른 질문(예: "꼭 5단계 다 해야 하나요?")이 오면 답변 후 동의 받고 진입.

## 1단계 — 소재 발굴 (목표 5~7분)

무엇을 쓸지가 없는 상태에서 출발한다. 머릿속 씨앗 하나를 끌어내, "만약(What if)" 질문을 붙여 이야기의 전제(한 줄)로 바꾼다. 이 한 줄이 이후 모든 단계의 기준점이 된다.

### 첫 질문

```
[1단계 — 소재 발굴]

소설은 거창한 아이디어가 아니라 작은 씨앗 하나에서 시작합니다.
지금 머릿속에 남아 있는 것 중 가까운 것을 1~2개 골라주세요.
보기에 없으면 본인 표현으로 답하셔도 됩니다.

(a) 잊히지 않는 경험 한 조각 — 내가 겪은 일 중 오래 남은 장면
(b) 인상 깊은 한 컷 — 길에서·영화에서·꿈에서 본 장면
(c) 풀리지 않는 질문 — "왜 사람은 ~할까" 같은 의문
(d) 마음에 걸리는 인물 — 실제로 봤거나 상상한 누군가
(e) 오래 붙잡고 있는 감정 — 상실·후회·그리움·분노 등
(f) 머릿속에 남은 사건·뉴스 한 줄
```

### What if 변형 (씨앗 → 이야기)

씨앗을 받으면, 갈등의 가능성을 만드는 "만약" 질문을 함께 붙인다.

```
좋습니다. 이 씨앗에 "만약 ~라면?"을 붙여봅니다.
이야기는 평범한 씨앗이 낯선 상황과 부딪힐 때 생깁니다.

예) 씨앗: 편의점에서 본 노숙인
    만약: 만약 그가 기억을 잃은 의사라면?

예) 씨앗: 오래된 후회
    만약: 만약 그 선택을 되돌릴 기회가 단 하루 주어진다면?

지금 씨앗에 붙일 "만약 ~라면?"을 한 줄로 답해주세요.
(떠오르지 않으면 보기 2~3개를 더 제시합니다)
```

### 한 줄 전제 정리 (로그라인 전 단계)

What if까지 받으면, 다음 골격으로 한 줄 전제를 만든다.

```
이제 한 줄 전제로 묶습니다.

[누가] + [어떤 상황에서] + [무엇을 하려다] + [어떤 벽에 부딪힌다]

예) 기억을 잃은 한 남자가, 편의점 야간 알바를 하며,
    잃어버린 과거를 되찾으려다, 그 과거가 숨기고 싶은 것이었음을 알게 된다.

이 골격에 맞춰 한 줄로 정리해드릴까요? (사용자 답변을 받아 문장으로 다듬어 제시)
```

### 단계 완료 확인

```
[1단계 완료]

- 소재 씨앗: {씨앗}
- 만약(What if): {만약 질문}
- 한 줄 전제: {로그라인}

이 전제가 다음 단계(장르·인물·플롯)의 기준이 됩니다.
이대로 다음 단계로 가시겠어요? 수정할 부분이 있으면 알려주세요.
```

전제가 막연하면 What if를 1~2개 더 변형해 비교 제시한다. 한 줄 전제는 반드시 확정하고 넘어간다. 전제 없이 장르로 가면 이후 단계가 다시 흔들린다.

## 2단계 — 장르·톤 (목표 5분)

### 첫 질문

```
[2단계 — 장르·톤]

1단계 전제를 어떤 분위기로 풀지 정합니다.
가까운 것을 1~2개 고르시거나, 본인 표현으로 답해주세요.

(a) 일상물 — 따뜻한·잔잔한·담담한 (예: 〈불편한 편의점〉)
(b) 스릴러 — 긴장감·음모·추적
(c) 로맨스 — 설렘·관계·감정 곡선
(d) SF — 미래·기술·가상 세계
(e) 판타지 — 마법·모험·가상 종족
(f) 문학 — 인간 본질·사회 비판·깊이 (예: 〈소년이 온다〉)
```

### 후속 수집 항목

장르·톤이 확정되면 추가 질문:

1. **분위기 키워드 3~5개** — 색깔·온도·감정 표현
   예: "회색·차가운·조용한·외로운"
2. **참조 작품 1~2개** (선택) — 문체·구조·분위기 중 무엇을 참조하는지 명시
3. **독자 타깃** — 누가 이 책을 읽으면 좋을지 (연령대·관심사)

### 단계 완료 확인

```
[2단계 완료]

- 장르: {장르}
- 톤: {톤}
- 분위기 키워드: {키워드 3~5개}
- 참조 작품: {작품명 + 무엇을 참조}
- 독자 타깃: {독자 페르소나}

이대로 다음 단계로 가시겠어요? 수정할 부분이 있으면 알려주세요.
```

`references/genre-examples.md` 참조하여 장르별 한국 출간 사례 추가 안내 가능.

## 3단계 — 주인공 1~2명 (목표 10분)

### 첫 질문

```
[3단계 — 주인공]

소설은 주인공의 이야기입니다. 주인공 1명을 먼저 그려보겠습니다.
(보조 인물은 나중에 추가)

다음 항목을 한꺼번에 답하셔도 되고, 떠오르는 것부터 답하셔도 됩니다.

이름 (가명도 OK):
나이·직업:
외형 한 줄 (인상적인 한 가지):
성격 핵심 2~3가지:
말투 (대사 예시 1개):
```

### 핵심 추진 요소

성격까지 받은 후, 추진력을 만드는 두 가지를 묻는다.

```
이 인물의 추진력을 정합니다.
소설은 이 두 가지가 부딪힐 때 움직입니다.

핵심 욕망 — 이 인물이 가장 원하는 것은 무엇인가?
(직업적 성공 / 사랑 / 인정 / 평온 / 정의 / 복수 / 자기 발견 ...)

핵심 결핍 — 이 인물이 갖지 못한 것 / 두려워하는 것은?
(가족 부재 / 신뢰 불능 / 트라우마 / 사회적 위치 / 자존감 ...)
```

### 변화 방향 (인물 아크)

```
변화 방향 — 인물 아크

소설 시작 시점의 상태는?
소설 끝 시점의 상태는?

(예: 시작 — 무력감 / 끝 — 한 번의 선택을 내림)
(예: 시작 — 신뢰 불능 / 끝 — 한 사람을 받아들임)
```

### 보조 인물 (선택)

```
보조 인물 1명이 더 필요하면 추가하시겠어요?
(주인공의 친구·가족·라이벌·연인 등)

스킵하셔도 OK — 단편이라면 1명으로도 충분합니다.
```

### 단계 완료 확인

```
[3단계 완료]

주인공: {이름} ({나이·직업})
- 외형: {한 줄}
- 성격: {2~3가지}
- 말투: "{대사 예시}"
- 욕망: {핵심 원하는 것}
- 결핍: {핵심 두려움/부재}
- 변화: {시작 상태} → {끝 상태}

[보조 인물 — 있다면]
{이름} ({나이·직업}) — {주인공과의 관계 한 줄}

이대로 다음 단계로 가시겠어요?
```

## 4단계 — 플롯 골격 (목표 10분)

### 첫 질문 (3막 구조)

```
[4단계 — 플롯 골격]

3막 구조로 골격을 잡습니다.

1막 (발단·전개) — 25%
   주인공의 일상 → 어떤 균열·사건이 시작?
   한 줄로 답해주세요.

(이것을 쓴 후 다음 막 질문)
```

1막 답변 받은 후:

```
좋습니다. 다음:

2막 (위기·갈등) — 50%
   주인공이 추구하는 일은? 가장 큰 위기·갈등은?
   한 줄로 답해주세요.
```

2막 후:

```
3막 (절정·결말) — 25%
   최종 선택·대결·해소는?
   결말의 톤은? (열린·닫힌·반전·여운)
   한 줄로 답해주세요.
```

### 씬 분해

3막 골격을 5~10개 씬으로 분해.

```
[씬 분해]

5~10개 씬으로 나누어 봅니다. 씬 = 한 장면 = 한 장소·시간·사건.

각 씬 항목:
- 장소
- 등장 인물
- 사건 (무엇이 일어나는가)
- 감정 변화 (시작 감정 → 끝 감정)

먼저 1막의 첫 2~3씬부터 채워봅시다.
```

씬을 1막 → 2막 → 3막 순서로 채워간다. 사용자가 막히면 보기 제시:

```
1막 첫 씬 보기:

(a) 일상의 한 순간 — 평범한 출근길에 누군가를 발견
(b) 사건의 시작 — 전화가 걸려옴, 편지가 도착
(c) 인물 소개 — 주인공의 직장·집·습관

가까운 패턴 고르시거나 본인 표현으로 답해주세요.
```

`references/plot-templates.md` 참조.

### 단계 완료 확인

```
[4단계 완료]

[3막 골격]
1막 (25%) — {한 줄}
2막 (50%) — {한 줄}
3막 (25%) — {한 줄, 결말 톤}

[씬 리스트]
1. ({장소}, {인물}, {사건}, {감정})
2. ...
...

이대로 다음 단계로 가시겠어요?
```

## 5단계 — 작업 단위 (목표 5분)

### 첫 질문

```
[5단계 — 작업 단위]

50~60페이지 분량을 어떻게 나눌지 정합니다.

권장:
- 단편 1편 (50~60p) = 1챕터 = 5~10씬
- 단편 2편 (각 25~30p) = 2챕터 = 각 3~5씬
- 중편 1편 (50~60p) = 5~10챕터 = 각 5~10p

본인 작업에 맞는 형식을 골라주세요.
```

### 후속 수집

```
형식 결정 후:

- 챕터 수: ___
- 씬 수: ___
- 1회 AI 요청 분량: 1,500~2,000자 권장 (씬 1개 = 1회 요청)
- 작업 순서: 1챕터 → 마지막 챕터 순서? 또는 핵심 챕터부터?
```

### 단계 완료 확인

```
[5단계 완료]

- 형식: {단편 1편 / 단편 2편 / 중편 1편}
- 챕터 수: {N}
- 씬 수: {M}
- 1회 요청 분량: 1,500~2,000자
- 작업 순서: {순서}

기획안 정리로 넘어가겠습니다.
```

## 산출물 정리 (마지막)

5단계가 모두 완료되면 1쪽 기획안 + 챕터·씬 골격을 한 번에 출력한다.

```markdown
# {제목 가제 — 사용자가 정했으면 그대로, 없으면 가제 제안}

## 전제 (한 줄)
{소재 씨앗에서 끌어낸 로그라인 — 누가, 어떤 상황에서, 무엇을 하려다, 어떤 벽에 부딪힌다}

## 장르·톤
{장르} · {톤} · {분위기 키워드}
참조 작품: {작품명 + 참조 포인트}

## 주인공
**{이름}** ({나이·직업})

- 외형: {한 줄}
```

## 자주 발생하는 변수와 대응

### "잘 모르겠어요" 답변

소재·장르·인물·플롯 어떤 단계에서든 사용자가 막히면:

1. 보기 3~5개 추가 제시
2. "비슷한 책 1권 떠올려보기" 권유
3. "지금 머릿속에 떠오르는 장면 1개 묘사해보기" 등 우회 질문

본인 답변을 끌어내는 것이 핵심. 강사가 답을 주지 않는다.

### 1단계에서 소재가 전혀 안 나올 때

소재 발굴은 초보자가 가장 막히는 지점이다. 막히면 범위를 좁힌다.

```
크게 생각하지 마세요. 오늘 하루 중 잠깐이라도 마음에 걸린 순간 하나를 떠올려보세요.
그것이 소재가 됩니다.

여전히 떠오르지 않으면, 보기 중 하나를 빌려 시작해도 됩니다.
- 빈집에 혼자 남은 사람
- 마지막 버스를 놓친 밤
- 오래된 편지 한 통을 발견한 아침
```

빌린 보기로 시작해도 What if 변형부터는 본인 색을 입히도록 유도한다.

### "그냥 써줘" 강한 요청

```
이해합니다. 다만 사전 설계 없이 바로 쓰면 글이 일관성 없이 산발적이 됩니다.

최소 1단계만 정해도 됩니다. 지금 머릿속에 남아 있는 장면이나 인물 하나만 말해주세요.
거기서 한 줄 전제를 같이 만들겠습니다.
```

최소 단계는 강제. 사용자가 끝까지 거부하면 "본격 작업은 book-novel 스킬"로 안내.

### 1차 시간 부족

4단계까지만 마치고 5단계와 산출물 정리는 자율 학습으로:

```
5단계는 분량 결정만 남았습니다. 다음 차시까지 다음 중 선택해서 가져오세요:
- 단편 1편 / 단편 2편 / 중편 1편

지금까지 정한 것을 1쪽 기획안으로 정리해드립니다.
```
