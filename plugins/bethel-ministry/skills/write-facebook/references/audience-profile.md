# 페이스북 오디언스 프로필

## 핵심 독자층
- 연령: 40~50대
- 직업: 직장인, 1인 기업가, 강사, 콘텐츠 제작자
- 페이스북 사용 패턴: 출근 전(8~9시), 점심(12~1시)에 피드 확인

## AI 사용 수준과 관심 범위
- ChatGPT 유료 구독 중이거나 무료 사용 중
- 클로드, 제미나이에 관심이 늘고 있으며, 도구 간 비교에 민감
- 노트북LM, 나노바나나 등 특화 도구에 호기심이 있는 단계
- AI를 통해 업무 생산성을 높이려는 실용적 목적이 강함
- 새로운 AI 트렌드(에이전트, 스킬, MCP 등)에 관심은 있으나
  기술 용어보다 "그래서 나한테 어떤 변화가 생기는지"를 알고 싶어 함

## 이 독자가 반응하는 글
- "나도 겪었는데" 하고 자기 경험을 떠올리게 하는 글
- 바로 따라할 수 있는 실용 가이드
- AI 도구의 실제 사용 과정을 보여주는 작업 서사
- 기존 통념을 뒤집는 판단 기준 제시
- 도구 간 비교 ("이 작업에는 이 도구, 저 작업에는 저 도구")

## 이 독자가 반응하지 않는 글
- 기술 용어 나열 (API, 토큰, 파라미터 설명 중심)
- 뉴스 요약형 ("OpenAI가 새 모델을 발표했습니다")
- 감탄형 홍보 ("이 도구 정말 대단합니다!")
- 특정 도구의 기능만 소개하고 작업 맥락이 없는 글

## 이 독자의 핵심 고민
- AI로 글을 쓰고 싶은데 내 글 같지 않다
- 도구는 알겠는데 어떤 순서로 작업해야 하는지 모르겠다
- 책을 쓰고 싶은데 시작을 못 하고 있다
- 블로그/SNS를 운영하고 싶은데 꾸준히 못 한다
- AI 도구가 너무 많아서 어디에 시간을 투자해야 할지 모르겠다
- 새로운 도구가 나올 때마다 따라가야 하는지 판단이 안 선다

## 글쓰기 적용 규칙
- 전문 용어 사용 시 반드시 한글(영문) 병기
- 예시는 AI 글쓰기·책쓰기·이미지 생성·업무 자동화 맥락에서 가져온다
- 독자를 가르치는 위치가 아니라, 같은 작업을 먼저 해본 사람의 위치
- 도구 소개 시 기능이 아니라 작업 맥락("이 작업에서 이 도구를 쓴 이유")으로 접근
