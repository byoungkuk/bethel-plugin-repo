# 리라이팅 점검 체크리스트

Step 4(리라이팅)에서 이 체크리스트를 순서대로 점검한다. 각 점검 항목을 통과한 후 다음으로 넘어간다. 문제가 발견되면 수정 후 해당 항목을 다시 점검한다.

---

## 점검 1: 핵심 판단문 + '더보기' 전 텍스트

- [ ] 글 전체를 관통하는 핵심 판단문(또는 원칙)이 존재하는가
- [ ] 핵심 판단문이 단독 행으로 분리되어 있는가 (앞뒤 행간)
- [ ] 첫 문장이 완결형이며, 읽는 즉시 의미가 전달되는가
- [ ] 훅 패턴이 글 유형에 맞는가 (유형별 훅 패턴 대조)
- [ ] 모바일 기준 약 125자 이내에 '더보기' 클릭 동기가 완성되는가
- [ ] 실용형 글(가이드·템플릿)의 경우, 1~2문장 선언만으로 충분한가

---

## 점검 2: 구조·흐름

- [ ] 유형별 구조 패턴(블록 순서)이 지켜지는가
- [ ] 각 블록 간 전환이 자연스러운가 (논리적 연결)
- [ ] 마무리가 유형에 맞는 방식인가

| 유형 | 마무리 방식 |
|------|-----------|
| 관점 제시형 | 대비 압축 1문장 또는 2문장 쌍 |
| 시스템 해설형 | 단독 판단문 기준 재정렬 |
| 경험 공유형 | 역할 정리 또는 경험 요약 |
| 교육 콘텐츠형 | 3단계 점층 |
| 실용 가이드형 | 완성 예시 1개 |
| 템플릿 배포형 | 커뮤니티 유입 안내 |
| 프레임워크형 | 비유형 압축 + 행동 제안 |

---

## 점검 3: 문체 패턴 적용

유형별 필수 패턴이 적용되었는지 확인한다. 미적용 시 추가 필요.

| 글 유형 | 필수 패턴 | 적용 여부 |
|---------|----------|----------|
| 관점 제시형 | 양보+전환, 단독 판단문, 2문장 쌍, 대비 반복 | [ ] |
| 시스템 해설형 | 양보+전환, 질문형 전환, 작업 서사, 단독 판단문 | [ ] |
| 경험 공유형 | 시간 대비 | [ ] |
| 교육 콘텐츠형 | Before/After 변환 예시, 단독 판단문 | [ ] |
| 실용 가이드형 | 라벨+핵심+부연 유닛 | [ ] |
| 템플릿 배포형 | 단독 판단문 1개 (맥락부) | [ ] |
| 프레임워크형 | 라벨+핵심+부연 유닛, 비유형 마무리 | [ ] |

---

## 점검 4: 종결어미·문장·금지어

### 종결어미
- [ ] 종결어미가 유형별 기본값과 일치하는가
- [ ] 합니다체와 ~다체가 한 글 안에서 혼용되지 않는가
- [ ] "~습니다"가 3회 이상 연속 반복되지 않는가 (리듬 변화 필요)

### 문장
- [ ] 문장 길이가 12~20단어 내외인가
- [ ] 한 문장에 정보·판단이 하나만 담겨 있는가
- [ ] 긴 문장 3개가 연속되지 않는가
- [ ] 능동형 문장이 기본인가

### 금지어 대조 (`references/anti-patterns.md` 참조)
- [ ] 과장형 형용사 없는가 (혁신적인, 획기적인, 완벽한, 최고의, 강력한)
- [ ] 모호한 부사 없는가 (매우, 굉장히, 상당히, 꽤, 쉽게, 빠르게)
- [ ] 추측·완곡 표현 없는가 (~할 수 있습니다, ~일 수 있습니다)
- [ ] 불필요한 연결어 없는가 (전반적으로 볼 때, 일반적으로 말하면)
- [ ] 추상 명사 중심 문장이 없는가 (중요성, 필요성, 가능성)
- [ ] AI 흔적 조합이 없는가 (부사 + 형용사 + 가능성 + 추상 명사)

---

## 점검 5: 가독성

### 행간
- [ ] 2~3문장마다 한 줄 띄우기가 적용되었는가
- [ ] 주제 전환 시 두 줄 띄우기가 적용되었는가
- [ ] 한 문단(행간 사이 블록)이 최대 4문장을 넘지 않는가
- [ ] 연속으로 5문장 이상 이어 쓴 곳이 없는가

### 시각적 리듬
- [ ] 짧은 문장(5~8단어)과 보통 문장(12~20단어)이 교차 배치되었는가
- [ ] 핵심 판단 문장이 단독 행으로 분리되었는가 (앞뒤 행간)

### 유형별 리스트 규칙
- [ ] 관점 제시형, 경험 공유형: 산문 중심, 리스트 최소화
- [ ] 교육 콘텐츠형, 프레임워크형: 번호 사용 허용 (1. 2. 3. 또는 ①②③)
- [ ] 실용 가이드형, 템플릿 배포형: - 기호 불릿 허용

### 여운 장치
- [ ] "..." 사용이 글 전체에서 1~2회 이내인가

### 금지
- [ ] 과도한 이모지가 없는가
- [ ] 해시태그가 본문에 삽입되지 않았는가 (본문 끝에만 배치)

---

## 점검 6: 반응 설계 + 오디언스 대조

### 반응 목표 점검
- [ ] 반응 목표(좋아요/공유/전문성/커뮤니티)에 맞는 공유 장치가 존재하는가
- [ ] 즉시 활용 가능한 실용물이 포함되어 있는가 (해당 유형만)

### 오디언스 프로필 대조 (`references/audience-profile.md` 참조)
- [ ] "반응하지 않는 글" 패턴에 해당하지 않는가
  - 기술 용어 나열이 아닌가
  - 뉴스 요약형이 아닌가
  - 감탄형 홍보가 아닌가
  - 작업 맥락 없는 기능 소개가 아닌가
- [ ] 독자의 핵심 고민 중 하나 이상에 연결되는가
- [ ] 도구 소개 시 기능이 아니라 작업 맥락으로 접근했는가
- [ ] 전문 용어에 한글(영문) 병기가 적용되었는가

### 분량 점검
- [ ] 유형별 권장 분량 범위를 준수하는가

## 사용 규칙

- Step 4 진입 시 이 파일을 로드하여 점검 1부터 순서대로 진행한다.
- 각 점검에서 문제 발견 시 수정 후 해당 점검을 다시 통과시킨다.
- 점검 6의 오디언스 대조는 `references/audience-profile.md`와,
  점검 4의 금지어 대조는 `references/anti-patterns.md`와 교차 참조한다.
