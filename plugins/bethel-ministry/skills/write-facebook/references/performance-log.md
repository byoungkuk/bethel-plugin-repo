# 페이스북 발행 성과 기록

이 문서는 페이스북에 발행한 글의 반응 데이터를 누적 기록한다. 2~3개월 데이터가 쌓이면 유형별·분량별·시간대별 성과를 분석하여 스킬을 개선한다.

## 분석 기준 (데이터 10건 이상 축적 시 활용)

### 유형별 평균 반응
| 유형 | 평균 좋아요 | 평균 댓글 | 평균 공유 | 글 수 |
|------|-----------|----------|----------|-------|
| 관점 제시형 | - | - | - | 0 |
| 시스템 해설형 | - | - | - | 0 |
| 경험 공유형 | - | - | - | 4 |
| 교육 콘텐츠형 | - | - | - | 2 |
| 실용 가이드형 | - | - | - | 0 |
| 템플릿 배포형 | - | - | - | 0 |
| 프레임워크형 | - | - | - | 0 |

### 점검 질문 (월 1회)
- 댓글이 가장 많은 유형은 무엇인가?
- 공유가 가장 많은 유형은 무엇인가?
- 짧은 글(500자 이하)과 긴 글(1,000자 이상)의 반응 차이는?
- 어떤 훅 패턴이 가장 높은 참여를 유발하는가?
- 발행 시간대(오전 vs 점심 vs 저녁)별 차이는?
- 도구 비교 글과 단일 도구 글의 반응 차이는?
- 오디언스 프로필의 "반응하는 글" 항목과 실제 데이터가 일치하는가?

## 사용 규칙

- 글 발행 후 **48시간 뒤** 좋아요·댓글·공유 수를 기록한다.
- 비고란에 특이사항(이미지 포함, 댓글 유도 질문 사용, 이벤트 연결 등)을 기록한다.
- 데이터 10건 이상 쌓이면 유형별 평균 반응 테이블을 업데이트한다.
- 분석 결과에 따라 SKILL.md의 유형별 분량 권장 범위, 훅 패턴 우선순위를 조정한다.
