# 블로그 발행 메타 정보 양식

아래 양식을 글 최종본과 함께 작성한다.

---

## 발행 메타 정보

```
제목: 
슬러그(URL): sshong.com/blog/
카테고리: 
태그: 
메타설명 (150자 이내): 

대표 이미지 콘셉트: 
내부 링크:
  - 관련글 1: 
  - 관련글 2: 
  - 관련글 3: 
시리즈: (해당 시 시리즈명 + 회차)

SEO 키워드:
  - 핵심: 
  - 보조 1: 
  - 보조 2: 
  - 보조 3: 

분량: 자 (공백 포함)
예상 읽기 시간: 분
```

---

## 작성 기준

### 제목
- 50자 이내
- 핵심 키워드 포함
- 판단·관점이 드러나는 형태 우선

### 슬러그
- 핵심 키워드를 영문 또는 한글로 간결하게
- 예: `ai-write-content`, `prompt-design-principle`

### 메타설명
- 150자 이내
- 핵심 키워드 1회 포함
- "이 글에서는~"으로 시작하지 않는다
- 글의 핵심 판단 또는 독자 혜택을 담는다

### 대표 이미지 콘셉트
- 직접 생성하지 않고, 방향만 제시
- 예: "타이핑하는 손과 AI 인터페이스가 겹치는 미니멀 일러스트"
- 예: "5단계 프로세스를 보여주는 플로우차트 스타일"

---

## 워드프레스 발행 체크리스트

```
□ 제목 입력
□ 본문 붙여넣기 (H2/H3 소제목 확인)
□ 카테고리 선택
□ 태그 입력
□ 메타설명 입력 (Yoast/RankMath)
□ 대표 이미지 업로드
□ 내부 링크 URL 확인
□ TOC 자동 생성 확인
□ 미리보기 → 모바일 레이아웃 확인
□ 발행
```
