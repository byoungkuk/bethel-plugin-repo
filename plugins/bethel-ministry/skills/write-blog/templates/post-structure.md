# 블로그 글 유형별 구조 템플릿

각 유형의 H2/H3 구조를 따르되, 주제에 맞게 소제목 문구를 조정한다.
소제목은 기능명·명사 나열이 아닌 **판단·행동 중심 문장**으로 작성한다.

---

## 유형 1: 방법론 해설

```
[도입부] 3~4문장
- 현상 관찰 + 판단 선언
- 독자가 왜 이 글을 읽어야 하는지

## H2: 개념 정의 — 무엇이며 왜 중요한가
- 개념을 정의하되, 사전식이 아닌 문제 상황에서 출발
- 기존 이해와 다른 지점을 짚는다

## H2: 단계별 실행 — 어떻게 적용하는가
### H3: Phase 1. (판단 기준 + 실행)
### H3: Phase 2. (판단 기준 + 실행)
### H3: Phase 3. (판단 기준 + 실행)
- 각 단계마다 "왜 이 순서인가"를 설명

## H2: 흔한 오해와 주의점
- 독자가 잘못 적용할 수 있는 지점을 교정

[마무리] 3~5문장
- 핵심 기준 압축 + 관점 재정렬
```

**분량:** 1,500~2,500자
**적합한 주제:** AI 글쓰기 프로세스, 프롬프트 설계 원칙, 워크플로우 구축법

---

## 유형 2: 도구·기능 리뷰

```
[도입부] 3~4문장
- 이 도구를 왜 검토했는가 (해결하려는 문제)

## H2: 핵심 기능과 평가 기준
### H3: 기능 A — (평가 결과)
### H3: 기능 B — (평가 결과)
- 기능 나열이 아닌, 어떤 기준으로 평가했는지 중심

## H2: 기존 도구와 무엇이 다른가
- 비교 대상을 명시하고, 차이를 구체적으로 서술

## H2: 어떤 상황에서 선택해야 하는가
- 조건별 판단 기준 제시

[마무리] 3~5문장
- 판단 기준 정리
```

**분량:** 1,200~2,000자
**적합한 주제:** ChatGPT vs Claude 비교, 새 AI 도구 리뷰, 플러그인 평가

---

## 유형 3: 인사이트·관점

```
[도입부] 3~4문장
- 현상 관찰 + "그러나 본질은 다르다" 식의 반론

## H2: 기존 관점은 왜 한계가 있는가
- 통념을 정리하고 어디서 흔들리는지 지적

## H2: 기준을 바꾸면 보이는 것
- 새로운 판단 기준 제시
- 사례·경험으로 뒷받침

## H2: 실제 적용하면 무엇이 달라지는가
- 구체적 변화, 결과, 장면 서술

[마무리] 3~5문장
- 관점 전환 — 독자가 가져갈 기준
```

**분량:** 1,200~2,000자
**적합한 주제:** AI 시대 글쓰기 관점, 콘텐츠 전략 변화, 교육 방식 재정의

---

## 유형 4: 경험 기반 글

```
[도입부] 2~3문장
- 구체적 상황 제시 (강의 현장, 집필 중, 컨설팅 장면)

## H2: 그 경험에서 발견한 것
- 상황을 서술하되, 관찰과 판단을 분리

## H2: 기준이 바뀐 지점
- 경험 전후로 무엇이 달라졌는지

[마무리] 3~5문장
- 독자에게 남기는 판단 기준
```

**분량:** 1,200~1,800자
**적합한 주제:** 강의 후기에서 얻은 인사이트, 집필 과정 기록, 실무 현장 관찰

---

## 유형 5: 가이드·튜토리얼

```
[도입부] 2~3문장
- 이 가이드가 필요한 구체적 상황

## H2: 시작 전 확인할 것
- 전제 조건, 준비물, 사전 설정

## H2: 단계별 실행
### H3: Step 1. (구체적 행동)
- 프롬프트 예시, 설정값, 스크린샷 위치 표시 [IMAGE]
### H3: Step 2. (구체적 행동)
### H3: Step 3. (구체적 행동)

## H2: 자주 발생하는 문제와 대응
- Q&A 또는 트러블슈팅 형식

[마무리] 2~3문장
- 핵심 실행 기준 정리
```

**분량:** 1,500~2,500자
**적합한 주제:** AI 도구 사용법, 프롬프트 작성 가이드, 워크플로우 셋업

## 유형 6: 출간·강의 안내

```
[도입부] 2~3문장
- 무엇을, 왜 만들었는가

## H2: 이런 분에게 필요합니다
- 대상 독자/수강생의 상황 서술

## H2: 구성과 핵심 내용
- 목차 또는 커리큘럼 요약
- 각 파트의 핵심을 1~2문장으로

## H2: 참여/구매 방법
- 일정, 링크, 가격 등 실행 정보

[마무리] 1~2문장
- 간결한 마무리
```

**분량:** 800~1,500자
**적합한 주제:** 신간 안내, 강의 모집, 워크숍 공지
