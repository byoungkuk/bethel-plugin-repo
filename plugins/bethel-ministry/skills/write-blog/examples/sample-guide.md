# 예시 — 가이드·튜토리얼형 블로그 글

이 파일은 가이드·튜토리얼 유형의 완성 글 예시다.
실행 가능한 단계, 프롬프트 예시 포함, 소제목 설계의 기준으로 참조한다.

---

## 완성 글

**제목:** 클로드(Claude) 스킬로 블로그 글쓰기를 자동화하는 3단계

블로그 글을 쓸 때마다 같은 지시를 반복하고 있다면, 문제는 AI가 아니라 방식에 있습니다.

클로드 스킬(Claude Skills)을 사용하면 글의 구조, 문체, SEO 규칙을 한번 정의해두고, 이후에는 주제만 입력하면 됩니다.

## 시작 전 확인할 것

- Claude Pro 또는 Max 플랜 (스킬 업로드 기능 필요)
- Settings > Capabilities에서 "Code execution and file creation" 활성화
- 스킬 파일을 ZIP으로 묶을 수 있는 환경 (macOS Finder, Windows 탐색기)

## 단계별 실행

### Step 1. SKILL.md 파일을 작성합니다

SKILL.md는 스킬의 핵심 지침 파일입니다. 상단에 YAML 메타데이터, 하단에 마크다운 본문을 넣습니다.

```
---
name: my-blog-writer
description: 내 블로그에 맞는 구조와 문체로 글을 작성한다.
---

# 블로그 글쓰기 스킬

## 절차
1. 주제와 글 유형을 확인한다
2. H2/H3 소제목 구조를 설계한다
3. 초안을 작성한다
4. 문체 기준에 맞춰 수정한다

## 문체 기준
- 종결어미: ~습니다
- 문장: 15~25단어
- 도입부: 현상 관찰 또는 문제 제시로 시작
```

`name`은 소문자와 하이픈만 사용합니다. `description`은 Claude가 이 스킬을 언제 쓸지 판단하는 기준이 됩니다.

### Step 2. 폴더를 구성하고 ZIP으로 압축합니다

SKILL.md를 폴더 안에 넣고, 폴더째로 압축합니다.

```
my-blog-writer/        ← 이 폴더를 ZIP으로 압축
└── SKILL.md
```

주의: ZIP 안에 `my-blog-writer/SKILL.md` 경로가 있어야 합니다. SKILL.md가 ZIP 루트에 바로 있으면 인식하지 못합니다.

[IMAGE: ZIP 폴더 구조 스크린샷]

### Step 3. 업로드하고 테스트합니다

Settings > Capabilities > Skills에서 ZIP 파일을 업로드합니다. 목록에 나타나면 토글을 ON으로 켭니다.

새 채팅을 열고 "블로그에 올릴 글 써줘, 주제는 AI 이미지 편집"처럼 요청합니다. 스킬이 자동으로 적용되면 SKILL.md에 정의한 구조와 문체로 글이 생성됩니다.

[IMAGE: 스킬 업로드 화면 스크린샷]

## 잘 안 될 때 확인할 것

| 증상 | 원인 | 해결 |
|------|------|------|
| 업로드는 되지만 스킬이 작동하지 않음 | description이 모호함 | "~할 때 사용한다"를 구체적으로 수정 |
| ZIP 업로드 오류 | 폴더 없이 파일만 압축 | 폴더를 만들고 그 안에 SKILL.md를 넣은 뒤 폴더째 압축 |
| 스킬이 다른 요청에서 작동함 | description 범위가 넓음 | 트리거 조건을 좁혀서 작성 |

스킬의 핵심은 description의 정밀도입니다.
Claude가 "이 요청에 이 스킬을 써야 한다"고 판단할 수 있을 만큼 구체적으로 작성하면, 나머지는 자동으로 작동합니다.

## 분석 포인트

이 예시에서 확인할 기준:

| 요소 | 적용 내용 |
|------|-----------|
| 도입부 | 문제 상황("같은 지시를 반복") → 해결 방향 제시 |
| 소제목 | 행동 중심 ("SKILL.md 파일을 작성합니다") |
| 코드 블록 | 실행 가능한 예시 포함 |
| [IMAGE] 마커 | 스크린샷 삽입 위치 표시 |
| 트러블슈팅 | 표 형식으로 증상→원인→해결 정리 |
| 마무리 | 핵심 판단 기준 1문장으로 압축 |
| 분량 | 약 1,500자 |
