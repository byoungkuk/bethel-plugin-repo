# sshong.com 블로그 SEO 체크리스트

## 1. 키워드 설계

### 키워드 구조
- 핵심 키워드 1개: 글의 주제를 대표하는 단어/구문
- 보조 키워드 2~3개: 핵심 키워드의 변형, 연관어, 롱테일 키워드

### 키워드 배치 규칙

| 위치 | 키워드 | 방식 |
|------|--------|------|
| 제목 (title) | 핵심 키워드 | 자연스럽게 포함. 앞쪽 배치 우선 |
| H2 소제목 | 핵심 + 보조 | H2 2~5개 중 최소 1개에 핵심 키워드 포함 |
| H3 소제목 | 보조 키워드 | 자연스러운 문맥에서만 |
| 도입부 (첫 3문장) | 핵심 키워드 | 1회 자연스럽게 등장 |
| 본문 | 핵심 + 보조 | 문맥에 맞게 분산. 키워드 밀도 강제하지 않음 |
| 메타설명 | 핵심 키워드 | 150자 이내 요약문에 포함 |
| URL 슬러그 | 핵심 키워드 | 영문 또는 한글 슬러그 |

### 금지 사항
- 키워드를 부자연스럽게 반복 삽입하지 않는다
- 소제목에 키워드를 억지로 넣지 않는다
- 키워드 밀도 수치를 목표로 삼지 않는다

## 2. 제목 SEO 규칙

- 50자 이내 (검색 결과에서 잘림 방지)
- 핵심 키워드를 앞쪽에 배치
- 판단·관점이 드러나는 제목 우선
- 시리즈 글: 번호(①②③) + 제목

### 제목 체크

| 점검 | 기준 |
|------|------|
| 길이 | 50자 이내 |
| 키워드 | 핵심 키워드 포함 |
| 차별성 | 같은 키워드 검색 시 기존 결과와 다른 관점 |
| 클릭 유도 | 정보성(~방법, ~가이드)과 관점형(~의 핵심은 ~이다) 중 선택 |

## 3. 메타설명 규칙

- 150자 이내
- 핵심 키워드 1회 포함
- 글의 핵심 판단 또는 독자 혜택을 담는다
- "이 글에서는~"으로 시작하지 않는다

### 메타설명 패턴

| 패턴 | 예시 |
|------|------|
| 판단 제시형 | "AI 글쓰기의 차이는 프롬프트가 아니라 수정 과정에서 결정됩니다. 5단계 워크플로우로 초안을 완성본으로 바꾸는 기준을 정리합니다." |
| 문제→해결형 | "프롬프트만으로는 원하는 글이 나오지 않습니다. 구조 설계부터 리라이팅까지, 실무에서 검증된 AI 글쓰기 프로세스를 소개합니다." |
| 대상 명시형 | "AI 글쓰기를 시작했지만 결과물이 만족스럽지 않은 실무자를 위한 가이드. 초안 생성이 아닌 수정 설계에 집중합니다." |

## 4. 구조 SEO

### H2/H3 소제목
- H2는 글의 핵심 섹션. 2~5개
- H3는 H2 내부 세분화. H2당 0~3개
- TOC 플러그인이 H2/H3를 자동 수집 → 소제목이 목차가 된다
- 소제목만 읽어도 글의 흐름이 파악되어야 한다

### 내부 링크
- 관련 글 2~3개를 본문 내에 자연스럽게 배치
- 링크 텍스트는 "여기", "이 글" 대신 **글 제목 또는 핵심 키워드** 사용
- 시리즈 글: 이전/다음 글 링크 필수

### 이미지
- 대표 이미지(Featured Image): 모든 글에 필수
- alt 텍스트에 핵심 키워드 포함
- 본문 이미지: 글의 흐름과 직접 관련된 경우만

## 5. 발행 전 최종 SEO 점검

```
□ 제목: 50자 이내, 핵심 키워드 포함
□ 메타설명: 150자 이내, 핵심 키워드 포함
□ H2 소제목: 최소 1개에 핵심 키워드
□ 도입부: 첫 3문장 내 핵심 키워드 등장
□ 내부 링크: 관련 글 2~3개 배치
□ 대표 이미지: 설정 완료
□ 카테고리·태그: 지정 완료
□ URL 슬러그: 핵심 키워드 반영
```
