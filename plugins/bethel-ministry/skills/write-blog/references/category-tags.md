# sshong.com 카테고리·태그 체계

## 1. 카테고리 구조

| 카테고리 | 설명 | 대표 주제 |
|----------|------|-----------|
| 생성형AI/챗GPT | AI 도구 활용, 프롬프트 설계, AI 워크플로우 | ChatGPT, Claude, AI 글쓰기, AI 이미지, 프롬프트 |
| 글쓰기 | 글쓰기 방법론, 콘텐츠 전략, 글쓰기 도구 | 글쓰기 원칙, 콘텐츠 기획, 플랫폼별 글쓰기 |
| 영상제작/AI영상 | AI 영상 생성, 편집, 영상 콘텐츠 제작 | AI 영상 도구, 편집 워크플로우, 숏폼 |
| 일하는법/생산성 | 업무 방식, 생산성 도구, 워크플로우 설계 | 자동화, 업무 시스템, 시간 관리 |
| 책쓰기 | 집필 프로세스, 출판, 원고 작업 | 원고 구조, 퇴고, 출판 과정 |
| 강의 | 강의 기획, 교육 콘텐츠, 강사 활동 | 커리큘럼 설계, 교안, 강의 후기 |
| 홍순성 | 개인 기록, 에세이, 일상 | 관찰, 생각, 기록 |

## 2. 카테고리 선택 기준

- 글 1개당 카테고리 **1~2개** 지정
- 주제가 겹칠 때: 글의 **핵심 판단이 어디에 속하는지**로 결정
  - 예: AI로 글쓰는 방법 → "생성형AI/챗GPT" + "글쓰기"
  - 예: 강의에서 AI 활용한 경험 → "강의" (AI는 소재일 뿐, 핵심은 강의 경험)
- 3개 이상 카테고리를 선택하지 않는다

## 3. 태그 운영 규칙

### 태그 수
- 글당 **2~4개**
- 너무 적으면 분류 효과 없음, 너무 많으면 태그 체계 흐려짐

### 태그 유형

| 유형 | 예시 | 설명 |
|------|------|------|
| 도구명 | ChatGPT, Claude, Midjourney, Notion | 특정 도구를 다루는 글 |
| 방법론 | 프롬프트설계, 워크플로우, 글쓰기원칙, SEO | 방법론·기법 중심 |
| 주제 키워드 | AI글쓰기, AI이미지, 건설안전, 콘텐츠전략 | 주제 분류 |
| 포맷 | 가이드, 리뷰, 인사이트, 경험기록 | 글의 형식 |

### 태그 작성 규칙
- 기존에 사용한 태그와 **동일한 표기** 유지 (예: "챗GPT"와 "ChatGPT" 혼용 금지)
- 새 태그 생성 시, 해당 태그로 3편 이상의 글이 예상될 때만 생성
- 태그는 띄어쓰기 없이 붙여쓰기 기본 (예: AI글쓰기, 프롬프트설계)

## 5. 시리즈 관리

### 시리즈 번호 체계
- 원 번호: ①②③④⑤⑥⑦⑧⑨⑩
- 색인 글(시리즈 소개): ⓪
- 번호는 제목 앞에 붙인다: "③ AI 글쓰기 워크플로우 — 리라이팅 단계"

### 시리즈 연계
- 각 글 도입부 또는 결론에 시리즈 이전/다음 글 링크 배치
- 색인 글(⓪)이 있으면 해당 글에 새 글 링크 추가
- 시리즈 태그 부여 (예: "AI글쓰기시리즈")
