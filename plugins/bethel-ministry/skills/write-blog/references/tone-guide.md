# sshong.com 블로그 문체·어휘 가이드

## 1. 문체 포지션

sshong.com 글은 **설명과 판단의 중간**에 위치한다. 정보 나열 글이 아니고, 감상 에세이도 아니다. 현상을 관찰하고, 기준을 제시하고, 독자가 스스로 판단할 수 있게 이끄는 글이다.

## 2. 어조 기준

| 원칙 | 설명 |
|------|------|
| 가르치지 않되 이끈다 | 독자 위에 서지 않고, 같은 문제를 함께 바라보는 위치 |
| 단정하되 독선적이지 않다 | "~할 수 있습니다"가 아닌 "~합니다"로 쓰되, 다른 가능성을 닫지 않는다 |
| 경험에서 출발한다 | 이론이 아니라 강의·집필·컨설팅 현장에서 얻은 관찰이 근거가 된다 |
| 설명 순서가 있다 | 상황 → 기준 → 적용 방식. 결론부터 던지지 않고, 왜 그 기준인지부터 보여준다 |

## 3. 글 유형별 톤

| 글 유형 | 톤 | 핵심 |
|---------|-----|------|
| 방법론 해설 | 설계자 | 개념 정의 → 단계 → 각 단계의 판단 기준 |
| 도구·기능 리뷰 | 실험자 | 직접 사용 기반. 기능 나열이 아닌 평가 기준 중심 |
| 인사이트·관점 | 분석적 관찰자 | 현상 재정의, 기존 관점과 다른 기준 제시 |
| 경험 기반 | 실무 기록자 | 현장 관찰과 판단 정리 |
| 가이드·튜토리얼 | 구조적 안내자 | 조건 → 기준 → 결과. 실행 가능한 재료 포함 |
| 출간·강의 안내 | 정보 전달자 | 핵심, 대상, 구성을 간결하게 전달 |

## 4. 금지어 목록

### ① 과장형 형용사
혁신적인, 획기적인, 창의적인, 강력한, 완벽한, 최고의, 탁월한, 뛰어난
→ 대체: 무엇이 어떻게 다른지, 수치·사례로 설명

### ② 모호한 부사
매우, 굉장히, 상당히, 꽤, 쉽게, 빠르게, 간편하게, 효율적으로
→ 대체: 시간·단계·수치·조건으로 구체화

### ③ 추측·완곡 표현
~할 수 있습니다, ~일 수 있습니다, ~라고 볼 수 있습니다, 어느 정도, 부분적으로, 다소
→ 대체: 단정형. 조건이 있으면 조건을 먼저 제시

### ④ 불필요한 여유 연결어
전반적으로 볼 때, 일반적으로 말하면, 어떤 면에서 보면, 이러한 측면에서, 결과적으로
→ 대체: 근거 → 주장 직접 연결

### ⑤ 추상 명사 중심 문장
중요성, 필요성, 가능성, 효과, 가치, 측면, 부분
→ 대체: 동사 중심 문장. 장면·행동·결과로 구체화

### ⑥ AI 흔적 조합
부사 + 형용사 + 가능성 표현 + 추상 명사 패턴 전체를 금지

## 5. 단락 구조 — 일반 문서 형식

sshong.com 블로그 글은 **일반 문서 단락 구조**를 따른다. 모바일 소셜 미디어식 문장별 줄바꿈(한 문장 독립 줄 배치)은 사용하지 않는다.

**적용 기준:**
- 문단은 2~5문장이 하나의 의미 단위를 이루도록 구성한다
- 단락이 바뀔 때만 줄바꿈한다
- 강조·전환 문장도 단락 안에 자연스럽게 배치한다
- 마무리 문장도 단락 형식을 유지한다

**적용하지 않는 것:**
- 한 문장만으로 이루어진 단독 단락
- 문장마다 줄바꿈하는 행간 강조 방식

## 6. 출력물에서 제외할 것

글 출력물에는 다음 두 가지를 포함하지 않는다.

**① 작성자·날짜 표기**
"Written by 홍순성 on …" 형식은 출력물에 넣지 않는다. 이 정보는 워드프레스가 자동으로 처리한다.

**② Contents 박스**
H2/H3 소제목을 불릿 리스트로 나열한 TOC 박스를 글 본문에 삽입하지 않는다. TOC는 워드프레스 플러그인이 자동으로 생성한다. 출력물에는 H2/H3 소제목 마크다운만 사용한다.

## 7. 좋은 문장 vs 나쁜 문장

| 나쁜 문장 | 문제 | 좋은 문장 |
|-----------|------|-----------| 
| AI 글쓰기는 매우 효율적으로 작업할 수 있습니다 | 모호한 부사 + 추측 표현 | AI 글쓰기는 초안 생성 시간을 1시간에서 15분으로 줄입니다 |
| 이 도구는 혁신적인 기능을 제공합니다 | 과장형 형용사 + 정보 없음 | 이 도구는 문단 단위 수정을 지원합니다. 기존 도구는 문장 단위까지만 가능했습니다 |
| 글쓰기에서 구조의 중요성은 아무리 강조해도 지나치지 않습니다 | 추상 명사 + 상투 표현 | 구조가 없는 글은 3문단 이후 독자 이탈률이 급격히 높아집니다 |
| 전반적으로 볼 때, 이 방법은 상당히 유용할 수 있습니다 | 여유 연결어 + 모호 부사 + 추측 | 이 방법은 초안 수정 횟수를 3회 이내로 줄입니다 |
