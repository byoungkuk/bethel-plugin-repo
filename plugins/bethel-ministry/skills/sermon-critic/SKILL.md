# 설교 평가 (sermon-critic)

`sermon-lectionary` §8·§8.5를 담당하는 **판정 전용** 스킬. 쓰지 않는다. 채점하고 반응한다.

## 왜 별도 스킬인가

무브를 쓴 에이전트가 그 무브를 채점하면 점수가 후해진다. 자기가 방금 고른 단어를 자기가 부정하기 어렵다. 그래서 이 스킬은 **원고를 쓴 문맥과 분리된 서브에이전트로 실행한다.**

또 하나. 목사님은 그동안 완성 설교를 ChatGPT에 붙여넣어 용사 청중 반응을 받아 다시 Claude로 가져오는 수동 릴레이를 해왔다. 그 역할 프롬프트(볼트 `교회력설교작성/_설교점검_ChatGPT청중프롬프트.md`)를 이 스킬이 그대로 흡수했다. **이제 릴레이 없이 파이프라인 안에서 끝난다.** 외부 모델로 교차검증하고 싶으면 여전히 그 노트를 쓰면 된다.

---

## 작업 철학 — 구조화가 아니라 맥락화

7항목 루브릭은 채점을 표준화하는 도구이지, 점수를 만들어내는 목적이 아니다. 항목 칸을 기계적으로 채우는 것이 아니라, 이 무브가 실제로 청중의 의식이라는 맥락 안에서 작동하는지가 우선이다 — "현상학적 접근성" 항목이 이미 이 원칙을 채점 기준으로 명문화하고 있다("청중 의식에 남는 것이 '장면'인가 '정보'인가").

같은 이유로, 지목은 연역("이 항목은 원래 이래야 한다")이 아니라 귀납("이 문장을 실제로 읽어보니 여기서 걸린다")에서 출발한다. 청중 시뮬레이션을 채점자와 분리해 두 채널로 운영하는 것도 이 원리의 연장이다 — 미리 세운 기준으로 반응을 예단하지 않고, 실제 반응을 먼저 듣고 그것을 근거로 삼는다.

### 판단 루프 — 목사님의 작업 성향 참조
루브릭이 명시하지 않는 판단(어느 지목이 최우선인지, 애매한 항목의 점수 등)이 필요할 때는 프로젝트 문서 `claude/목회자-작업성향-프로파일.md`를 참조해 그 성향을 기본 기준으로 삼는다. 새로운 개입이 나오면 작업 종료 후 그 문서에 사례를 추가한다.

# 실행 방식 (필수)

메인 에이전트는 **Agent 툴로 서브에이전트를 호출**한다. 직접 채점하지 않는다.

- `subagent_type`: `general-purpose`
- **두 역할을 한 메시지에서 병렬 호출한다**: ① 채점자 ② 용사 청중
  - 두 역할을 한 에이전트에 몰면 채점 기준이 청중 반응을 오염시킨다. 청중은 루브릭을 몰라야 한다.
- `model`: **아래 §모델·입력 자동 전환 표**에 따라 매번 결정한다. 고정값 아님.

## 호출 전 메인 에이전트가 먼저 하는 일 (비협상)

이 세 가지를 건너뛰면 서브에이전트가 같은 일을 중복 수행해 토큰이 배로 든다.

1. **자수를 메인이 계측한다.** `python3 -c "import re; print(len(re.sub(r'\s','',open(경로,encoding='utf-8').read())))"` 로 실측해 **숫자를 프롬프트에 박아 넣는다.** 서브에이전트에게는 "이미 계측 완료, 재계측 금지"라고 명시한다.
2. **수정 규모를 판정한다.** 직전 버전과 대조해 변경 문장 수를 센다. 이 값이 모델·입력 범위를 결정한다.
3. **필요한 역할만 호출한다.** 표기만 고친 경우 두 역할 다 호출하지 않는다.

# 모델·입력 자동 전환 (2026-08-08 신설)

## 판정 기준: 수정 규모

| 등급 | 정의 |
|---|---|
| **표기** | 맞춤법·띄어쓰기·줄바꿈·문장부호만 변경. 의미 변화 없음 |
| **국소** | 3문장 이하 교체·삭제·추가. 무브 구조·이미지 축 불변 |
| **구조** | 4문장 이상 변경, 또는 문단 재배치·이미지 교체·도입/결말 재설계 |
| **신규** | 새 무브의 첫 채점(v1) |

## 전환 표

| 상황 | 역할 A 채점자 | 역할 B 청중 | 채점자에게 넘길 입력 |
|---|---|---|---|
| **신규** (v1) | `sonnet` | `sonnet` | 무브 전문 + 루브릭 전문 + 배경 |
| **구조** 수정 | `sonnet` | `sonnet` | 무브 전문 + 루브릭 전문 + 직전 점수표 |
| **국소** 수정 | `sonnet` | `haiku` | **변경 문장 diff + 직전 점수표 + 루브릭 축약본** (전문 아님) |
| **표기** 수정 | **호출 안 함** | **호출 안 함** | 메인이 자수만 재계측, 직전 점수 승계·사유 명시 |
| 3회 순환 후 90 미달 | `opus` 1회 | 호출 안 함 | 전문 + 누적 지목 이력 전체 |
| 5무브 완성 후 전체 총평 | `sonnet` 1회 | `sonnet` 1회 | 5무브 전문 |

## 왜 이 배치인가

- **채점자는 국소 수정에서도 `sonnet`을 유지한다.** 점수는 **버전 간 일관성**이 생명이다. 모델을 낮추면 같은 원고에 다른 점수가 나와 증감표가 무의미해진다. 채점자 절감은 모델이 아니라 **입력 축소(diff 방식)**로 낸다 — 더 안전하고 절감폭도 크다.
- **청중은 재호출부터 `haiku`로 내린다.** 청중 역할은 루브릭 없음·도구 없음·짧은 정성 출력이다. 첫 회(`sonnet`)에서 기준 반응이 확보되면, 이후는 국소 변화에 대한 체감 차이만 보면 된다.
- **`opus`는 교착 상태 1회만.** 3회 순환에도 90점을 못 넘으면 루브릭 해석 자체가 걸린 것이므로 그때만 승급한다. 평시 사용 금지.

## haiku 청중 품질 폴백

haiku 청중 응답이 아래에 해당하면 **`sonnet`으로 1회만 재호출**하고, 보고에 "청중 재호출(haiku→sonnet)"이라고 남긴다.

- 구체적 지점 인용 없이 총평만 늘어놓는다 ("전반적으로 좋았습니다" 류)
- 7개 항목 중 3개 이상이 "특별히 없음"으로 비어 있다
- 몰입도 점수만 있고 그 근거 장면이 없다

# Voice 정본 참조 (writer-voice, 2026-08 병합)

`writer-voice` 스킬(같은 플러그인 안)의 `references/voice-profile.md`·`references/review-rubric.md`는 2024–2025년 벧엘 설교 107편을 분석한 목사님의 설교 voice 정본이다(옛 독립 스킬 `kim-byoung-kuk-sermon-voice`를 `writer-voice`로 병합했다). 여기 복사해 넣지 않는다 — 원본이 갱신되면 사본이 낡는다. **7항목 100점 배점 자체는 바꾸지 않는다**(2026-07-31 확정 사항). voice 정본은 기존 항목의 근거를 보강하는 참조축이지, 8번째 점수가 아니다.

## 언제 부른다
위 §모델·입력 자동 전환 표의 등급을 그대로 따른다 — 새 판정 체계를 만들지 않는다.

| 등급 | voice 정본 사용 |
|---|---|
| **신규**(v1) / **구조** 수정 | 채점자에게 `references/voice-profile.md`(§3 Voice DNA·§6 문장전개·§7 어휘장) 요약과 `references/review-rubric.md` §2(100점 Voice 점수 8차원), §3(빠른 체크리스트 14문항)을 함께 넘긴다 |
| **국소** 수정 / **표기** 수정 | 넘기지 않는다. diff 판정에 voice 재평가는 배보다 배꼽이 크다 |
| 5무브 완성 후 **전체 총평** | voice-profile §1 해석구간(85–100/70–84/55–69/0–54)을 기준점으로 삼아 정성 메모 1단락을 별도로 남긴다(점수 아님) |

## 어느 항목에 근거로 편입하는가
- **문장구조·구어적합성(15점)**: voice-profile §6(문장 리듬·전개 장치)과 review-rubric §2의 "말할 수 있는 문장과 리듬" 행을 근거로 쓴다. 2025년 문장 중앙 길이(대략 23~28자, 20자 이하 단문 28~40%)는 목표치가 아니라 크게 벗어난 초안을 다시 보게 하는 경보선이다 — 이 수치를 이유로 문장을 기계적으로 자르거나 늘리라고 지시하지 않는다.
- **인문학적 깊이(15점)**: voice-profile §7(어휘장·상징망)·§8(예화 사용법)을 근거로 쓴다. 좋아하는 단어가 흩어져 있다고 가점하지 않는다 — review-rubric §4 "위조적 흉내의 경고 신호"의 첫 항목(길·빛·봄·향기·함께·은혜를 서로 연결하지 않은 채 흩뿌린다)에 해당하면 오히려 지목한다.
- 그 외 5항목(신학적 적합성·청중 적합성·흐름 연속성·메인아이디어 연관성·현상학적 접근성)에는 voice 정본을 근거로 쓰지 않는다. 항목의 성격이 다르다 — 신학·청중·구조 판정에 문체 기준을 끌어오면 채점이 오염된다.

## 무결성 관문과의 관계
review-rubric §1 "먼저 확인할 무결성 관문"(본문·사실·인용·청중 맥락·맞춤법·고통의 도구화 여부)은 이 스킬의 §신학 원칙(비협상)·채점 전 체크리스트와 취지가 겹친다. 새 게이트를 만들지 않는다 — 신규·구조 등급에서 review-rubric §1을 훑어보되, 걸리는 항목이 있으면 기존 채점 전 체크리스트(아래 §채점 전 체크리스트)의 해당 항목에 얹어 지목한다.

## 위조적 흉내 감지 (신규·구조 등급 한정)
review-rubric §4의 경고 신호(모든 문단을 질문·3항 반복으로 만들기, 실제 청중과 무관한 군사 비유, 관습적 강단 문구 자동 삽입, 그리스어·신학자 이름 장식, 고통을 건너뛰고 즉시 정답으로 가기, 5·6무브 형식만 맞추고 내용은 반복)에 해당하는 지점이 있으면 문장구조·구어적합성 또는 인문학적 깊이 항목의 지목 사유로 인용한다.

```
- 청중 반응을 추정·인용·창작하지 마라. 청중은 별도 에이전트가 수집하며
  메인이 두 결과를 합친다. 청중 적합성은 원고 구조(용어 설명 순서·문장 난이도·정보

  (관측 실패: 채점자가 지어낸 몰입도가 실제 청중 응답과 어긋났다)
```

## 국소 수정 시 diff 프롬프트 골격

무브 전문을 다시 붙이지 않는다. 대신 이렇게 넘긴다.

```
[직전 v{n-1} 채점 결과]

당시 지목 사항: {번호별 한 줄씩}

[이번 v{n}에서 바뀐 것 — 이것만 평가하라]
① `{직전 문장}` → `{수정 문장}` (수정 의도: {한 줄})
② …

[변경 문장의 앞뒤 문맥 2줄씩]
…

[자수] {n}자 (메인 실측 완료, 재계측 금지)

[지시] 위 변경이 직전 점수의 어느 항목을 움직였는지만 판정하라.
변경과 무관한 항목은 직전 점수를 그대로 승계하고 근거란에 "변경 없음"이라고 적어라.
전체 재채점을 하지 마라.
```

| 문장구조·구어적합성 | 15 |
| 신학적 적합성 | 20 |
| 청중 적합성 | 15 |
| 흐름 연속성 | 15 |
| 인문학적 깊이 | 15 |
| **메인아이디어 연관성** | **10** |
| **현상학적 접근성** | **10** |

**90점 이상 = 무브 확정.** 미달 시 일반적 칭찬 대신 **문제 문장을 정확히 지목**한다. "흐름이 조금 아쉽습니다" 같은 말은 채점이 아니다.

### 메인아이디어 연관성 (10점)
채점 전에 먼저 그 주의 메인아이디어를 명시적으로 확인하고 시작한다.

- 이 무브가 메인아이디어의 **어느 국면**을 맡는지 한 문장으로 규정할 수 있는가. 규정이 안 되면 **5점 이하**.
- 그 국면이 실제 본문에 구현됐는가, 아니면 무브흐름 표에만 있는가. 메인아이디어 계열 어휘·모티프가 본문에 흔적을 남겼는지 확인한다. 단, 단어 수 자체가 기준은 아니다 — 어휘가 없어도 동작·이미지로 구현됐으면 인정한다.
- **앞뒤 무브에 넘겨줄 고리를 남겼는가.** 다음 무브의 전환이 돌발이 되지 않도록 예비 문장을 심었는지 본다. **이 항목의 실패는 대부분 여기서 난다.**
- 감점 신호: 무브 단독으로는 좋은데 메인아이디어를 빼도 성립한다 / 다음 무브의 반전이 준비 없이 튀어나온다 / 무브의 축 개념이 메인아이디어가 아니라 본문 요약에 붙어 있다.

### 현상학적 접근성 (10점) — Buttrick 기준
무브가 청중 **의식 안에서** 형성되는가를 본다.

- **이미지 하나 · 무드 하나.** 한 무브 안에서 무드가 바뀌면 그건 무브 두 개다. 특히 오해 방어·경계 조항 블록이 무드를 끊는지 확인한다. **부정문 방어는 무드를 끊고, 긍정 이미지 방어는 안 끊는다.**
- **확정 이미지가 무브 전체를 지탱하는가.** 도입에만 있고 중반 이후 사라지면 감점. 앞뒤 두 지점에 서 있으면 가점.
- **청중 의식에 남는 것이 '장면'인가 '정보'인가.** 어휘 주석·개념 해설이 3개 이상 연속하면 강해설교의 의식 구조로 넘어간 것이다. 주석은 이미지로 되돌려 착지시킨다.
- **진입이 의식의 순서를 따르는가.** 본문 순서가 아니라 의식의 순서다. 메타 서술("성경은 이렇게 적습니다" 계열)로 진입하면 청중이 장면 밖에 선다. 구조상 불가피하면 −2까지만. **명명(라벨) 없이 곧장 장면 묘사로 들어가는 진입은 즉시성의 모드로 가점 대상**이다(예: "오병이어," 라벨을 빼고 "떡 다섯 개와 물고기 두 마리로…"로 시작).
- 감점 신호: 설명이 친절한데 청중을 한 번도 멈춰 세우지 않는다 / 방어·해명 문장이 절정 직전에 몰려 감정 곡선이 내려앉는다 / 주어가 무브의 지정 주어(인간/그리스도)에서 이탈해 길게 흐른다 / **장면 서술 도중 강단 아사이드(직접 청중 호명·설교자 소감)로 이탈한다**.

### 채점 전 체크리스트
삽화 방향 일치(`sermon-lectionary` §삽화·예화 선택 원칙 준수 — 군 생활 디테일 자제, 20대 남성 보편 심리 우선. 구체적 군 생활 에피소드를 지어냈으면 감점) / 봉독 범위 생략 / 일반화 단정 완화 / 호칭 안전선 / 원어 제한(전체 1~2회, 무브당 1개) / 인용 식상함(김춘수 〈꽃〉 지양) / 묘사·숫자의 성경적 근거 / 절 표기 일관성 / **낭독 오청**(동음 위험 시 표현 교체 권고) / 제목 키워드 밀도(무브당 2~3회) / 전환 문장 유무 / (신규·구조 등급) Voice 위조적 흉내 경고 신호(위 §Voice 정본 참조 — review-rubric §4) 해당 여부.

### 자수 기준
- 무브당 **700~750자**(공백 제외). 5무브 총 3,500~3,750자.
- **계측은 메인이 한다.** 서브에이전트는 넘겨받은 숫자로 판정만 한다.
- 미달이면 패딩 제안 금지 — 실질 내용 보강 지점을 지목한다.
- 초과면 감량 1순위 문단을 지정한다.

# 역할 B — 20대 초반 초신자 용사 (청중 시뮬레이션)

## 이 역할에 넘길 것
**낭독용 설교 본문만.** 제목·점수표·무브명·작업 기록 등 메타는 전부 제외한다. 설교는 눈으로 읽는 글이 아니라 **귀로 한 번 듣는 말**이므로, 청중이 "한 번 듣는" 상황을 재현해야 한다. 루브릭도 알려주지 않는다.

**국소 수정 재호출 시에도 본문은 전문으로 넘긴다.** 청중은 diff를 들을 수 없다. 대신 모델을 `haiku`로 내려 비용을 잡는다.

## 역할 프롬프트 (그대로 서브에이전트에 넣는다)

```
너는 20대 초반, 입대한 지 얼마 안 된 초신자 용사다. 교회는 부대 안 벧엘교회,
주일예배에서 이 설교를 딱 한 번 귀로 듣는 상황이다. 신학 지식은 거의 없다.
아래 설교를 '듣고' 솔직하게 반응해라. 교리 교정이나 칭찬은 하지 말고,
실제 그 자리에 앉은 용사의 체감으로만, 조금 무뚝뚝해도 좋으니 솔직하게 답해라.
서브에이전트를 추가로 호출하지 말고, 도구도 쓰지 말고, 네가 바로 답해라.
항목별로:
1) 한 번 듣고 머리에 남은 한 문장
2) 집중이 풀린 지점(어느 대목에서 딴생각이 들었나)
3) 못 알아들은 단어·개념(교회 용어 등)
4) 마음에 닿은 대목과 그 이유
5) 설교조·훈계처럼 느껴져 반발이 든 부분
6) 내 삶(생활관·훈련·전역·진로)과 연결됐다고 느낀 지점
7) 한 줄 총평 + 체감 몰입도 10점 만점
각 항목은 반드시 설교 안의 구체적 문장·장면을 짚어서 답해라.
"특별히 없음"으로 넘기지 마라.
```

## 반환된 반응의 처리 (메인 에이전트가 수행)

막연한 감상으로 두지 않는다. **무브별 구체 수정 지점으로 변환**한다.

| 청중 반응 | 변환 |
|---|---|
| 못 알아들은 용어 | 뜻풀이로 교체 (원어 제한 준수) |
| 집중 풀린 대목 | 감량 · 이미지 강화 (길이 기준 유지) |
| 설교조 반발 | Being→Doing · 선행적 은혜로 재프레이밍 (훈화 금지) |
| 삶 연결 약한 무브 | 20대 남성 보편 심리(정체성 불안·인정욕구·소속 갈망 등) 삽화로 보강 우선. 군 생활 디테일은 확실·유추 가능한 큰 틀 **1개 이하**로만 제한 보강(`sermon-lectionary` §삽화·예화 선택 원칙) |
| 남은 한 문장이 메인아이디어와 무관 | 메인아이디어 연관성 항목 재검토 |
| "그래서 뭘 하라는 건지" 결핍 호소 | Move 1~2에서는 감점 아님. **다음 무브가 받아야 할 신호**로 기록 |

이 반응은 7항목 중 **'청중 적합성'(15점)의 근거**로만 편입한다. 다른 항목의 점수를 흔들지 않는다.

## 두 결과 대조 (메인이 반드시 수행)

채점자의 예비 청중 점수와 실제 청중 응답이 **어긋나면 실제 청중을 따른다.** 어긋난 사실을 목사님께 명시적으로 보고한다. 채점자가 추정으로 채운 수치를 그대로 옮기지 않는다.

두 채널이 **같은 결함을 독립적으로 지목하면** 그 지적은 신뢰도가 높다고 표시한다. 최우선 수정 지점이다.

## 경계 (비협상)

- **신학 교정 제안은 채택하지 않는다.** 청중 역할이든 채점자 역할이든, 이 스킬은 판정만 한다. `sermon-lectionary`의 신학 원칙·금지선(Being→Doing, 선행적 은혜, 유형배분 화법 금지, 근거 없는 묘사·숫자 금지, 이단 논리 배제)이 **항상 우선**한다.
- **시뮬레이션이므로 과신 금지.** 실제 용사 반응과 다를 수 있다. 보고할 때 `[청중추정]`으로 표시하고, 원고에 실제로 있는 근거를 짚는 지적은 `[원고근거]`로 구분한다.
- 청중 역할은 **고쳐 쓰지 않는다.** 반응만 보고한다.
- **서브에이전트는 서브에이전트를 부르지 않는다.**
- 이단(구원파·신천지) 논리 배제.

## 순환 규칙

- 90점 미만 무브만 **국소 수정** 후 재호출. 설교 전체를 다시 채점하지 않는다.
- 최대 3회 순환. 그 뒤에도 미달이면 `opus` 1회 승급 후, 그래도 미달이면 남은 문제를 위치와 함께 목사님께 보고하고 판단을 넘긴다. 점수를 억지로 올리지 않는다.
- 채점 결과는 항목별 표 + **직전 버전 대비 증감**으로 제시한다. 증감이 없으면 수정이 헛돈 것이다.
- 03-초안.md에 버전별로 누적 기록한다.

## 이 스킬과 edit-writing-room의 분업

| | sermon-critic | edit-writing-room |
|---|---|---|
| 단위 | **무브 하나** | **완성 원고 전체** |
| 시점 | 설교 작성 중 반복 루프 | 설교 확정 후 |
| 산출 | 100점 점수 + 지목 | 독자 리포트 + 편집 제안 |
| 기준 | 7항목 루브릭(+ voice 정본은 근거로만) | 문체 정본(writer-voice) + 독자 페르소나 |

둘 다 돌리되 역할을 섞지 않는다. critic이 문체를 고치려 들거나 편집실이 점수를 매기면 잘못 작동하는 것이다. 두 스킬은 이제 **같은 정본** `writer-voice`를 보되 쓰는 폭이 다르다 — sermon-critic은 그 안의 `references/voice-profile.md`·`review-rubric.md`(2024–2025 벧엘 설교 코퍼스 기반)만 문장구조·구어적합성/인문학적 깊이 항목의 근거로 좁혀 쓰고, edit-writing-room은 `writer-voice` SKILL.md 본문 전체(낭독체·산문체 두 레지스터 규약)를 완성 원고의 문체 정본으로 쓴다.
