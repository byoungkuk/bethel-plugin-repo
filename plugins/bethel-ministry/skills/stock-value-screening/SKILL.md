# 오일전문가 종목 선정 점수표 (Stock Value Screening)

싱글파이어 영상에 소개된 "오일전문가" 종목 선정 점수표를 그대로 적용해, 한 기업을 장기 가치투자 관점에서 **100점 만점으로 채점**하고 A~D 등급으로 해석하는 도구다.

## 가장 먼저 — 한계와 면책 (작업 전 반드시 인지)

- 이 점수표는 **영상 원작자(오일전문가)의 개인적 기준**이다. 보편 정답이 아니다.
- 이 스킬은 **투자 자문이 아니다.** Claude가 직접 매수·매도를 권유하지 않는다.
- 점수는 공개 재무지표를 정형화한 참고 정보일 뿐, 미래 수익을 예측하지 못한다.
- 높은 점수가 좋은 투자라는 보장이 아니다. **싸게 보이는 데는 이유가 있을 수 있다**(가치함정).
- 모든 산출물 끝에 아래 면책 문구를 그대로 붙인다:

> ⚠️ 본 점수·등급은 영상에 소개된 한 개인의 종목 선정 기준을 적용한 참고 정보이며, 투자 자문이나 매수·매도 권유가 아닙니다. 모든 투자 판단과 책임은 전적으로 본인에게 있습니다. 최신 수치는 공시(DART)·거래소(KRX)·증권사 자료로 직접 확인하십시오.

## 작업 순서

1. **대상·기준일 확정** — 어떤 기업, 어느 시점 기준인지 확인한다.
2. **데이터 확보** — 사용자가 수치를 주면 그대로 쓰고, 없으면 web_search로 최신 공개 수치(KRX, FnGuide, 증권사, DART)를 찾아 출처·기준일을 함께 기록한다. **수치를 못 구하면 추정하지 말고 "데이터 없음"으로 표시한다.**
3. **정성 항목 판단** — 점수표에는 정성적 판단 항목(이익 지속성, 미래 성장 잠재력, 기업 경영, 세계적 브랜드)이 있다. 근거(사업보고서·뉴스·업황)를 들어 보수적으로 매긴다. 근거가 약하면 그 사실을 명시한다.
4. **세 영역 채점 (100점)** — 아래 점수표대로 항목별 점수를 합산한다.
5. **등급 산출 + 해석** — 등급표로 A~D를 정하고, 고정 출력 양식으로 정리한 뒤 면책 문구를 붙인다.

## 점수표 (100점 만점)

각 항목에서 해당 구간의 점수 하나를 고른다. 비교 지표(PER·PBR 등)는 가능하면 **동종 업종 맥락**도 함께 언급한다.

### ① 이익 창출력 / 저평가 여부 / 지속 가능성 — 35점

| 항목 | 구간 → 점수 | 배점 |
|---|---|---|
| PER | <5 → 20 / <8 → 15 / <10 → 10 / >10 → 5 | 20 |
| PBR | <0.3 → 5 / <0.6 → 4 / <1.0 → 3 / >1.0 → 0 | 5 |
| 이익이 지속 가능한가? (정성) | 대체로 지속 가능 → 5 / 불안정한 이익 창출력 → 0 | 5 |
| 중복 상장 여부 (자회사·손자회사 상장) | 중복 상장 → 0 / 단독 상장 → 5 | 5 |

### ② 미래 성장 잠재력 / 기업 경쟁력 — 25점

| 항목 | 구간 → 점수 | 배점 |
|---|---|---|
| 미래 성장 잠재력 (정성) | 매우 높다 → 10 / 높다 → 7 / 보통 → 5 / 낮다 → 3 | 10 |
| 기업 경영 (정성) | 우수한 경영자 → 10 / 전문 경영자 → 5 / 저조한 실적 오너 경영 → 0 | 10 |
| 세계적 브랜드 보유 여부 | 있다 → 5 / 없다 → 0 | 5 |

### ③ 주주환원 의지 — 40점

| 항목 | 구간 → 점수 | 배점 |
|---|---|---|
| 배당수익률 | >7% → 10 / >5% → 7 / >3% → 5 / <3% → 2 | 10 |
| 분기 배당을 실시하고 있는가? | 예 → 5 / 아니요 → 0 | 5 |
| 배당 연속 인상 연수 (배당 동결 시 연속은 인정, 인상은 불인정) | 10년 이상 → 5 / 5년 이상 → 4 / 3년 이상 → 3 / 해당없음 → 0 | 5 |
| 정기적 자사주 매입·소각 여부 (최소 연 1회 이상) | 예 → 7 / 아니요 → 0 | 7 |
| 소각한다면, 연간 소각 비율 (총주식수 대비) | >2% → 8 / >1.5% → 5 / >0.5% → 3 / <0.5% → 0 | 8 |
| 자사주 보유 비율 | 없음 → 5 / <2% → 4 / <5% → 2 / >5% → 0 | 5 |

> ※ "자사주 보유 비율"은 **보유 자체보다 소각을 선호**하는 원작자 논리상, 자사주를 쌓아두지 않은 쪽(없음=5)에 높은 점수를 준다.

**총점 = ① + ② + ③ (100점 만점)**

## 등급표 (영상 원작자 기준)

| 총점 | 등급 | 원작자 설명 |
|---|---|---|
| 80점 초과 | A | 장기투자 적합 · 적극 매수 |
| 70 ~ 80점 | B | 장기투자 적합 · 매수 고려 |
| 50 ~ 70점 미만 | C | 장기투자 유지 (홀딩) |
| 50점 미만 | D | 장기투자 추천하지 않음 |

> 등급 경계: 정확히 80점은 B, 정확히 70점은 B, 정확히 50점은 C.
> "적극 매수" 등의 표현은 **원작자의 기준 명칭**이다. Claude는 이를 그대로 권유하지 않으며, 종합 해석은 분석적 서술로 작성한다(아래 작성 원칙 참조).

## 출력 양식 (항상 이 구조로)

```
# [기업명] 종목 선정 점수표 (오일전문가 기준)
- 기준일 / 데이터 출처: ____
- 업종: ____

## ① 이익 창출력·저평가·지속가능성 ( __ / 35 )
   PER __ → __ / PBR __ → __ / 이익지속 __ / 중복상장 __
## ② 미래 성장·기업 경쟁력 ( __ / 25 )
   성장잠재력 __ / 기업경영 __ / 세계적 브랜드 __
## ③ 주주환원 의지 ( __ / 40 )
   배당수익률 __ / 분기배당 __ / 배당연속인상 __ / 자사주매입·소각 __ / 소각비율 __ / 자사주보유 __
──────────────────────────────
총점 __ / 100  →  [등급 A~D] (원작자 기준: ____)

## 정성 판단 근거 (정성 항목을 어떤 근거로 매겼는지)
## 강점 (점수 높은 항목)
## 확인 필요 (점수 낮은 항목 + 데이터 없음 항목)
## 보조 점검 — 가치함정·데이터 신뢰성
   - 싼 이유가 구조적인가(사양산업·규제·수요감소)?
   - 일회성 이익·산업 사이클 고점 착시 여부
   - 적자/자본잠식이면 PER·PBR·ROE 왜곡 주의
## 종합 해석 (2~3문장, 분석적 서술. 사라/팔라 직접 명령 금지)

⚠️ [면책 문구 그대로]
```

## 작성 원칙

- **추정 금지.** 수치를 못 구하면 "데이터 없음"으로 적고, 그 항목은 0점이 아니라 미산정으로 표시한 뒤 총점 해석 시 한계를 명시한다.
- **정성 항목은 근거와 함께.** "미래 성장 잠재력 높음" 같은 판단은 반드시 근거(업황·사업보고서·뉴스)를 댄다. 근거가 약하면 보수적으로, 그리고 그 불확실성을 밝힌다.
- **권유 표현 자제.** 등급 라벨(적극 매수 등)은 원작자 기준으로 인용·표기하되, Claude 자신의 종합 해석에서는 "사라/팔라/지금이 기회" 대신 "~지표가 양호하다 / ~를 추가 확인할 필요가 있다"는 분석적 서술을 쓴다.
- **가치함정을 반드시 점검한다.** 이 점수표는 정량 비중이 크므로, 싼 이유가 구조적 쇠퇴인지 별도로 확인한다.
- **면책 문구를 모든 산출물에 붙인다.**

## 출처

- 싱글파이어(SINGLE FIRE) 유튜브 영상 "1년만에 17억 자산 증식한 장기투자자의 저평가 우량주 찾는 방법"에 소개된 "오일전문가" 종목 선정 점수표.
- 배점·구간·등급표는 사용자가 제공한 영상 캡처 6장을 그대로 옮긴 것이다.
