## §1. 원문 분석
절별로: 원문 → 직역 → 주요 단어 해설(품사·어근·의미 스펙트럼) → 신학적 함의.
동사 시제·태, 접속사·전치사 기능, 강조 구문(이중 부정·조건절·비유 도입 공식) 포함.

## §3. 4본문 통합 메인아이디어
- 4본문(구약·시편·서신·복음서)이 공명하는 하나의 신학적 긴장 + 초신자 보편 질문 + 개인 구원과 공공성 동시 포함.
- 명제(문장) 형태. 형식: "[인간 현실]에도 불구하고/속에서 [하나님의 행동]이 [어떻게] 작동한다"
- 단, 목사님이 표제어(단일 명사·동명사)를 지정하면 그것을 따른다.
💾 00-본문연구.md 하단 + 01-개념망.md 상단

## §4. BMF 36개념망 (6×6)
- 메인아이디어 중심 6무브 흐름 × 6회, 전 개념 중복·유사 금지.
- 흐름별 각도 분산: 일상 경험 / 본문 역설 / 사회·문화 비판 / 내면 심리 / 하나님 성품 / 공동체·공공성.
- C6열은 복음적 전환(그리스도 능동 동사). 형식: `C1: [개념] - [한 줄 설명]`.
- 개념 품질: 한 단어 명명 가능 / 무브 하나를 지탱할 무게 / 청중 경험과 연결 가능. 근거 약한 개념은 ★ 표시로 기록.
💾 6×6 표 → 01-개념망.md

## §6. 3대지
설교는 3대지로 쓰지 않지만 구조 뼈대로 3개념 확정: 메인아이디어를 가장 명확히 드러내고, 신학적 무게가 있고, 서로 균형(삼각 구조). 각 대지의 역할·신학적 의미·관계성 서술.
💾 02-무브흐름.md 이어서

## §7. Breaking & Twisting
- Breaking ×3: 기존 해석 틀을 깨는 질문 ("정말 이 본문은 ___을 말하는가?")
- Twisting ×3: 관점 180도 전환 ("주인공이 ___라면?", "본문이 말하지 않는 것은?")
- 각 질문에 2~4문장 답변(초안에 반영될 창발적 통찰).
💾 02-무브흐름.md 마지막 섹션

## §8.5. 외부 청중 피드백 수용 (선택 — 요청 시)
8단계로 5무브를 확정한 뒤, 9단계 총평 전에 실행하는 교차검증 단계. 외부 모델(ChatGPT 등)에 "20대 초반 초신자 용사 청중"의 한-번-듣는 반응을 시뮬레이션시켜 청중 적합성을 점검한다. 별도 에이전트·하네스 불필요 — 수동 릴레이(목사님이 ChatGPT에 붙여넣고 답을 다시 Claude로 가져옴).
- 넘길 자료: **낭독용 설교 본문만**(제목·점수표·작업기록 제외). "정독 비평가"가 아니라 "한 번 듣는 청중"으로 반응하도록 지시.
- 역할 프롬프트 원본: 볼트 `교회력설교작성/_설교점검_ChatGPT청중프롬프트.md` (7항목: 남은 한 문장 / 집중 풀린 지점 / 못 알아들은 용어 / 닿은 대목 / 설교조 반발 / 삶 연결 / 한줄총평+10점).
- 되받은 피드백 처리: 8단계 평가 루프의 '청중 적합성'(20점) 축 근거로 편입. 막연한 감상이 아니라 무브별 구체 수정 지점으로 변환한다.
  - 못 알아들은 용어 → 뜻풀이 교체(원어 제한 준수) / 집중 풀린 대목 → 감량·이미지 강화(길이 기준 유지) / 설교조 반발 → Being→Doing·선행적 은혜로 재프레이밍(훈화 금지) / 삶 연결 약한 무브 → 청중 맥락 삽화 1개 이하 보강.
- 수정 후 해당 무브 재채점(≥90 유지).
- 경계: 외부 모델의 **신학 교정·해석 제안은 채택하지 않는다**(청중 반응만 취함). 스킬의 신학 원칙·금지선(유형배분 화법·근거 없는 묘사·이단 논리 등)이 항상 우선. 시뮬레이션이므로 과신 금지 — 실제 용사 반응과 다를 수 있다.
