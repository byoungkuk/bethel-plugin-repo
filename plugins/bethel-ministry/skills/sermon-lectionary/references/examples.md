# 확립 사례·패턴 (4~5단계 참고용 — 필요 시에만 읽을 것)

## 1. 기준 사례: 성령강림절후 3주 〈환대〉 (마 9:35-10:8, 2026.6.14)
- 5무브: 다가섬(환대)–바라봄(연민)–부르심(제자)–보내심(사도)–흘러감(통로). 첫 부제 = 메인아이디어.
- 6→5 압축: 권능(10:1)+선포(10:7) = 하나의 '보내심' 장면 → 병합 채택. '내어줌'은 마지막 무브와 의미 겹침 → 기각.
- 제목 "Take and Give - 거저 받았으니 거저 주라": 1차 5유형 전부 미채택 → 어순 전복형 재추천에서 채택. 외래어 3중 검증(원형 보존 / λαμβάνω 의미 폭 / 한국어 부제 보정) 통과.
- 체크리스트 유래 사례: 아브라함 환대 삽화가 무브 방향(하나님이 먼저 오심)과 역방향 → "그 나그네는 하나님이셨다" 반전 추가로 해결 / 9:37-38 봉독 생략분을 전환부에 삽입 / "당시 종교는 기다리는 종교였다"(단정) → "성전까지 가야만 한다고 믿었습니다"(신념 진술).
- 최종 무브당 790~897자·총 4,196자 (구기준. 현행은 700~750/3,500~3,750).

## 2. 두 번째 사례: 성령강림절후 7주 〈그럼에도불구하고〉 (마 13:1-9,18-23, 2026.7.12)
- 5무브: 등돌린날–숨막힌나–나아가심–풀어주심–맺게하심 (소리: 날·나·심·심·심. 앞 2 = 인간의 자리, 뒤 3 = 그리스도 행위).
- 메인아이디어 크레셴도: M1–M2 봉인 → M3 첫 등장 → M4 1회 → M5 2회. 수미쌍관(M1 끝 문장 ↔ M5 끝 문장 반전).
- 표제어 규칙의 명명된 예외: 개념어('역설') 대신 고백적 어조('그럼에도불구하고') 채택.
- 유형 배분 화법 금지 확립: "여러분 중 어떤 사람은…" 대신 한 의식이 세 국면을 차례로 통과.

## 3. BMF 개념망 압축 사례
- 눅 14:25-33 "값비싼 은혜": 동행–선택–무게–비용–정체성 (3대지: 동행·비용·정체성)
- 눅 14:1,7-14 "낮은 자리의 VIP": 자리–분류–가치–임재–섬김–초청 (3대지: 분류·임재·초청)
- 눅 12:49-56 "분별의 불": 관점–이율배반–갈등–징조–방향전환 (3대지: 이율배반·징조·방향전환)

## 4. 무브 전개 패턴
- C1(도입): 청중 관찰/일상 경험 → 보편 경험 → 본문 진입. 신학 선언은 C1 후반부에만.
- 반전 무브: 세상 논리 제시 → 예수님의 다른 방식 → 하나님 나라 원리 선언.
- 마지막 무브: 선택의 순간 → 정체성 선언(권면 아님) → 소망 마무리.

## 5. 인문학·삽화 소재 풀
- 디지털: SNS 알고리즘·팔로워·인플루언서 / AI / 게임 랭킹
- 사회: 번아웃·취업 경쟁·비교·불확실한 미래
- 군 생활(무브당 1개 이하): 훈련소→자대(입문) / 진급(성장) / 생활관 동거(동행) / 당직·경계(깨어 있음)
- 검증된 삽화: 고흐 〈씨 뿌리는 사람〉(거절을 아는 사람의 그림 — 사실 서술까지만) / 바르트 1954 바젤 감옥 설교 'Dennoch'(검증됨) / 김춘수 〈꽃〉은 식상 — 지양.

## 6. 폐회기도 벤치마크
2026.6.21 마 10:24-39 '우리의 사막' 폐회기도가 현행 기준(한 단락 8문장·300자·실존적 어조)의 벤치마크.
구사례(구조형): "…수많은 사람들 가운데 저희를 불러주시고… 자기를 부인하고 자기 십자가를 지고 세상의 가치가 아닌 주님의 은혜를 셈하며 주를 따르는 제자의 길을 걷는 저희들이 되게 하여 주시옵소서…" (눅 14:25-33)

## 7. 위탁의 말씀(파송) 패턴
핵심 정체성 선언 + 공동체적 결단 + 주님의 동행 확인.
예: "우리는 세상이 감당할 수 없는 사람들입니다. 하나님 나라의 평화를 힘입어 살아가는 사람들이기 때문입니다."
