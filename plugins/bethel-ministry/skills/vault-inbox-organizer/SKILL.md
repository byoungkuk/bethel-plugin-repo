# 볼트 인박스 정리 (vault-inbox-organizer)

옵시디언 볼트 `00.Inbox`의 자료를 분류 → 태그·프론트매터 표준화 → 제자리 이동 → 색인 갱신까지 처리하는 워크플로우.

## 전제

- 볼트 경로: `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Vault_BK` (코워크에서 폴더 연결 필요. 연결 안 돼 있으면 먼저 요청)
- **기준 문서**: 볼트 최상위 `00.볼트규칙(태그·프론트매터).md`를 반드시 먼저 읽는다. 태그 체계·프론트매터 양식·파일명 규칙·폴더 구조가 모두 거기 정의돼 있다. 이 스킬과 규칙 노트가 충돌하면 **규칙 노트가 우선**한다 (사용자가 규칙을 갱신했을 수 있으므로).
- 한글 파일명은 NFC/NFD 정규화 문제가 있다. bash에서 경로 매칭이 실패하면 python `unicodedata.normalize('NFC', name)` 비교로 우회한다.

## 작업 순서

### 1단계: 스캔

`00.Inbox`의 전체 파일 목록을 만들고 각 파일에 대해 파악한다:
- 파일 유형 (md / pdf / 이미지 / hwp·hwpx / docx / 기타)
- md는 내용 앞부분을 읽어 주제 파악. 비md는 파일명과 (가능하면) 내용으로 판단
- 기존 프론트매터 유무

`.DS_Store`, 임시 파일(`~$...`)은 무시한다. `cron.log` 같은 시스템 로그 파일은 노트가 아니므로 삭제 후보로 보고만 한다 (직접 삭제하지 않는다).

### 2단계: 분류

파일마다 목적지를 정한다. 판단 기준:

| 신호 | 분류 | 목적지 |
|---|---|---|
| 아침브리핑, 일일 브리핑 | 브리핑 기록 | 30.교회 계열이 아닌 개인 기록 → `20.관심` (또는 규칙 노트에 브리핑 폴더가 지정돼 있으면 그곳) |
| 설교문 (무브 구조, 예배 순서, 본문+제목) | 설교 | `40.설교/42.벧엘주일설교/{년도}/` |
| 성서정과 묵상 | 묵상 | `30.교회/매일묵상/` |
| 본문연구·주석·신학 자료 | 연구 | `50.자료/52.신학/` |
| 독서 메모, 책 요약 | 독서 | `10.공부/독서/` |
| 교육·강의 자료 | 교육 | `50.자료/51.교육/` |
| 스캔·PDF 원문 | 스캔 | `50.자료/53.스캔/` |
| 웹 스크랩, 아티클 | 스크랩 | `50.자료/54.스크랩/` |
| IT·AI·도구 관련 | 테크 | `50.자료/55.테크/` |
| 어느 것도 아님 | 기타/보류 | 보류 목록에 넣고 사용자에게 질문 |

**확신이 서지 않으면 옮기지 않는다.** 내용이 비었거나(`Untitled.md` 등), 두 폴더에 걸치거나, 새 폴더가 필요해 보이는 파일은 "보류"로 분류하고 3단계로 넘어가기 전에 사용자에게 분류 제안과 함께 묻는다. 추측으로 옮긴 파일 하나가 볼트 전체 신뢰를 깎는다.

### 3단계: 프론트매터·태그 부여

규칙 노트의 양식을 따른다. 요점:

- md 노트: 기존 프론트매터를 보존하되 누락 필드를 보충한다. 최소 구성:
  ```yaml
  ---
  date: YYYY-MM-DD        # 파일명·내용·파일 수정시각 순으로 추정
  tags:
    - {유형태그}           # 설교/묵상/연구/리서치 중 1개, 해당 없으면 폴더 성격에 맞는 태그
    - 성경/{구약|신약}/{책}   # 성경 본문이 있을 때만
    - 교회력/{절기}          # 확실할 때만
  ---
  ```
- 태그 신설 전에 볼트에서 기존 태그를 검색해 중복을 피한다 (`grep -r "tags:" -A5` 또는 유사 검색).
- 절기·날짜 등 확신 없는 메타데이터는 **빈칸으로 두고 보고서에 명시**한다. 추정값을 그럴듯하게 채우지 않는다.
- 예외: 설교 노트의 `메인아이디어`가 본문에 명시돼 있지 않으면 제목으로 채운다 (42 아카이브의 기존 관례).

**비md 파일 (pdf, hwp, 이미지 등)**: 파일을 목적지로 옮기고, 같은 폴더에 동반 md 노트를 만든다:
```markdown
---
date: YYYY-MM-DD
tags:
  - {유형태그}
---

# {자료 제목}

> 원본: [[{옮긴 파일명}]]

{2~3문장 요약 — 내용을 읽을 수 있는 경우만. 못 읽으면 파일명 기반 한 줄 설명}
```
동반 노트 파일명은 원본과 같게 하되 확장자만 `.md`.

### 4단계: 이동

- 파일명이 규칙(금지 문자, 형식)에 어긋나면 이동하면서 바로잡는다. 원래 이름은 프론트매터 `원본파일명:` 필드에 남긴다.
- 목적지에 동명 파일이 있으면 덮어쓰지 말고 `-2` 접미사를 붙이고 보고서에 표시한다.
- 이동은 복사 후 검증(파일 존재·크기 확인) 후 원본 삭제 순서로 한다.

### 5단계: 색인 갱신

설교 노트가 `42.벧엘주일설교`로 들어갔으면 `60.색인/벧엘주일설교/`의 색인 3종에 행을 추가한다:
- `00.벧엘주일설교색인.md` — 해당 연도 표에 날짜순 삽입
- `벧엘설교_교회력색인.md` — 해당 절기 표에 삽입 (절기 미상이면 절기미상 섹션)
- `벧엘설교_성경색인.md` — 해당 성경책 표에 장절순 삽입
- `벧엘설교_개념색인.md` — 개념 태그가 있으면 해당 개념 아래 추가

링크 형식은 기존 색인과 동일: `[[파일명|제목]]`. 묵상 노트는 (묵상 색인이 존재할 경우에만) 같은 방식으로 갱신한다.

### 6단계: 보고

작업 후 사용자에게 간결한 표로 보고한다:

```
## 인박스 정리 결과 (N건)

| 파일 | 분류 | 이동 위치 | 비고 |
|---|---|---|---|
| ... | 설교 | 42.벧엘주일설교/2026 | 색인 갱신됨 |

### 보류 (사용자 확인 필요)
- Untitled.md — 내용 비어 있음. 삭제할까요?
```

보류 항목이 있으면 반드시 질문으로 끝내고, 답을 받은 뒤 마무리한다.

## 원칙

- **삭제하지 않는다.** 빈 파일·로그 파일도 삭제는 사용자 승인 후에만.
- **규칙 노트가 진실의 원천이다.** 이 스킬의 표가 규칙 노트와 다르면 규칙 노트를 따르고, 차이를 사용자에게 알려 스킬 갱신을 제안한다.
- **원본 내용을 고치지 않는다.** 프론트매터 추가·보충만 하고 본문은 건드리지 않는다.
- 인박스가 비어 있으면 그렇다고 보고하고 끝낸다.
