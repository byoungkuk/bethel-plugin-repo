# 관문 3: 이미지 제작 진입 검증

lecture-slides 종료 시점에 실행하는 파이프라인 검증 관문. lecture-infographic 진입 전 필수 통과.

## 파이프라인 위치

lecture-plan [관문 1] → lecture-research [관문 2] → **lecture-slides [관문 3]** → lecture-infographic [관문 4]

## 실행 시점

lecture-slides의 모든 Phase가 완료된 직후, 최종 출력물 저장 전에 실행한다.

## 입력 조건 확인 (실행 전)

lecture-slides 시작 시 lecture-research 산출물의 YAML에서 아래를 확인한다.

- [ ] `gate_2_passed: true` 플래그 존재
- [ ] `target_profile` 블록 존재
- [ ] `ab_case_ratio` 70% 이상

하나라도 미충족이면 **lecture-research로 회귀**하여 관문 2를 먼저 통과시킨다.

## 관문 3 체크리스트 (7개 항목, 모두 충족)

### 슬라이드 구조 (3개)

- [ ] **슬라이드 수가 강의 시간 대비 적정한가**
  - 기준: 1슬라이드당 2~3분 (실습 슬라이드 제외)
  - 예: 180분 강의 → 60~90장 (쉬는 시간·실습 제외)
  - 초과 시 분할·통합, 부족 시 보강

- [ ] **각 슬라이드에 핵심 메시지 1개가 명시되었는가**
  - 1슬라이드 = 1메시지 원칙
  - 메시지가 2개 이상이면 슬라이드 분할
  - 핵심 메시지 필드가 비어 있는 슬라이드 없음

- [ ] **꼭지별 대표 슬라이드가 지정되었는가**
  - 각 Ch마다 "표지 슬라이드" 또는 "핵심 요약 슬라이드" 1개 지정
  - 이미지 우선순위 판단 기준이 됨

### 이미지 연결 (3개)

- [ ] **이미지 필요 슬라이드 목록이 추출되었는가**
  - 전체 슬라이드 중 이미지가 필요한 것을 별도 리스트로 분리
  - 각 항목에 "왜 이 슬라이드에 이미지가 필요한가" 1줄 명시

- [ ] **각 이미지 슬롯에 레이아웃 유형이 지정되었는가**
  - 5종 중 1개 선택: 중앙 / 2분할 / 카드그리드 / 타임라인 / 방사형
  - lecture-infographic의 레이아웃 체계와 일치

- [ ] **컬러 키가 강의 전체에 일관되게 지정되었는가**
  - 7종 중 1개 선택 (blue·green·purple·orange·teal·rose·slate)
  - 강의 전체에 동일 컬러 키 적용 (꼭지별로 다르게 X)
  - 선택 근거 1줄 명시 (예: "AI 기술 강의 → blue")

### 텍스트 배치 (1개)

- [ ] **텍스트 배치(T1/T2/T3) 모드가 선택되었는가**
  - T1: 상단 중앙 (기본 모드, 안정적)
  - T2: 좌측 하단 (장면형, 여백 활용)
  - T3: 분할 배치 (비교·대조용)
  - 강의 성격에 맞는 기본 모드 지정 (이미지별 예외 허용)

## 통과 기준

**7/7 모두 충족**

부분 통과는 없다. 1개라도 미충족이면 해당 항목만 보완 후 재검증.

## 실패 시 대응

### 항목 1~3 실패 (슬라이드 구조)
- **슬라이드 수 초과**: 유사 메시지 슬라이드 통합, 보조 정보는 핸드아웃으로 이동
- **슬라이드 수 부족**: 핵심 메시지를 재분해하여 슬라이드 추가
- **메시지 2개 이상 슬라이드**: 분할
- **대표 슬라이드 누락 꼭지**: 해당 꼭지에 표지 또는 요약 슬라이드 추가

### 항목 4~6 실패 (이미지 연결)
- **이미지 필요 목록 누락**: 슬라이드 전체 재검토, 텍스트만으로 전달 어려운 것 선별
- **레이아웃 미지정**: RL 노트의 "슬라이드 이미지 키워드"를 참조해 자동 매핑
- **컬러 키 불일치**: 강의 주제·대상·톤을 기준으로 재선택

### 항목 7 실패 (텍스트 배치)
- T1을 기본값으로 설정하고 이미지별 예외만 별도 표기

### 2회 연속 전체 실패
- lecture-slides Phase 1부터 재실행 권장
- 근본 원인이 lecture-research에 있으면 관문 2부터 재검증

## 출력 YAML 추가 항목

관문 3 통과 후 슬라이드 산출물 YAML 프론트매터에 아래를 기록한다.

```yaml
gate_1_passed: true   # lecture-plan에서 상속
gate_2_passed: true   # lecture-research에서 상속
gate_3_passed: true
gate_3_score: 7/7
gate_3_checked_at: {YYYY-MM-DD}
slide_count: {N}
image_slot_count: {N}
color_key: {blue/green/purple/orange/teal/rose/slate}
text_layout_default: {T1/T2/T3}
```

## 다음 단계 전달 사항

관문 3 통과 시 lecture-infographic에 아래 정보가 자동 전달된다.

- 이미지 필요 슬라이드 목록 (레이아웃 유형 포함)
- 컬러 키
- 텍스트 배치 기본 모드
- target_profile (lecture-plan·lecture-research에서 상속)
- 강의 제목·대상·시간

이 정보만으로 lecture-infographic은 재질문 없이 바로 이미지 프롬프트 생성에 착수할 수 있다.

## Harness 블록 (관문 3 전용)

| 항목 | 값 |
|------|-----|
| **평가 분리** | lecture-slides 본 프로세스와 분리된 독립 검증 단계 |
| **통과 기준** | 7/7 모두 충족 (부분 통과 없음) |
| **실패 시 대응** | 항목별 개별 보완 → 2회 실패 시 Phase 1 회귀 |
| **재검증 조건** | 보완 후 해당 항목만 재체크 |

## 실행 원칙

- 관문 3은 lecture-slides 본 프로세스 **종료 직후** 실행한다
- **관문 3 통과 전에는 lecture-infographic 진입 금지**
- 입력 조건(gate_2_passed)이 false면 lecture-research로 회귀
- 통과 시 YAML 플래그 기록 및 lecture-infographic 입력 패키지 생성
- 실패 시 항목별 대응 경로를 명시적으로 출력
