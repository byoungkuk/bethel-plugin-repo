## 1. 타이틀 슬라이드

```
┌─────────────────────────────────────┐
│                                     │
│     [강의 제목] — 180pt, 중앙        │
│     핵심 키워드 악센트(#F27100)       │
│                                     │
│     강사명 — 32pt, 중앙              │
│                                     │
│     ┌────────────┬────────────┐     │
│     │  Before    │  After     │     │
│     │  (문제)    │  (해결)    │     │
│     └────────────┴────────────┘     │
│                                     │
└─────────────────────────────────────┘
```

**구성 규칙:**
- 제목은 2줄 구성. 1줄: 대상/맥락, 2줄: 핵심 주제
- 핵심 키워드 1~2개를 악센트 색(#F27100)으로 강조
- 일러스트는 좌우 대비 구도 권장 (문제 상황 vs 해결 상황)
- 강사 정보는 제목과 일러스트 사이 중앙에 배치

**서술 원칙:**
- 제목에 "~를 위한", "~의 비밀" 같은 대상 지향 구문 사용
- 부제 없이 제목만으로 강의 내용이 파악되어야 함

## 2. 섹션 구분 슬라이드

```
┌─────────────────────────────────────┐
│                                     │
│     (N)  섹션 제목                   │
│     원형   95pt, #5E5E5E            │
│     90pt                            │
│                                     │
│     [관련 일러스트 / 아이콘]         │
│                                     │
└─────────────────────────────────────┘
```

**구성 규칙:**
- 원형 번호: 진회색(#5E5E5E) 원 안에 흰색(#FFFFFF) 숫자
- 섹션 제목: 95pt, #5E5E5E, 원형 오른쪽에 배치
- 제목은 간결한 구문 (15자 내외)

**일러스트 영역 (하단):**
- 슬라이드 하단에 일러스트 영역을 예약한다
- 이미지 제공 시: 좌표 x:3.0, y:6.0, w:20.67, h:8.0 영역에 배치
- 이미지 미제공 시: 회색 플레이스홀더(#F0F0F0) + 설명 텍스트로 표시
- 원본 템플릿에서는 캐릭터 일러스트+AI 아이콘이 이 영역에 배치됨

**서술 원칙:**
- "무엇을 배우는가"가 아닌 "무엇을 할 수 있게 되는가" 관점
- 예: "AI 리터러시 & 인식 전환", "AI 필수 도구 소개: 우리 회사의 무기"

## 3. 콘텐츠 슬라이드 (개념 설명)

```
┌─────────────────────────────────────┐
│  [①번호 + 판단 중심 제목] — 60pt    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │                             │    │
│  │     일러스트 이미지           │    │
│  │     (슬라이드 면적 60~70%)   │    │
│  │                             │    │
│  └─────────────────────────────┘    │
│                                     │
└─────────────────────────────────────┘
```

**구성 규칙:**
- 제목: 60pt, 검정, 중앙 정렬
- 번호 접두사: ①②③④ 형태로 섹션 내 순서 표시
- 일러스트가 핵심 내용을 전달 — 텍스트는 제목 1줄만
- 상세 설명은 발표 노트(Speaker Notes)에 작성

**제목 서술 원칙:**
- ❌ "AI의 정의" → ✅ "②AI, 어렵게 생각하지 마세요"
- ❌ "보안 주의사항" → ✅ "③보안과 윤리: 내 정보는 내가 지킵니다"
- 판단·행동·태도를 담은 문장형 제목
- 청중에게 말하듯 쓴다 (격식체 또는 해요체)

**일러스트 가이드:**
- 핵심 개념을 시각적으로 표현하는 일러스트
- 좌우 분할(Before/After, X/O), 프로세스 도해, 비유 도식 등
- 텍스트가 포함된 일러스트 가능 (키워드, 라벨 수준)

## 4. 비교/대조 슬라이드

```
┌─────────────────────────────────────┐
│  [비교 기준이 드러나는 제목] — 60pt  │
│                                     │
│  ┌──────────────┬──────────────┐    │
│  │     ✗        │     ✓        │    │
│  │   항목 A     │   항목 B     │    │
│  │   일러스트   │   일러스트   │    │
│  │              │              │    │
│  │   설명 텍스트 │   설명 텍스트 │    │
│  └──────────────┴──────────────┘    │
│                                     │
└─────────────────────────────────────┘
```

**구성 규칙:**
- 좌우 2분할 일러스트로 대비 표현
- 부정(❌) 좌측, 긍정(✓) 우측 배치가 기본
- 각 영역 하단에 1~2줄 설명 텍스트
- 하단에 핵심 결론 1줄 가능

**서술 원칙:**
- 제목: "사람을 대체하는 것이 아닌, '서류 지옥'에서 해방"
- 비교 기준이 제목에 드러나야 함

## 5. 프로세스 슬라이드

```
┌─────────────────────────────────────┐
│  [단계별 흐름 제목] — 60pt           │
│                                     │
│  ┌───────┐  →  ┌───────┐  →  ┌───────┐
│  │카드 1 │     │카드 2 │     │카드 3 │
│  │라벨   │     │라벨   │     │라벨   │
│  │설명   │     │설명   │     │설명   │
│  └───────┘     └───────┘     └───────┘
│                                     │
│  Tip 텍스트 (선택)                   │
└─────────────────────────────────────┘
```

**검증된 좌표 (3단계 기준):**

| 요소 | x (in) | y (in) | w (in) | h (in) |
|------|--------|--------|--------|--------|
| 제목 | 공통 제목 좌표 적용 (template-spec.md 4-0) ||||
| 카드 1 | 2.5 | 3.5 | 5.5 | 7.5 |
| 카드 2 | 10.0 | 3.5 | 5.5 | 7.5 |
| 카드 3 | 17.5 | 3.5 | 5.5 | 7.5 |
| 화살표 (카드 사이) | 카드x+5.5 | 5.5 | 2.0 | 2.0 |
| Tip 텍스트 | 2.5 | 12.0 | 21.67 | 0.8 |

**구성 규칙:**
- 카드: ROUNDED_RECTANGLE, fill #F5F5F5, rectRadius 0.2
- 카드 내 라벨: 악센트 색(#F27100), 36pt, bold
- 카드 내 설명: 검정, 28pt
- 화살표: "→" 텍스트, 악센트 색, 72pt
- 3~6단계 (4단계 이상이면 카드 폭·간격 조정)
- 단계 수가 7개 이상이면 2장으로 분할

## 6. 실습 안내 슬라이드

```
┌──────────────────────────────────────┐  ← 배경 #FFF3E0
│  [실습: 실습 제목] — 60pt             │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  과제    설명 텍스트           │    │  ← 흰색 카드
│  │  ────────────────────         │    │
│  │  조건    설명 텍스트           │    │
│  │  ────────────────────         │    │
│  │  시간    N분                  │    │
│  │  ────────────────────         │    │
│  │  힌트    설명 텍스트           │    │
│  └──────────────────────────────┘    │
│                                      │
└──────────────────────────────────────┘
```

**검증된 좌표:**

| 요소 | x (in) | y (in) | w (in) | h (in) |
|------|--------|--------|--------|--------|
| 배경색 | 슬라이드 전체 | - | - | - |
| 제목 | 공통 제목 좌표 적용 (template-spec.md 4-0) ||||
| 카드 배경 | 3.0 | 2.5 | 20.67 | 9.5 |
| 항목 라벨 (과제/조건/시간/힌트) | 4.0 | 3.2 + i×2.0 | 3.0 | 1.5 |
| 항목 값 | 7.5 | 3.2 + i×2.0 | 15.0 | 1.5 |
| 구분선 | 4.0 | 항목 사이 | 18.5 | 0 |

**구성 규칙:**
- 슬라이드 배경: #FFF3E0 (연한 주황) → 일반 슬라이드와 시각적 구분
- 카드: ROUNDED_RECTANGLE, fill #FFFFFF, rectRadius 0.2
- 항목 라벨: 악센트 색(#F27100), 36pt, bold
- 항목 값: 검정, 30pt
- 구분선: #E0E0E0, width 1
- 과제·조건·시간·힌트 4개 항목 (힌트는 선택적)

## 7. 사례/예시 슬라이드

콘텐츠 슬라이드(유형 3)와 동일한 레이아웃.
- 제목에 사례의 판단 포인트를 명시
- 일러스트에 실제 결과물/화면 캡처 배치
- 하단에 판단 기준 해설 1~2줄 추가 가능

## 8. 체크포인트 슬라이드

```
┌─────────────────────────────────────┐
│  [체크포인트] — 60pt, 악센트 색      │
│                                     │
│  Q: [이해도 확인 질문] — 40pt        │
│                                     │
│  ┌─────────────────────────┐        │
│  │ A) 선택지 1              │        │
│  └─────────────────────────┘        │
│  ┌═════════════════════════┐        │  ← 정답: 악센트 테두리
│  │ B) 선택지 2              │        │
│  └═════════════════════════┘        │
│  ┌─────────────────────────┐        │
│  │ C) 선택지 3              │        │
│  └─────────────────────────┘        │
└─────────────────────────────────────┘
```

**검증된 좌표:**

| 요소 | x (in) | y (in) | w (in) | h (in) |
|------|--------|--------|--------|--------|
| 제목 "체크포인트" | 공통 제목 좌표 적용 (template-spec.md 4-0) ||||
| 질문 텍스트 | 3.0 | 2.8 | 20.67 | 2.5 |
| 선택지 카드 (각각) | 5.0 | 6.0 + i×2.2 | 16.67 | 1.8 |

**구성 규칙:**
- 제목 "체크포인트": 악센트 색(#F27100), 60pt, bold
- 질문: 검정, 40pt, bold, 중앙 정렬
- 선택지: ROUNDED_RECTANGLE 카드, rectRadius 0.15
  - 일반 선택지: fill #F5F5F5, line #E0E0E0 (width 1)
  - 정답 선택지: fill #FFFFFF, line 악센트(#F27100, width 3)
- 선택지 텍스트: 검정, 32pt
- 정답 표시는 강의 중 구두로, 또는 다음 슬라이드에서 공개

## 9. 요약/정리 슬라이드

```
┌─────────────────────────────────────┐
│  [④요약 제목] — 60pt                │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  요약 일러스트               │    │
│  │  (핵심 포인트 시각화)        │    │
│  └─────────────────────────────┘    │
│                                     │
│  → 한 줄 결론 텍스트                 │
│                                     │
└─────────────────────────────────────┘
```

**구성 규칙:**
- 콘텐츠 슬라이드와 동일한 레이아웃
- 핵심 포인트를 시각적으로 정리한 일러스트
- 하단에 한 줄 결론 문장 가능 (예: "AI는 현장을 더 똑똑하고 안전하게 만든다")
- 다음 섹션 전환 예고 포함 가능

## 11. 다컬럼 정보 슬라이드

여러 항목을 병렬 비교하거나 로드맵을 한눈에 보여줄 때 사용한다.

```

│  [제목] — 60pt                       │
│                                     │
│  ┌────────┐  ┌────────┐  ┌────────┐│
│  │ 제목   │  │ 제목   │  │ 제목   ││
│  │ (부제) │  │ (부제) │  │ (부제) ││
│  │ ────── │  │ ────── │  │ ────── ││
│  │ · 항목 │  │ · 항목 │  │ · 항목 ││
│  │ · 항목 │  │ · 항목 │  │ · 항목 ││
│  │ · 항목 │  │ · 항목 │  │ · 항목 ││
│  │        │  │        │  │        ││
│  │ [목표] │  │ [목표] │  │ [목표] ││
│  └────────┘  └────────┘  └────────┘│
└─────────────────────────────────────┘
```

**검증된 좌표 (3컬럼 기준):**

| 요소 | x (in) | y (in) | w (in) | h (in) |
|------|--------|--------|--------|--------|
| 제목 | 공통 제목 좌표 적용 (template-spec.md 4-0) ||||
| 카드 1 | 1.5 | 2.2 | 7.72 | 10.5 |
| 카드 2 | 9.72 | 2.2 | 7.72 | 10.5 |
| 카드 3 | 17.94 | 2.2 | 7.72 | 10.5 |
| 카드 내 제목 | 카드x+0.3 | 2.5 | 7.12 | 1.2 |
| 카드 내 부제 | 카드x+0.3 | 3.7 | 7.12 | 0.8 |
| 카드 내 구분선 | 카드x+0.5 | 4.7 | 6.72 | 0 |
| 카드 내 항목 | 카드x+0.5 | 5.0+i×1.5 | 6.72 | 1.2 |
| 카드 내 목표 카드 | 카드x+0.3 | 10.5 | 7.12 | 1.5 |

**구성 규칙:**
- 카드: ROUNDED_RECTANGLE, fill #F5F5F5, rectRadius 0.15
- 카드 내 제목: 검정, 28pt, bold, 중앙 정렬
- 카드 내 부제: 회색(#B8B8B8), 22pt, 중앙 정렬
- 카드 내 항목: "· " 접두, 검정, 22pt
- 하단 목표 카드: ROUNDED_RECTANGLE, fill #FFFFFF, rectRadius 0.1
- 목표 텍스트: 진회색(#5E5E5E), 20pt, bold, 중앙 정렬
- 2컬럼이면 카드 폭을 11"로, 4컬럼이면 5.5"로 조정

## 슬라이드 유형 선택 가이드

### 목적 기반 선택

| 전달 목적 | 추천 유형 |
|----------|----------|
| 새 개념 도입 | 콘텐츠 (개념 설명) |
| A vs B 차이 | 비교/대조 |
| 순서·절차 | 프로세스 |
| 실제 사용 예 | 사례/예시 |
| 수강생 참여 | 체크포인트 |
| 직접 해보기 | 실습 안내 |
| 섹션 끝 | 요약/정리 |
| 대단원 전환 | 섹션 구분 |
| 여러 항목 병렬 비교 | 다컬럼 정보 |
| 전체 로드맵/커리큘럼 | 다컬럼 정보 |

### 콘텐츠 수 × 순서 기반 의사결정 트리

내용을 슬라이드로 구성할 때, 다루는 항목 수와 순서 유무로 유형을 결정한다.

```
항목이 몇 개인가?
│
├─ 1개 → 콘텐츠 (개념 설명)
│
├─ 2개
│   └─ 대비/비교 관계인가?
│       ├─ 예 → 비교/대조
│       └─ 아니오 → 콘텐츠 2장으로 분리
│
├─ 3~4개
│   └─ 항목 간 순서가 있는가?
│       ├─ 예 (A→B→C) → 프로세스
│       └─ 아니오 (A, B, C 병렬) → 다컬럼 정보
│
└─ 5개 이상
    └─ 2장 이상으로 분할 (위 기준 재적용)
```

**판단 예시:**
- "ChatGPT vs Claude vs Gemini 비교" → 3개, 순서 없음 → **다컬럼**
- "Role → Context → Format 3단계" → 3개, 순서 있음 → **프로세스**
- "가명처리 vs 사람 검수" → 2개, 대비 관계 → **비교/대조**
- "LLM이란 무엇인가" → 1개 → **콘텐츠**
