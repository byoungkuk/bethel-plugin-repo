# 소설 보이스 레퍼런스 워크플로우 (book-novel-voice)

파일럿 챕터를 한 번 써본 뒤, 그 원고를 근거로 참조 작가를 추천받고 자기 문체 규약을 확정하는 워크숍. 기획 직후가 아니라 집필 중간(파일럿 직후)에 실행한다. 이유는 자기 문장이 한 번 나와야 어떤 작가의 어떤 특성을 빌려 교정할지가 구체화되기 때문이다.

## 파이프라인 위치

```
book-planning-novel (기획)
  → 한 줄 전제 + 기획안 + 씬 골격
book-novel  Phase 1 설계 키트 → Phase 2 파일럿 챕터 1개
  → 파일럿 원고
book-novel-voice (이 스킬)
  → style-guide.md (내 문체 규약)
book-novel  Phase 4 본격 집필 → Phase 6 퇴고 → Phase 7 편집
```

이 스킬은 book-novel Phase 3(톤 레퍼런스 확정)을 대체한다. book-novel을 외부에서 호출할 때 Phase 3 단계는 이 스킬의 산출물(style-guide.md)로 갈음한다.

---

## 핵심 원칙

**1. 추천 기반 (사용자 지정 아님)**

작가를 사용자에게 먼저 묻지 않는다. 파일럿 원고의 문체·주제·정서를 진단한 뒤, 그 진단을 근거로 적합 작가 2~3명을 추천한다. 사용자가 특정 작가를 직접 지정하면 그 작가로 진행하되, 기본 흐름은 원고 기반 추천이다.

**2. 형식 속성만 추출**

참조 작가에게서 가져오는 것은 측정 가능한 형식 속성뿐이다. 문장 길이 분포, 서술 시점, 감각 묘사 밀도, 대화와 서술의 비중, 문장 리듬, 종결·어조 패턴, 정서 온도. 줄거리·설정·실제 문장은 가져오지 않는다.

**3. 자기다움 우선**

산출물은 "○○ 작가처럼 쓰기"가 아니다. 작가 원리를 참고점으로 삼아, 사용자 파일럿 원고의 강점과 결합한 "내 소설의 문체 규약"이다. 작가는 방향을 가리키는 참고점일 뿐이다.

**4. 파일럿 원고 전제**

이 스킬은 파일럿 챕터 원고를 입력으로 요구한다. 원고 없이 주제만 있으면, 먼저 book-novel Phase 2로 파일럿 한 챕터를 쓰고 오도록 안내한다.

---

## 저작권 가드레일 (고정)

이 스킬의 모든 단계는 아래를 위반하지 않는다.

- 참조 작가의 실제 문장을 인용·재현·발췌·모사하지 않는다.
- 추출 대상은 측정 가능한 형식 속성에 한정한다. 줄거리·세계관·고유 표현은 추출하지 않는다.
- 작가 이름 거명은 문체 방향 참고로만 쓴다. 산출물에서는 작가 의존을 일반화해 사용자 고유 규약으로 전환한다.
- 5단계 Evaluator가 출력 샘플의 작가 유사도를 점검한다. 특정 작가 문장과 유사하면 자기다움 쪽으로 되돌린다.

---

## Harness Engineering 블록

- **생성-평가 분리:** 4단계(보이스 가이드 합성·샘플 생성)는 Generator, 5단계(모사·자기다움 검증)는 Evaluator로 분리한다. 같은 패스에서 만들고 평가하지 않는다.
- **AI 흔적 제거:** 합성한 규약과 샘플에서 과장형 형용사·모호한 부사·추측 표현·추상명사 중심 문장을 제거한다.
- **원문 보존 레벨:** 이 스킬은 파일럿 원고를 분석만 한다(L1 관찰). 원고 자체를 고쳐 쓰지 않는다. 적용 샘플은 별도 단락으로 생성해 before/after로 비교한다.
- **분량 가드레일:** 작가 추천은 2~3명, 근거는 각 3줄 이내. 보이스 가이드(style-guide.md)는 A4 1~2쪽. 적용 샘플은 1단락(150~250자).

---

## 문체 측정 7축

1단계 진단과 작가 추천, 가이드 합성에서 공통으로 쓰는 측정 축.

| 축 | 측정 내용 |
|----|----------|
| 문장 길이 분포 | 평균 어절 수, 단문·중문·장문 비율 |
| 서술 시점 | 1인칭 / 3인칭 제한 / 3인칭 전지, 서술 거리 |
| 감각 묘사 밀도 | 장면당 감각 채널(시·청·촉·후·미) 수 |
| 대화 대 서술 | 대화문과 서술의 비중 |
| 문장 리듬 | 단문 연타 / 만연체 / 교차 |
| 종결·어조 | 현재형·과거형, 종결어미 경향, 호흡 |
| 정서 온도 | 건조함 ↔ 서정성의 위치 |

## 시작 응답 템플릿

```
보이스 레퍼런스를 시작합니다.

파일럿 챕터에서 나온 문장을 근거로 진행합니다.
작가를 먼저 고르지 않습니다. 원고를 읽고 어울리는 작가를 추천해드립니다.

순서는 5단계입니다. (총 20~30분)
  1단계 — 파일럿 원고 진단
  2단계 — 작가 추천 (원고 기반)
  3단계 — 문체 원리 추출
  4단계 — 보이스 가이드 합성
  5단계 — 적용 샘플·검증

먼저 파일럿 챕터 원고를 붙여주세요.
(아직 없으면 book-novel Phase 2로 한 챕터를 쓰고 오시면 됩니다)
```

---

## 1단계 — 파일럿 원고 진단 (목표 7분)

파일럿 챕터 원고를 입력받아 문체 7축을 측정하고, 주제·정서·장르를 추출한다.

```
[1단계 — 파일럿 원고 진단]

원고를 읽고 다음을 측정했습니다.

문체 7축:
- 문장 길이: {평균 어절} / 단문 {%}·중문 {%}·장문 {%}
- 시점: {1인칭/3인칭...} (서술 거리: {가까움/멀음})
- 감각 묘사 밀도: 장면당 {N}개 채널
- 대화 대 서술: {대화 %} : {서술 %}
- 문장 리듬: {단문 연타/만연체/교차}
- 종결·어조: {현재형/과거형}, {종결 경향}
- 정서 온도: {건조 ↔ 서정} 중 {위치}

주제·정서:
- 핵심 주제: {한 줄}
- 지배 정서: {감정 1~2개}
- 장르 결: {장르}

이 진단을 근거로 작가를 추천합니다. 다음 단계로 갈까요?
```

진단은 관찰만 한다. 원고를 평가하거나 고치지 않는다.

---

## 2단계 — 작가 추천 (목표 5분)

1단계 진단 프로파일을 `references/author-matching.md`의 문체 축별 작가 경향과 대조해 2~3명을 추천한다. 각 작가가 왜 이 원고에 맞는지 형식 근거로 제시한다.

```
[2단계 — 작가 추천]

원고 프로파일과 가까운 작가를 추천합니다.
(작가는 문체 방향의 참고점입니다. 그대로 따라 쓰는 것이 아닙니다)

추천 1) {작가명}
  - 맞는 이유: {진단 축과 연결한 형식 근거 3줄 이내}
  - 빌릴 만한 특성: {예: 단문 리듬, 감각 절제}

추천 2) {작가명}
  - 맞는 이유: {...}
  - 빌릴 만한 특성: {...}

[추천 3) — 결이 다른 선택지 1명 추가 가능]

이 중 한 명을 고르시면 3단계로 갑니다.
직접 떠오르는 작가가 있으면 그 이름으로 진행해도 됩니다.
```

추천 근거는 줄거리·세계관이 아니라 형식 속성으로만 쓴다. 사용자가 직접 작가를 대면 그 작가로 진행한다.

---

## 3단계 — 문체 원리 추출 (목표 5분)

선택 작가의 문체를 측정 가능한 형식 속성으로만 분해한다. 저작권 가드레일을 적용한다.

```
[3단계 — 문체 원리 추출]

{작가명}의 문체를 형식 속성으로 분해했습니다.
(실제 문장은 옮기지 않습니다. 형식만 봅니다)

- 문장 길이 경향: {...}
- 시점·거리: {...}
- 감각 묘사 방식: {...}
- 대화 처리: {...}
- 리듬: {...}
- 종결·어조: {...}

이 중 내 원고에 어울리는 것과 어긋나는 것을 4단계에서 가립니다.
```

---

## 4단계 — 보이스 가이드 합성 (목표 7분, Generator)

작가 원리와 사용자 파일럿 원고의 강점을 결합한다. 차용할 것과 버릴 것을 명시해 내 문체 규약으로 전환한다.

```
[4단계 — 보이스 가이드 합성]

작가 원리 + 내 원고 강점을 합쳐 문체 규약을 만들었습니다.

차용 (작가에게서 가져옴):
- {특성 1} — 이유: {내 주제·정서와 맞는 지점}
- {특성 2}

유지 (내 원고의 강점):
- {파일럿에서 이미 잘 작동한 특성}

버림 (작가 특성 중 안 맞는 것):
- {특성} — 이유: {내 주제와 충돌}

→ style-guide.md 초안을 생성합니다.
```

`references/voice-guide-template.md` 골격으로 style-guide.md를 작성한다.

---

## 5단계 — 적용 샘플·검증 (목표 5분, Evaluator)

보이스 가이드를 파일럿 한 단락에 적용해 before/after를 만들고, 모사 여부·자기다움을 점검한다. 4단계 Generator와 다른 시점으로 평가한다.

```
[5단계 — 적용 샘플·검증]

[before — 파일럿 원문 1단락]
{원문}

[after — 보이스 가이드 적용]
{적용 단락 150~250자}

검증:
- 작가 모사 여부: {특정 작가 문장과 유사한 부분 없음 / 있음→수정}
- 자기다움: {원고 고유 색이 유지됨 / 흐려짐→되돌림}
- 7축 정합: {가이드 수치와 샘플 일치 여부}

문제가 있으면 가이드를 수정하고 샘플을 다시 만듭니다.
```

검증을 통과하면 style-guide.md를 확정한다.

## 자주 발생하는 변수와 대응

### 파일럿 원고가 없을 때

```
보이스 레퍼런스는 파일럿 원고를 근거로 추천합니다.
원고가 없으면 추천 근거가 없습니다.

book-novel Phase 2로 핵심 챕터 한 개를 먼저 쓰고 오시면,
그 원고로 작가를 추천하겠습니다.
```

### 추천 작가가 마음에 안 들 때

결이 다른 선택지 1명을 추가 추천한다. 그래도 안 맞으면 사용자가 직접 지정한 작가로 3단계를 진행한다. 추천은 강제가 아니다.

### 파일럿 원고가 너무 짧을 때 (500자 미만)

```
원고가 짧아 문체 측정이 불안정합니다.
파일럿을 1,000자 이상으로 늘려 오시면 진단 정확도가 올라갑니다.
지금 분량으로 잠정 진단은 가능하나, 추천은 참고 수준입니다.
```
