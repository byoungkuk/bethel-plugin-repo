# 씬 프롬프트 템플릿 (Scene Prompt Templates)

소설 집필의 각 단계에서 AI에게 전달할 프롬프트 구조.
사용자는 [ ] 안의 내용을 자기 소설에 맞게 채워 넣는다.

---

## A. 씬 초안 요청 프롬프트

```
당신은 [장르] 소설의 공동 작가입니다.
아래 설정을 반드시 따르세요.

[서술 규칙]
- [서술 시점] (예: 3인칭 제한 시점, 서진호 시선)
- [시제], [종결어미] (예: 과거형, ~다체)
- 감정 직접 서술 금지. 행동과 감각으로 표현.
- 문장 [N]자 이내, 문단 [N]~[N]문장
- [금지 표현 목록]

[톤 레퍼런스]
아래 문단의 톤과 문체를 유지하세요.
---
[톤 레퍼런스 문단 3~5개 붙여넣기]
---

[인물 정보]
[해당 챕터에 등장하는 인물 설계서 붙여넣기]

[현재 챕터]
챕터 번호: [N]
장소: [장소]
등장 인물: [인물 이름]
씬 요약: [무엇이 일어나는가]
감정 변화: [시작 감정] → [끝 감정]
필수 요소: [이 장면에 반드시 포함할 것]
금지 요소: [이 장면에서 하지 말아야 할 것]

[직전 장면 마지막 문단]
[이전 챕터의 마지막 2~3문단 붙여넣기]

위 조건에 맞춰 약 [N]자 분량으로 이 장면을 작성해 주세요.
```

## B. 이어쓰기 프롬프트

같은 챕터를 2~3회로 나눠 쓸 때 사용한다.

```
아래는 챕터 [N]의 앞부분입니다. 이어서 작성해 주세요.

[서술 규칙]
(A 프롬프트와 동일한 규칙 붙여넣기)

[톤 레퍼런스]
(동일)

[현재까지 작성된 내용]
[앞부분 전체 또는 마지막 3~5문단 붙여넣기]

[남은 장면에서 일어날 일]
- [사건/행동 요약]
- 감정 변화: [현재 감정] → [이 파트 끝 감정]
- 필수 요소: [포함할 것]
- 금지 요소: [하지 말 것]

약 [N]자 분량으로 이어서 작성해 주세요.
앞부분의 톤과 리듬을 자연스럽게 이어받으세요.
```

## C. 퇴고 요청 프롬프트

```
아래 소설 원고를 다음 기준으로 퇴고해 주세요.

[점검 항목]
1. 감정 직접 서술("두려웠다", "화가 났다" 등)이 있으면 행동/감각 묘사로 교체
2. [N]자 초과 문장을 분리
3. "[금지 전환 부사]" 제거
4. [금지 표현] 제거
5. "마치 ~처럼" 비유가 [N]회 초과하면 줄이기
6. 인물 말투가 설계서와 일치하는지 확인
   - [인물 A]: [말투 특징]
   - [인물 B]: [말투 특징]
   - [인물 C]: [말투 특징]

수정한 부분은 【 】로 표시하고, 수정 이유를 각주로 달아주세요.

[원고]
(퇴고할 텍스트 붙여넣기)
```

## D. 대화문 점검 프롬프트

대화문이 많은 장면에서, 인물별 말투 일관성을 별도로 점검할 때 사용한다.

```
아래 소설 원고의 대화문만 점검해 주세요.

[인물별 말투 규칙]
- [인물 A]: [말투 특징 + 대사 예시]
- [인물 B]: [말투 특징 + 대사 예시]
- [인물 C]: [말투 특징 + 대사 예시]

[점검 기준]
1. 각 인물의 대사가 위 말투 규칙과 일치하는가
2. 대사만 읽었을 때 누구의 말인지 구분되는가
3. 설명적 대사(인물이 독자에게 정보를 전달하기 위해 부자연스럽게 말하는 것)가 있는가
4. 대사 태그("~라고 말했다")가 단조롭지 않은가

일치하지 않는 대사를 찾아서:
- 원문을 인용하고
- 어떤 규칙에 어긋나는지 설명하고
- 수정안을 제시해 주세요.

[원고]
(점검할 텍스트 붙여넣기)
```

## E. 장면 밀도 조절 프롬프트

긴장감이 높은 장면(클라이맥스, 반전)에서 밀도를 높이거나, 전환 장면에서 간결하게 줄일 때 사용한다.

### 밀도 높이기 (긴장 장면용)

```
아래 장면의 긴장감을 높여주세요.

[방법]
- 문장을 더 짧게 끊어주세요 (20자 이내)
- 감각 묘사를 추가해 주세요 (특히 청각, 촉각)
- 인물의 미세한 신체 반응을 추가해 주세요 (손떨림, 입술 깨물기, 호흡 변화 등)
- 시간이 느리게 가는 느낌을 만들어 주세요

원문의 사건과 대사 내용은 바꾸지 마세요. 표현과 호흡만 조절합니다.

[원고]
(해당 장면 붙여넣기)
```

### 간결하게 줄이기 (전환 장면용)

```
아래 장면을 [N]자 이내로 압축해 주세요.

[방법]
- 핵심 사건과 감정 변화만 남기세요
- 묘사를 최소화하세요 (장소 묘사 1~2문장)
- 대화문이 있다면 핵심 대사 1~2개만 남기세요
- 이동·준비·일상 동작은 요약하세요

[원고]
(해당 장면 붙여넣기)
```

## F. 복선 점검 프롬프트

중간 점검(Phase 5)이나 퇴고(Phase 6)에서 복선의 설치와 회수를 점검할 때 사용한다.

```
아래는 소설 전체 원고(또는 챕터 요약)입니다.
복선(foreshadowing)의 설치와 회수를 점검해 주세요.

[점검 기준]
1. 설치된 복선 목록을 정리해 주세요 (어떤 챕터에서, 어떤 형태로)
2. 각 복선이 회수되었는지 확인해 주세요 (어떤 챕터에서, 어떤 형태로)
3. 회수되지 않은 복선이 있으면 표시해 주세요
4. 복선 없이 갑자기 등장하는 사건/정보가 있으면 표시해 주세요

표 형태로 정리해 주세요:

| 복선 | 설치 (챕터/위치) | 회수 (챕터/위치) | 상태 |
|------|-----------------|-----------------|------|
| ... | ... | ... | 완료/미회수/과도 |

[원고 또는 챕터 요약]
(붙여넣기)
```
