# 소설 설계 키트 템플릿 (Design Kit Template)

이 문서는 소설 집필 전 준비하는 6가지 설계 문서의 상세 양식이다.
가상 소설 **〈회색 수조〉**(사회파 스릴러)를 예제로 포함한다.

---

## 1. 장르와 톤

### 양식

| 항목 | 내용 |
|------|------|
| 장르 | |
| 톤 | |
| 분위기 키워드 | (3~5개) |
| 참조 작품 | (1~2개, 참조 대상 명시: 문체/구조/분위기) |
| 독자 타깃 | |

### AI 톤 지시문 작성법

장르와 톤을 정했으면, AI에게 전달할 톤 지시문을 5~8줄로 작성한다.
포함할 내용:
- 감정 표현 방식 (직접 서술 vs 행동/감각)
- 문장 호흡 (짧은가, 긴가, 섞는가)
- 비유의 소재 (자연물, 도시, 신체 등)
- 유머의 유무
- 사용하지 않는 표현

### 예제: 〈회색 수조〉

| 항목 | 설정 |
|------|------|
| 장르 | 사회파 스릴러 |
| 톤 | 건조하고 담담한 서술. 감정을 직접 설명하지 않고 행동과 풍경으로 보여준다. |
| 분위기 키워드 | 불안, 침묵, 회색, 습기, 균열 |
| 참조 작품 | 정유정 〈종의 기원〉(서술 밀도), 요네즈 호나가 〈흰 토끼는 그곳에 있었다〉(구조적 반전) |
| 독자 타깃 | 30~40대 직장인. 조직 안에서 윤리적 딜레마를 경험한 사람 |

**톤 지시문 예시:**
```
이 소설은 건조한 문체를 사용한다.
- 감정을 형용사로 직접 표현하지 않는다. ("슬펐다" 대신 행동이나 감각으로 보여준다)
- 문장은 짧고 끊어진다. 평균 2~3줄.
- 비유는 자연물(물, 콘크리트, 먼지)에서 가져온다.
- 유머는 없다. 아이러니는 있다.
```

## 2. 인물 설계서

### 양식 (인물 1명당)

| 항목 | 내용 |
|------|------|
| 이름 (나이, 성별) | |
| 직업 | |
| 외형 | (2~3가지 특징. 버릇 포함) |
| 성격 | (핵심 2~3가지) |
| 말투 | (특징 + 대사 예시 2~3개) |
| 핵심 욕망 | (이 인물이 가장 원하는 것) |
| 핵심 결핍 | (이 인물에게 부족하거나 숨기고 있는 것) |
| 변화 방향 | (시작점 → 끝점) |
| 다른 인물과의 관계 | |
| 이야기에서의 역할 | (주인공/조력자/적대자/촉매/거울 등) |

### 말투 설계 가이드

말투는 인물의 성격을 가장 직접적으로 드러낸다. 다음 요소를 조합해 설계한다.

- **문장 길이**: 짧고 끊는가 / 길고 이어지는가
- **어미**: ~요 / ~다 / ~거든 / ~잖아 / 끝을 흐리는가
- **호칭**: 직급 / 이름 / 별명 / 관계 호칭
- **습관적 표현**: 자주 쓰는 입버릇 1~2개
- **정보 요구 방식**: 질문을 많이 하는가 / 단정적으로 말하는가

### 예제: 〈회색 수조〉 주인공

**서진호 (38세, 남)**

| 항목 | 내용 |
|------|------|
| 직업 | K건설 환경안전팀 대리 (10년차) |
| 외형 | 마른 체형, 항상 구겨진 와이셔츠, 안경 위로 이마를 자주 문지르는 버릇 |
| 성격 | 원칙주의자이지만 충돌을 피하는 성향. 옳다고 믿는 것을 말하기까지 시간이 오래 걸린다. |
| 말투 | 짧은 문장, 끝을 흐림. "…인 것 같은데요", "그건 좀…" / 혼자 있을 때 혼잣말 |
| 핵심 욕망 | 조용히 살고 싶다. 문제를 보고도 모른 척할 수 있는 사람이 되고 싶다. |
| 핵심 결핍 | 아버지가 산업재해로 사망했다는 사실을 10년간 숨기고 있다. |
| 변화 방향 | 침묵하는 사람 → 증거를 들고 기자회견장에 서는 사람 |

## 3. 플롯 구조 (씬 리스트)

### 양식

3막 구조를 기본으로 씬(Scene)을 나열한다.

| 씬 # | 막 | 장소 | 등장 인물 | 사건 | 감정 변화 | 이야기 역할 |
|-------|---|------|-----------|------|-----------|-------------|
| 1 | 1막 | | | | (시작→끝) | (설정/갈등심화/반전/해소 등) |

### 씬 수 가이드

| 분량 | 권장 씬 수 |
|------|-----------|
| 단편 (5,000~15,000자) | 3~5씬 |
| 중편 (20,000~50,000자) | 8~12씬 |
| 장편 (60,000~120,000자) | 15~25씬 |

### 예제: 〈회색 수조〉 1막

| 씬 | 장소 | 사건 | 감정 변화 |
|----|------|------|-----------|
| 1 | K건설 사무실 | 진호가 폐수 처리 보고서에서 수치 불일치를 발견한다. | 의아함 → 무시하려는 충동 |
| 2 | 아파트 거실 | 퇴근 후 어머니와 저녁. 아버지 기일이 다가온다. | 일상의 무게 |
| 3 | 공장 인근 하천 | 진호가 직접 수질을 확인하러 간다. 물 색깔이 이상하다. | 불안의 시작 |
| 4 | 회의실 | 팀장에게 보고서 수치를 질문한다. "원래 그런 거야"라고 넘긴다. | 의심 → 고립감 |
| 5 | 카페 | 환경부 조사관이 접촉해 온다. 진호는 자기가 아니라고 부인한다. | 공포 + 호기심 |

## 4. 세계관·배경 설정

### 양식

```
시간:
  - 시대/연도:
  - 계절:
  - 이야기 기간:

공간: (주요 장소 3~5곳)
  - 장소 1: (위치, 분위기, 감각적 특징)
  - 장소 2:
  - 장소 3:

사회적 배경:
  - 이야기에 영향을 미치는 제도/관습/규칙:
  - 인물들이 속한 조직/공동체의 특성:

감각 소재 팩: (장면 묘사에 반복 사용할 소재)
  - 시각:
  - 청각:
  - 후각:
  - 촉각:
```

### 감각 소재 팩 작성 가이드

소설의 분위기를 일관되게 유지하려면, 장면 묘사에 반복적으로 사용할 감각 소재를 미리 정해둔다. 장르·톤에 맞는 소재를 5~10개 선정한다.

**예제: 〈회색 수조〉**
- 시각: 회색 물, 형광등, 갈대밭, 콘크리트 제방, 구겨진 와이셔츠
- 청각: 복합기 소리, 형광등 지직거림, 물 흐르는 소리, 벽시계 초침
- 후각: 화학 냄새, 된장찌개 냄새, 종이컵 커피
- 촉각: 차가운 공기, 코트 깃, 젖은 흙

## 6. 작업 단위 설계

### 양식

| 항목 | 설정 |
|------|------|
| 전체 목표 분량 | |
| 챕터 수 | |
| 챕터당 분량 | |
| 1회 AI 요청 분량 | (권장: 1,500~2,000자) |

### 작업 순서 기본 템플릿

```
1단계: 파일럿 챕터 (Ch 1~2) → 톤·말투 점검 및 설계 키트 보정
2단계: 톤 레퍼런스 확정
3단계: 1막 집필 (Ch 3~N)
4단계: 2막 전반 집필
5단계: 중간 점검 (50~60% 시점)
6단계: 2막 후반 + 3막 집필
7단계: 전체 퇴고 (3회 패스)
8단계: 최종 편집
```
